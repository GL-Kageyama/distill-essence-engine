# 入力：Suicaオルタナティブ案⑧ イヌ「ワン」（寄り添う・となりを歩く）

> 対象: 架空のSuica新イメージキャラクター候補（非公式・本投票3案とは別の、あり得たかもしれない案）。既存キャラ（ペンギン・リス・ウサギ・モグラ）の模倣を避けた独自案。

## キャラクターの骨格

| 項目 | 内容 |
|---|---|
| モチーフ | イヌ（犬）。忠実に人へ寄り添い、盲導犬・介助犬として導く。人の最良のパートナー |
| 通称案 | 「ワン」（＝犬の鳴き声。誰でも呼べる、親しみの名前） |
| 体色 | 温かい茶＋クリームの腹・鼻まわり＋Suicaグリーンの首輪 |
| 概念（動詞） | **寄り添う・となりを歩く（毎日のパートナー）** |
| 性格 | 素直で忠実。寄り添って歩くのが好き。知らない人にもしっぽを振る |

## なぜSuicaに合うか（ブランドとの対応）

- **毎日のパートナー**：Suicaの標語「毎日のパートナー」を、文字通り体現する。忠実に、毎日となりを歩く。
- **寄り添う**：盲導犬・介助犬は、人の安全を導き、寄り添う。Suicaが通勤・帰宅に寄り添う存在であることと重なる。
- **忠実・安心**：犬は道を覚え、必ず家へ帰る。迷っても、ついていけば安心。
- **首輪の緑**：体は茶色でも、Suicaグリーンの首輪でブランドカラーを身に着ける（カワウソのマフラー、フクロウのマントと同じ「まとう」型）。

## 語る一点（物語）

朝、家を出ると、ワンがとなりを歩き始める。改札も、乗り換えも、帰り道も、ずっと半歩後ろで寄り添う。あなたが「ただいま」と言うまで、しっぽを振って歩く。Suicaグリーンの首輪が、歩くたびに小さく鳴る。

- Suicaグリーンの首輪＝ブランドカラーを身に着ける。
- しっぽ＝嬉しそうに振れる、寄り添う気持ち。
- 半歩後ろを歩く＝「となりを歩く」毎日のパートナー。

## 使用シーン（イメージボードの小パネルで描く）

> ※ 実際のSuicaカードでは、キャラはカード面の**右端**に、**やや小ぶりに**印刷される（既存ペンギンを置き換え）。

1. 朝の駅前で、通勤する人のとなりを歩く（カードをタッチする手のそばに寄り添う）。
2. 改札の前で、カードを差し出す人の足元に、ちょこんと座って待つ。
3. 夜の帰り道、駅を出た人のとなりを、しっぽを振って歩く。

## 期待する雰囲気

素直で、忠実で、あたたかい。ふわっとした耳・丸い目・しっぽ。かわいさは「人懐っこさ」と「となりを歩く健気さ」。日本の交通系マスコットの「やわらかい平塗り」で、光沢やグラデは使わない。
