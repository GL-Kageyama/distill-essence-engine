# 入力：Suicaオルタナティブ案㉖ テントウムシ「テントウムシ」（ちいさな幸運を運ぶ）

> 対象: 架空のSuica新イメージキャラクター候補（非公式・本投票3案とは別の、あり得たかもしれない案）。既存キャラ（ペンギン・リス・ウサギ・モグラ）の模倣を避けた独自案。

## キャラクターの骨格

| 項目 | 内容 |
|---|---|
| モチーフ | テントウムシ（天道虫）。幸運の象徴。赤い甲羅に黒い斑点 |
| 通称案 | 「テントウムシ」 |
| 体色 | やわらかい赤の丸い甲羅＋黒い斑点＋小さな目 |
| 概念（動詞） | **ちいさな幸運を運ぶ** |
| 性格 | 小さくて、静かで、幸運をそっと運ぶ |

## なぜSuicaに合うか（ブランドとの対応）

- **天道虫＝神の虫**：テントウムシは「天道虫（天の道の虫）」。空へ飛んでいくことから「幸運を運ぶ」縁起物。
- **赤＝緑に映える**：赤い甲羅は、葉っぱの緑＝Suicaの緑に映える自然な補色。カードに並ぶとぽっと映える。
- **ちいさな幸運**：「ちいさな幸運」を運ぶ＝毎日の通勤に、ささやかな幸せをそっと添える。
- **小さな足＝タッチ**：小さな足で、カードをそっとタッチする仕草そのもの。

## 語る一点（物語）

赤いテントウムシが、緑の葉っぱ＝Suicaカードのそばに、ちょこんと止まっている。黒い斑点の甲羅が、ぽっと映える。小さな足でそっと「ピッ」。今日も、ちいさな幸運を、あなたの道にそっと運ぶ。

- 赤い甲羅＝Suicaの緑に映える補色。
- 天道虫＝幸運を運ぶ縁起物。
- 小さな足＝改札のタッチ。

## 使用シーン（イメージボードの小パネルで描く）

> ※ 実際のSuicaカードでは、キャラはカード面の**右端**に、**やや小ぶりに**印刷される（既存ペンギンを置き換え）。

1. 葉っぱ（＝緑）の上で、じっと止まって幸運を待つ。
2. 小さな足で、カードをそっとタッチする。
3. 改札のそばで、ちいさな幸運を静かに運ぶ。

## 期待する雰囲気

小さくて、静かで、幸運の健気さ。赤い丸い甲羅・黒い斑点・小さな足。かわいさは「ちいさな幸運を運ぶ健気さ」。日本の交通系マスコットの「やわらかい平塗り」で、光沢やグラデは使わない。
