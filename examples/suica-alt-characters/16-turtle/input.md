# 入力：Suicaオルタナティブ案⑯ カメ「カメ」（背負う・帰る場所をいつも持つ）

> 対象: 架空のSuica新イメージキャラクター候補（非公式・本投票3案とは別の、あり得たかもしれない案）。既存キャラ（ペンギン・リス・ウサギ・モグラ）の模倣を避けた独自案。

## キャラクターの骨格

| 項目 | 内容 |
|---|---|
| モチーフ | カメ（亀）。甲羅を背負い、どこへ行っても「家」を一緒に持っている。縁起物（鶴は千年、亀は万年＝長く寄り添う） |
| 通称案 | 「カメ」 |
| 体色 | やわらかい若草色の甲羅（Suicaグリーン寄り）＋白い腹＋のんびりした大きな丸い目 |
| 概念（動詞） | **背負う・帰る場所をいつも持つ** |
| 性格 | のんびり穏やか。急がず、ゆっくり、いつもの場所でじっと待つ |

## なぜSuicaに合うか（ブランドとの対応）

- **甲羅＝家**：カメは「家」を背負って歩く。どこへ行っても帰る場所を自分で持っている＝Suicaが「いつでも帰れるカード」であることと重なる。
- **万年＝25年**：「鶴は千年、亀は万年」の縁起物。25年続いたSuicaの「これからも長く」という願いを体現する。
- **のんびり＝焦らない**：急かさない、ゆっくりでいい、という穏やかさ。混雑する朝でも、焦らなくていいよ、と隣にいてくれる。
- **前足＝タッチ**：甲羅から差し出す前足が、改札でカードをそっと「タッチ」する仕草そのもの。

## 語る一点（物語）

甲羅を背負った小さなカメが、改札のそばで一匹。ゆっくり歩いて、いつもの場所にたどり着くと、のんびりと首を伸ばして待つ。甲羅にちょこんとSuicaを載せて、前足でそっと「ピッ」とタッチ。25年分の落ち着きで、今日もあなたの帰りを待っている。

- 甲羅＝いつも背負っている「家」＝帰る場所。
- 前足のタッチ＝改札の「ピッ」。
- 若草色の甲羅＝Suicaグリーンの縁起物。

## 使用シーン（イメージボードの小パネルで描く）

> ※ 実際のSuicaカードでは、キャラはカード面の**右端**に、**やや小ぶりに**印刷される（既存ペンギンを置き換え）。

1. 改札のそばで、甲羅にSuicaを載せてのんびり待つ。
2. 駅のベンチの下で、帰りを待つように首を伸ばす。
3. 家の玄関で、甲羅＝家の象徴としてじっと佇む。

## 期待する雰囲気

静かで、のんびりで、待つ落ち着き。甲羅＝家を背負った丸い体・のんびりした大きな目・そっと差し出す前足。かわいさは「焦らない穏やかさ」と「待つ安心感」。日本の交通系マスコットの「やわらかい平塗り」で、光沢やグラデは使わない。
