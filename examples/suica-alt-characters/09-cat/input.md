# 入力：Suicaオルタナティブ案⑨ ネコ「ニャン」（招く・招き猫）

> 対象: 架空のSuica新イメージキャラクター候補（非公式・本投票3案とは別の、あり得たかもしれない案）。既存キャラ（ペンギン・リス・ウサギ・モグラ）の模倣を避けた独自案。

## キャラクターの骨格

| 項目 | 内容 |
|---|---|
| モチーフ | ネコ（猫）。福を招く「招き猫」。駅は人を迎え入れ、街へ招く玄関 |
| 通称案 | 「ニャン」（＝猫の鳴き声。ポッポ・ワンと並ぶ呼びやすい名前） |
| 体色 | 白（または三毛）＋Suicaグリーンの首輪＋上げた前足 |
| 概念（動詞） | **招く・迎え入れる（おいで）** |
| 性格 | 気ままでマイペース。でも、お客さん（＝乗客）が来ると、前足を上げて「おいで」と招く |

## なぜSuicaに合うか（ブランドとの対応）

- **招く**：招き猫は福を招く縁起物。駅は人を迎え入れ、街・地域へ招く玄関。Suica Renaissanceが「移動から生活・地域へ」広がることと重なる。
- **前足のタッチ**：招き猫の上げた前足は、改札でカードをタッチする仕草に重なる。招く＝迎える＝タッチ。
- **駅猫文化**：「駅長猫」（たま・ニタマ）など、駅と猫は実際に深い縁がある。猫は駅に「いてほしい」存在。
- **癒し**：気ままな猫の存在は、通勤の疲れをほどく。

## 語る一点（物語）

駅前のロータリーに、白い猫が一匹。Suicaグリーンの首輪を揺らして、前足をちょんと上げる。通りかかる人に「おいで」と招き、街の奥へ案内する。カードをタッチするあなたにも、今日もそっと前足を上げて招く。

- 上げた前足＝改札のタッチの仕草（＝招く）。
- Suicaグリーンの首輪＝ブランドカラーを身に着ける。
- 長いしっぽ＝街へつながる道のライン。

## 使用シーン（イメージボードの小パネルで描く）

> ※ 実際のSuicaカードでは、キャラはカード面の**右端**に、**やや小ぶりに**印刷される（既存ペンギンを置き換え）。

1. 駅前のロータリーで、招き猫のように片手を上げて人を招く。
2. 改札の横で、カードをタッチする人の足元に、ちょこんと座る。
3. 夕方の駅前で、帰宅する人に「おかえり」の代わりに前足を上げる。

## 期待する雰囲気

気ままで、愛嬌があり、ほどよい距離感。丸い体・上げた前足・長いしっぽ。かわいさは「招く仕草」と「ツンとした気ままさ」。日本の交通系マスコットの「やわらかい平塗り」で、光沢やグラデは使わない。
