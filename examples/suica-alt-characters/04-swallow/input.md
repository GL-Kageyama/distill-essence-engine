# 入力：Suicaオルタナティブ案④ ツバメ「ツバメ」（見送る・いってらっしゃい）

> 対象: 架空のSuica新イメージキャラクター候補（非公式・本投票3案とは別の、あり得たかもしれない案）。既存キャラ（ペンギン・リス・ウサギ・モグラ）の模倣を避けた独自案。

## キャラクターの骨格

| 項目 | 内容 |
|---|---|
| モチーフ | ツバメ（燕）。駅の軒に巣を作り、毎年春に同じ場所へ戻ってくる渡り鳥 |
| 通称案 | 「ツバメ」（＝燕。駅と人との「縁（えん）」を結ぶ） |
| 体色 | Suicaグリーンの燕尾（二股の尾）＋白い腹＋のど元のオレンジ（改札オレンジ） |
| 概念（動詞） | **見送る・迎える（いってらっしゃい）** |
| 性格 | キビキビして気配り上手。朝は「いってらっしゃい」、夜は「おかえり」と声をかける駅のホスト |

## なぜSuicaに合うか（ブランドとの対応）

- **見送る／迎える**：駅は「旅立ち」と「帰還」の場所。ツバメは駅の軒に巣を作り、毎日行き交う通勤客を「いってらっしゃい」と見送る──Suicaの「毎日のパートナー」をそのまま体現する。
- **燕尾**：ツバメの二股の尾は「燕尾服（＝駅長・ホストの礼服）」。Suicaグリーンの燕尾をまとうことで、駅の「もてなし役」になる。
- **必ず戻る**：ツバメは毎年同じ巣に戻る渡り鳥。どんな遠くからも「この駅へ帰ってくる」＝Suicaでいつもの駅へ。
- **スイスイ**：ツバメの飛翔は滑らかで速く、低空を一直線に滑る。Suicaの「スイスイ」の飛翔版。

## 語る一点（物語）

朝の改札、軒の巣から飛び立ったツバメが、ホームへ急ぐあなたの一歩先を、すっと低く飛んで見送る。夕方には同じ軒で待っていて、帰ってきたあなたを「おかえり」と迎える。二股のSuicaグリーンの燕尾が、空に「ピッ」の軌跡を描く。

- 二股のSuicaグリーンの燕尾＝改札の「ピッ」の余韻。
- のど元のオレンジ＝改札のオレンジ（JR東日本のアクセント）。
- 白い腹＝ホームの安全ライン。

## 使用シーン（イメージボードの小パネルで描く）

> ※ 実際のSuicaカードでは、キャラはカード面の**右端**に、**やや小ぶりに**印刷される（既存ペンギンを置き換え）。

1. 朝の改札で、カードをタッチする人の肩の上を、低く飛んで見送る。
2. 駅の軒（ホームの屋根）の巣から、行き交う人を見下ろす。
3. 夕方、駅前のロータリーで帰宅する人を迎える。

## 期待する雰囲気

軽快で、気配りが行き届いたホストのよう。すらりと細い翼と、二股の尾。かわいさは「素早くも健気な飛翔」と「見送る仕草」。日本の交通系マスコットの「やわらかい平塗り」で、光沢やグラデは使わない。
