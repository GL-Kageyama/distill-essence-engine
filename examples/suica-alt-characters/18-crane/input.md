# 入力：Suicaオルタナティブ案⑱ ツル「ツル」（祈る・無事を祈る）

> 対象: 架空のSuica新イメージキャラクター候補（非公式・本投票3案とは別の、あり得たかもしれない案）。既存キャラ（ペンギン・リス・ウサギ・モグラ）の模倣を避けた独自案。

## キャラクターの骨格

| 項目 | 内容 |
|---|---|
| モチーフ | ツル（鶴）。日本の縁起物の筆頭。折り鶴は「無事・願い」の象徴。細い脚で静かに佇む |
| 通称案 | 「ツル」 |
| 体色 | 白い体＋Suicaグリーンの首元のリボン＋黒い長い脚＋小さな目 |
| 概念（動詞） | **祈る・無事を祈る** |
| 性格 | 静かで優雅。片足でじっと立ち、旅立つ人を無事に見送る |

## なぜSuicaに合うか（ブランドとの対応）

- **折り鶴＝無事**：折り鶴は「無事に帰る」という願いの象徴。改札で見送る鶴は、今日もあなたの安全を祈る。
- **縁起物**：鶴は日本で最も親しまれる縁起物。Suicaの「25年の安心」を、静かな佇まいで体現する。
- **片足立ち＝待つ**：片足でじっと立つ姿は、改札のそばで帰りを待つ「待つ」姿勢そのもの。
- **長いくちばし＝タッチ**：長いくちばしで、カードにそっと「ピッ」とタッチする仕草。

## 語る一点（物語）

駅の片隅に、白いツルが一羽、片足で静かに立っている。出発する人を長いくちばしでそっと見送り、帰る人をじっと待つ。首元のSuicaグリーンのリボンが、風にそっと揺れる。折り鶴に込めた「無事に帰って」が、今日も改札に漂っている。

- 折り鶴＝「無事に帰る」という願い。
- 片足立ち＝改札で待つ姿。
- 首元のリボン＝Suicaグリーンの縁起物。

## 使用シーン（イメージボードの小パネルで描く）

> ※ 実際のSuicaカードでは、キャラはカード面の**右端**に、**やや小ぶりに**印刷される（既存ペンギンを置き換え）。

1. 改札のそばで、片足で立って出発を見送る。
2. 折り鶴のモチーフを添えて、無事の祈りを届ける。
3. ホームの端で、静かに列車を待つ。

## 期待する雰囲気

静かで、優雅で、祈るような佇まい。白い体・細い脚・長いくちばし・Suicaグリーンのリボン。かわいさは「見送る静けさ」と「無事を願う健気さ」。日本の交通系マスコットの「やわらかい平塗り」で、光沢やグラデは使わない。
