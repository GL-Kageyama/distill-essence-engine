# 入力：Suicaオルタナティブ案③ カエル「カエル」（帰る・おかえり）

> 対象: 架空のSuica新イメージキャラクター候補（非公式・本投票3案とは別の、あり得たかもしれない案）。既存キャラ（ペンギン・リス・ウサギ・モグラ）の模倣を避けた独自案。

## キャラクターの骨格

| 項目 | 内容 |
|---|---|
| モチーフ | カエル（蛙）。「カエル＝帰る」。どんなに遠くへ行っても、ちゃんと帰れる存在 |
| 通称案 | 「カエル」（＝帰る／おかえり。名前そのものが帰宅を願う） |
| 体色 | スイカグリーンの体＋白い腹＋ほっぺたの桜色 |
| 概念（動詞） | **帰る・おかえり** |
| 性格 | おっとり。飛び跳ねるときだけ一瞬速い。雨の日が好き。家に着くと「ほっ」と一息 |

## なぜSuicaに合うか（ブランドとの対応）

- **帰る**：Suicaは「家に帰るためのカード」。終電に乗って、雨の日も、今日も無事に「おかえり」と帰り着く。カエルの鳴き声「ケロケロ」＝「帰ろ、帰ろ」。
- **スイカグリーン**：カエルの体色そのものがSuicaグリーン。ブランドカラーを体そのものが持つ（案①カワセミと同型）。
- **雨の日もスイスイ**：カエルは水をスイスイ泳ぎ、雨の日も平気。梅雨の通勤・帰宅に寄り添う。
- **タッチ＝吸盤**：カエルの指先の吸盤は、改札にぴたっと吸い付く「タッチ」の仕草に重なる。

## 語る一点（物語）

一日の終わり、ホームの水たまり（＝雨の日のホーム）に映った自分と一瞬目が合う。あなたが「ただいま」と言うまで、カエルは静かに隣をぴょこぴょこ跳ねて帰る。終電＝夜の帰り道を守る。

- 大きなまんまるの目は「おかえり」を見つめる暖かさ。
- ほっぺたの桜色は、帰宅の「ほっ」とした温かさ。
- 指先の小さな吸盤は「改札タッチ」の仕草。

## 使用シーン（イメージボードの小パネルで描く）

> ※ 実際のSuicaカードでは、キャラはカード面の**右端**に、**やや小ぶりに**印刷される（既存ペンギンを置き換え）。

1. カードの上にちょこんと座る。
2. 雨の日の改札で、傘の下から顔を出す。
3. 家のドアの前で「おかえり」と出迎える（＝カードをかざすと、ふわっと温かい）。

## 期待する雰囲気

温かく、静かで、安心。丸い体・大きなまんまるの目・長い後ろ足。かわいさは「見上げる瞳」と「帰りを待つ健気さ」。日本の交通系マスコットの「やわらかい平塗り」で、光沢やグラデは使わない。
