# 入力：Suicaオルタナティブ案⑬ チョウ「チョウ」（巡る・街を巡る）

> 対象: 架空のSuica新イメージキャラクター候補（非公式・本投票3案とは別の、あり得たかもしれない案）。既存キャラ（ペンギン・リス・ウサギ・モグラ）の模倣を避けた独自案。

## キャラクターの骨格

| 項目 | 内容 |
|---|---|
| モチーフ | チョウ（蝶）。花から花へひらひら巡る。旅・変身・自由の象徴 |
| 通称案 | 「チョウ」（＝蝶。街をひらひら巡る） |
| 体色 | Suicaグリーンの羽＋白い斑点＋黒い体 |
| 概念（動詞） | **巡る・旅する（街を巡る）** |
| 性格 | 気ままにひらひら。駅から駅へ、街から街へ、自由に巡る |

## なぜSuicaに合うか（ブランドとの対応）

- **巡る**：蝶は花から花へ巡る。Suicaは駅から駅へ、街から街へ巡るカード。移動の自由＝巡る喜び。
- **変身**：蝶は芋虫から蛹、そして羽化する「変身」。Suica Renaissanceが「移動カードから生活デバイスへ」変わることと重なる。
- **ひらひら＝スイスイ**：蝶の羽ばたきは軽やかで滑らか。Suicaの「スイスイ」の軽やかさ。
- **羽の緑**：Suicaグリーンの羽を広げる。ブランドカラーを羽そのものが持つ。

## 語る一点（物語）

改札を抜けると、緑の羽の蝶がひらひらと先を飛ぶ。駅から駅へ、街から街へ、あなたの行きたい場所へ。花を巡るように、路線を巡る。Suicaグリーンの羽が、軽やかに次の街を指し示す。

- Suicaグリーンの羽＝ブランドカラーを羽そのものが持つ。
- 白い斑点＝路線図の駅（＝停まる場所）。
- ひらひら巡る＝路線を巡る移動の自由。

## 使用シーン（イメージボードの小パネルで描く）

> ※ 実際のSuicaカードでは、キャラはカード面の**右端**に、**やや小ぶりに**印刷される（既存ペンギンを置き換え）。

1. 改札を抜けた先で、緑の羽をひらひらさせて先を巡る。
2. 駅のホームの花壇（＝街）の上を、軽やかに飛ぶ。
3. 観光地の駅前で、行きたい場所へ案内するように舞う。

## 期待する雰囲気

軽やかで、自由で、爽やか。大きく広げた羽・細い体・優雅な舞い。かわいさは「ひらひらした羽ばたき」と「巡る自由」。日本の交通系マスコットの「やわらかい平塗り」で、光沢やグラデは使わない。
