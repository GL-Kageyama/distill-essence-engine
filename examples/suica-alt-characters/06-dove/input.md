# 入力：Suicaオルタナティブ案⑥ ハト「ポッポ」（伝える・想いを伝える）

> 対象: 架空のSuica新イメージキャラクター候補（非公式・本投票3案とは別の、あり得たかもしれない案）。既存キャラ（ペンギン・リス・ウサギ・モグラ）の模倣を避けた独自案。

## キャラクターの骨格

| 項目 | 内容 |
|---|---|
| モチーフ | ハト（鳩）。伝書鳩として遠くまで想いを運び、必ず巣へ帰る。駅前に必ずいる一番身近な鳥 |
| 通称案 | 「ポッポ」（＝鳩の鳴き声。誰でも呼べる、親しみの名前） |
| 体色 | 柔らかいグレー／白の体＋首元のSuicaグリーンのリボン＋くわえた小さな手紙 |
| 概念（動詞） | **伝える・届ける（想いを伝える）** |
| 性格 | 穏やかで人懐っこい。駅前で待ち合わせる人、手紙を出す人にそっと寄り添う |

## なぜSuicaに合うか（ブランドとの対応）

- **伝える／届ける**：伝書鳩は遠く離れた場所まで、必ず想いを届けて戻る。Suicaは「移動のためのカード」から「想い・価値を運ぶデバイス」へ（Suica Renaissance）──その「運ぶ」を体現する。
- **必ず帰る**：伝書鳩はどんな遠くからも巣へ帰る帰巣本能。カエル「おかえり」の対として、「届けて、ちゃんと帰ってくる」。
- **駅前のハト**：老若男女が知る、駅前の日常風景。Suicaの「誰にでも親しまれる」をそのまま体現する。
- **平和・安心**：白い鳩＝平和。移動の平穏と安全の象徴。

## 語る一点（物語）

駅前の広場。伝書鳩のポッポが、Suicaグリーンのリボンを首に結び、小さな手紙（＝いつものSuicaカード）をくわえて飛び立つ。遠くの街へ想いを届け、ちゃんとこの駅へ帰ってくる。くわえた手紙は、タッチのたびに交わされる「行ってきます／ただいま」。

- Suicaグリーンのリボン＝首に結んだ「想いの届け先」。
- くわえた小さな手紙＝Suicaカード（＝伝えたい気持ち）。
- 白い羽＝平和・安全な移動。

## 使用シーン（イメージボードの小パネルで描く）

> ※ 実際のSuicaカードでは、キャラはカード面の**右端**に、**やや小ぶりに**印刷される（既存ペンギンを置き換え）。

1. 駅前のロータリーで、手紙（カード）をくわえて飛び立とうとする。
2. 改札のそばで、伝書鳩のようにじっと待ち合わせる。
3. 夕方の駅前で、帰宅する人の肩のそばに降り立つ。

## 期待する雰囲気

穏やかで、人懐っこく、どこかレトロ。ふっくらした体・首のリボン・くわえた手紙。かわいさは「身近さ」と「想いを運ぶ健気さ」。日本の交通系マスコットの「やわらかい平塗り」で、光沢やグラデは使わない。
