# 入力：Suicaオルタナティブ案㊲ ウマ「ウマ」（すすむ・はしる）

> 対象: 架空のSuica新イメージキャラクター候補（非公式・本投票3案とは別の、あり得たかもしれない案）。既存キャラ（ペンギン・リス・ウサギ・モグラ）の模倣を避けた独自案。

## キャラクターの骨格

| 項目 | 内容 |
|---|---|
| モチーフ | ウマ。駿馬。二足で立つ（立ちキャラ）。四本足で、前足が腕になる |
| 通称案 | 「ウマ」 |
| 体色 | やわらかい鹿毛（栗毛の茶）＋白いたてがみ・尾 |
| 概念（動詞） | **すすむ・はしる** |
| 性格 | 軽やかで、まっすぐ、前に進む |

## なぜSuicaに合うか（ブランドとの対応）

- **すすむ＝前進**：駿馬は軽やかに前へ駆ける。通勤＝毎日の前進に寄り添う。
- **駿馬＝縁起**：馬は成功・出世の縁起物。まっすぐ駆けて、先へ進む。
- **茶＝木・大地**：鹿毛の茶は、木や大地の自然色。緑と自然に調和する。
- **立ちキャラ＝IP展開**：前足が腕になるので、駆けるポーズやカードを持つ仕草を取らせやすい。たてがみが特徴で、ぬいぐるみ・キーホルダーに載せやすい。

## 語る一点（物語）

鹿毛のウマが、二足で立ち、軽やかに駆ける。たてがみをなびかせ、まっすぐ前へ。腕の手でそっと「ピッ」。今日も、あなたの前進を、軽やかに応援する。

- すすむ＝毎日の前進、軽やかに駆ける。
- 鹿毛の茶＝木・大地の自然色。
- 腕の手＝改札のタッチ。

## 使用シーン（イメージボードの小パネルで描く）

> ※ 実際のSuicaカードでは、キャラはカード面の**右端**に、**やや小ぶりに**印刷される（既存ペンギンを置き換え）。

1. 軽やかに駆け出して、まっすぐ前へ。
2. 腕の手で、カードをそっとタッチする。
3. 前へ進むのを、軽やかに見送る。

## 期待する雰囲気

軽やかで、まっすぐで、前進の健気さ。鹿毛の茶の体・白いたてがみ・尾・腕の手。かわいさは「まっすぐ前に進む健気さ」。**立ちキャラ（二足で直立）**で、腕でポーズを取らせやすい。日本の交通系マスコットの「やわらかい平塗り」で、光沢やグラデは使わない。
