# 入力：Suicaオルタナティブ案⑤ フクロウ「フク」（守る・夜を守る）

> 対象: 架空のSuica新イメージキャラクター候補（非公式・本投票3案とは別の、あり得たかもしれない案）。既存キャラ（ペンギン・リス・ウサギ・モグラ）の模倣を避けた独自案。

## キャラクターの骨格

| 項目 | 内容 |
|---|---|
| モチーフ | フクロウ（梟）。夜行性の森の守り手。「不苦労」「福」の縁起物 |
| 通称案 | 「フク」（＝福／不苦労。苦労なくスイスイ帰れる） |
| 体色 | 温かい茶／グレーの体＋Suicaグリーンのマント＋大きな黄色い目（終電のヘッドライト） |
| 概念（動詞） | **守る・見通す（夜を守る）** |
| 性格 | 夜に強く、物静かで頼りになる。終電が終わるまでじっと見守る、夜の駅長 |

## なぜSuicaに合うか（ブランドとの対応）

- **不苦労**：フクロウは「不苦労」＝苦労しない＝スイスイ。通勤の「苦労」を、終電まで寄り添ってほどいてくれる縁起物。
- **夜行性＝終電**：フクロウは夜に活動する。Suicaを使う「夜の帰り道」「終電」の時間帯を、丸い目で見守る。
- **見通す**：フクロウは首がほぼ一回り回り、暗闇を見通す。乗り換え・遅延・出口を「見通して」安心をくれる。
- **大きな黄色い目＝終電のライト**：暗いホームに灯る、行先を照らす光。夜の改札に安心をともす。

## 語る一点（物語）

終電が近づく夜の改札。フクロウがSuicaグリーンのマントをまとって、黄色い大きな目で最後の一人まで見守る。首をぐるりと回して、ホームの隅も、改札の向こうも「見通す」。帰り道が闇に沈まないように、目を灯す。

- 大きな黄色い目＝終電・ホームを照らすヘッドライト。
- Suicaグリーンのマント＝夜の見張り番の制服。
- 首を回す＝乗り換え・出口・遅延を「見通す」。

## 使用シーン（イメージボードの小パネルで描く）

> ※ 実際のSuicaカードでは、キャラはカード面の**右端**に、**やや小ぶりに**印刷される（既存ペンギンを置き換え）。

1. 夜の終電の改札で、最後の一人までカードのタッチを見守る。
2. ホームの柱に止まって、行先表示を黄色い目で照らす。
3. 帰宅後の玄関で、充電するカードのそばにじっと寄り添う。

## 期待する雰囲気

静かで、頼りになり、夜に暖かい。丸い体・大きな黄色い目・マントのたすき。かわいさは「丸さ」と「じっと見守る安心感」。日本の交通系マスコットの「やわらかい平塗り」で、光沢やグラデは使わない。
