# 入力：Suicaオルタナティブ案㉔ カニ「カニ」（寄り道でも、ちゃんと着く）

> 対象: 架空のSuica新イメージキャラクター候補（非公式・本投票3案とは別の、あり得たかもしれない案）。既存キャラ（ペンギン・リス・ウサギ・モグラ）の模倣を避けた独自案。

## キャラクターの骨格

| 項目 | 内容 |

| モチーフ | カニ。横歩き＝まっすぐ急がなくても、ちゃんと着く |
| 通称案 | 「カニ」 |
| 体色 | やわらかい赤（朱）の丸い体＋大きなハサミ＋小さな目 |
| 概念（動詞） | **寄り道でも、ちゃんと着く** |

## なぜSuicaに合うか（ブランドとの対応）

- **横歩き＝寄り道**：カニの横歩きは「まっすぐ急がなくても、ちゃんと着く」。寄り道しても大丈夫、という安心。
- **赤＝縁起**：カニは赤＝めでたい縁起物。お祝いの色。
- **のんびり＝焦らない**：急がない、回り道でも着く、という穏やかさ。
- **ハサミ＝タッチ**：ハサミで、カードをそっと挟んでタッチする仕草そのもの。

## 語る一点（物語）

赤いカニが、駅のそばを、横歩きでゆっくり進む。まっすぐじゃなくても、急がなくても、ちゃんと今日の帰り道に着く。ハサミでそっとカードを挟んで「ピッ」。寄り道しても、ちゃんと着く。

- 横歩き＝寄り道＝急がなくていい。
- 赤＝めでたい縁起。
- ハサミ＝改札のタッチ。

## 使用シーン（イメージボードの小パネルで描く）

> ※ 実際のSuicaカードでは、キャラはカード面の**右端**に、**やや小ぶりに**印刷される（既存ペンギンを置き換え）。

1. 駅のそばを、横歩きでゆっくり進む。
2. ハサミで、カードをそっと挟んでタッチする。
3. 改札のそばで、のんびりと帰りを待つ。

## 期待する雰囲気

のんびりで、穏やかで、寄り道の安心。赤い丸い体・ハサミ・横歩き。かわいさは「急がなくていい安心」と「ゆったりした健気さ」。日本の交通系マスコットの「やわらかい平塗り」で、光沢やグラデは使わない。
