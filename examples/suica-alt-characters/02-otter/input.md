# 入力：Suicaオルタナティブ案② カワウソ「モチ」（つながる・手をつなぐ）

> 対象: 架空のSuica新イメージキャラクター候補（非公式・本投票3案とは別の、あり得たかもしれない案）。既存キャラ（ペンギン・リス・ウサギ・モグラ）の模倣を避けた独自案。

## キャラクターの骨格

| 項目 | 内容 |
|---|---|
| モチーフ | カワウソ（川獺）。水の中をスイスイ泳ぎ、仲間と手をつないで眠る |
| 通称案 | 「モチ」（＝もちもちの触り心地／抱えた小石のように大切な存在） |
| 体色 | 温かい焦げ茶＋白い胸・鼻まわり＋スイカグリーンのマフラー（カードホルダー） |
| 概念（動詞） | **つなぐ・手をつなぐ** |
| 性格 | のんびりだけど要所は確実。おしゃべりで寂しがり屋。初対面でも「ねえねえ」と声をかける |

## なぜSuicaに合うか（ブランドとの対応）

- **つながり**：カワウソは眠るときに**互いの手をつないで流されないようにする**（実在の習性）。これは「Suica Renaissance」が目指す「人・都市・地域・日常をつなぐ」ことそのもの。
- **スイスイ**：カワウソは水の中を滑るようにスイスイ泳ぐ。ペンギンと同じ「水のスイスイ」の系譜を、哺乳類として引き継ぐ。
- **抱えた小石**：カワウソにはお気に入りの小石をポケットに入れて持ち歩く習性がある。その「いつも肌身離さない小石」＝Suicaカード、という対応。
- **緑のマフラー**：体は茶色でも、身に着けたSuicaグリーンのマフラーでブランドカラーをまとう（＝色を「持つ」のではなく「まとう」キャラ）。

## 語る一点（物語）

街の水路（＝路線）をスイスイ泳いで、駅で降りた人と**手をつなぎ**、次の駅へ。胸に抱えたつるつるの小石は、いつも肌身離さないSuica。眠るときも、その手を離さない。

- 手にはいつも**つるつるの小石（＝Suicaカード）を一つ**。
- しっぽは長く、水路＝線路のラインを描く。
- 眠るとき、仲間（＝隣の人）の手を握って流されない──「つながり」の象徴。

## 使用シーン（イメージボードの小パネルで描く）

> ※ 実際のSuicaカードでは、キャラはカード面の**右端**に、**やや小ぶりに**印刷される（既存ペンギンを置き換え）。

1. 改札の横で、両手でカード（小石）を差し出す。
2. 財布／スマホケースの端から、眠そうに顔だけ出す。
3. 夜、眠るようにカードを胸に抱えて休む（＝充電＝一休み）。

## 期待する雰囲気

温かく、柔らかく、少し眠たげ。丸い長い胴体・小さい耳・丸い鼻。かわいさは「もふっとした安心感」と「手をつなぐ仕草」。日本の交通系マスコットの「やわらかい平塗り」で、光沢やグラデは使わない。
