# 入力：Suicaオルタナティブ案⑫ カピバラ「カピ」（癒す・ほっとひと息）

> 対象: 架空のSuica新イメージキャラクター候補（非公式・本投票3案とは別の、あり得たかもしれない案）。既存キャラ（ペンギン・リス・ウサギ・モグラ）の模倣を避けた独自案。

## キャラクターの骨格

| 項目 | 内容 |
|---|---|
| モチーフ | カピバラ（水豚）。世界最大の齧歯類で、穏やかで動じない。温泉に浸かる姿が人気の癒しの象徴 |
| 通称案 | 「カピ」（＝カピバラの愛称。ほっとひと息） |
| 体色 | 温かい茶＋白い腹・鼻まわり＋Suicaグリーンの首元のバンダナ |
| 概念（動詞） | **癒す・和む（ほっとひと息）** |
| 性格 | 穏やかで、何があっても動じない。通勤の合間に、ほっとひと息つかせてくれる |

## なぜSuicaに合うか（ブランドとの対応）

- **癒し**：カピバラは温泉に浸かる姿が象徴的な「癒し」。通勤・帰宅の疲れを、ほっとひと息でほどく。Suicaが毎日寄り添う「生活のデバイス」としての温かさ。
- **動じない**：どんなに混雑した駅でも、マイペースで穏やか。行列も、遅延も、そっと和ませる。
- **のんびり＝安心**：焦らない＝安全。忙しい移動のなかに、ほっとできる余白をくれる。
- **バンダナの緑**：体は茶色でも、Suicaグリーンの首元バンダナでブランドカラーをまとう（マフラー・マント・首輪と同じ「まとう」型）。

## 語る一点（物語）

混雑した改札を抜けた先に、カピがいる。Suicaグリーンのバンダナをゆらゆら揺らして、温泉に浸かるみたいに、のんびりと座っている。その姿を見ると、今日の疲れがふっと抜けて、また一歩、歩き出せる。

- Suicaグリーンのバンダナ＝ブランドカラーをまとう。
- のんびり座る姿＝通勤の合間の「ほっとひと息」。
- 穏やかな目＝動じない安心感。

## 使用シーン（イメージボードの小パネルで描く）

> ※ 実際のSuicaカードでは、キャラはカード面の**右端**に、**やや小ぶりに**印刷される（既存ペンギンを置き換え）。

1. 駅のベンチのそばで、のんびり座って人を和ませる。
2. 改札を抜けた広場で、ほっとひと息つく人のとなりに座る。
3. 帰宅前、コンビニのそばで、疲れた人に「おつかれさま」と寄り添う。

## 期待する雰囲気

穏やかで、のんびりで、温かい。丸い大きな体・小さな耳・穏やかな目。かわいさは「動じない穏やかさ」と「和ませる存在感」。日本の交通系マスコットの「やわらかい平塗り」で、光沢やグラデは使わない。
