# 入力：Suicaオルタナティブ案㉗ ハチドリ「ハチドリ」（立ち止まる・空中で静止する）

> 対象: 架空のSuica新イメージキャラクター候補（非公式・本投票3案とは別の、あり得たかもしれない案）。既存キャラ（ペンギン・リス・ウサギ・モグラ）の模倣を避けた独自案。

## キャラクターの骨格

| 項目 | 内容 |
|---|---|
| モチーフ | ハチドリ。空中でぴたりと静止（ホバリング）できる小鳥。緑の羽 |
| 通称案 | 「ハチドリ」 |
| 体色 | やわらかい緑の羽（Suicaの緑そのものの自然色）＋白い腹＋細いくちばし |
| 概念（動詞） | **立ち止まる・空中で静止する** |
| 性格 | 小さくて、軽やかで、でも一瞬立ち止まれる |

## なぜSuicaに合うか（ブランドとの対応）

- **緑＝Suica緑**：ハチドリの緑の羽は、Suicaの緑そのものの自然色。カードに並ぶと、そのまま馴染む。
- **静止＝立ち止まる**：ハチドリは空中でぴたりと静止できる＝忙しい毎日のなかで、一瞬立ち止まって深呼吸する。
- **花から花へ＝駅から駅へ**：花から花へ飛ぶ姿＝駅から駅へ移動する人。
- **くちばし＝タッチ**：長く細いくちばしで、カードをそっとタッチする仕草そのもの。

## 語る一点（物語）

緑のハチドリが、空中でぴたりと止まっている。忙しく飛び回る合間に、一瞬立ち止まって、花＝駅のそばでほっとひと息。細いくちばしでそっと「ピッ」。今日も、立ち止まる余白を、そっとくれる。

- 緑の羽＝Suica緑そのものの自然色。
- 静止＝立ち止まる余白。
- くちばし＝改札のタッチ。

## 使用シーン（イメージボードの小パネルで描く）

> ※ 実際のSuicaカードでは、キャラはカード面の**右端**に、**やや小ぶりに**印刷される（既存ペンギンを置き換え）。

1. 空中でぴたりと静止して、一瞬立ち止まる。
2. 細いくちばしで、カードをそっとタッチする。
3. 駅のそばで、静かに静止して見送る。

## 期待する雰囲気

小さくて、軽やかで、立ち止まる静けさ。緑の羽・白い腹・細いくちばし。かわいさは「立ち止まる余白の健気さ」。日本の交通系マスコットの「やわらかい平塗り」で、光沢やグラデは使わない。
