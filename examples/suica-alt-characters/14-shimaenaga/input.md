# 入力：Suicaオルタナティブ案⑭ シマエナガ「シマ」（弾む・気分が弾む）

> 対象: 架空のSuica新イメージキャラクター候補（非公式・本投票3案とは別の、あり得たかもしれない案）。既存キャラ（ペンギン・リス・ウサギ・モグラ）の模倣を避けた独自案。

## キャラクターの骨格

| 項目 | 内容 |
|---|---|
| モチーフ | シマエナガ（島柄長）。ふわふわの白い体と長い尾の「雪の妖精」。小さくて丸くて大人気 |
| 通称案 | 「シマ」（＝シマエナガの愛称。ぴょこぴょこ弾む） |
| 体色 | 白いふわふわの体＋Suicaグリーンの小さなマフラー＋黒いまんまる目＋ピンクの頬 |
| 概念（動詞） | **弾む・軽やかに跳ねる（気分が弾む）** |
| 性格 | 小さくて活発。ぴょこぴょこ跳ねて、見ているだけで気分が弾む |

## なぜSuicaに合うか（ブランドとの対応）

- **弾む**：シマエナガは小さな体でぴょこぴょこ跳ねる。その愛らしさで、通勤の気分が「弾む」。移動が楽しくなる。
- **ふわっと＝軽やか**：雪の妖精のようにふわっと軽やか。Suicaの「スイスイ」の軽やかさ。
- **白＝安心**：白くふわふわの体は、清潔で安心な移動の象徴。Suicaグリーンのマフラーでブランドカラーをまとう。
- **人気**：シマエナガは写真集・グッズで全国的な人気。老若男女に「かわいい」と愛される。

## 語る一点（物語）

ホームの端に、白くて丸い小さな影がぴょこぴょこ。シマエナガがSuicaグリーンのマフラーを揺らして跳ねると、そのたびにあなたの気分も弾む。長い尾が、線路の先へ軽やかに揺れる。

- 白いふわふわの体＝清潔で安心な移動。
- Suicaグリーンのマフラー＝ブランドカラーをまとう。
- ぴょこぴょこ跳ねる＝気分が弾む。

## 使用シーン（イメージボードの小パネルで描く）

> ※ 実際のSuicaカードでは、キャラはカード面の**右端**に、**やや小ぶりに**印刷される（既存ペンギンを置き換え）。

1. 朝のホームで、ぴょこぴょこ跳ねて人を元気にする。
2. 改札の上で、カードをタッチする人に軽やかに寄り添う。
3. 駅前で、待ち合わせる人の肩の上にふわっと乗る。

## 期待する雰囲気

小さくて、ふわふわで、活発。丸い体・長い尾・まんまるの目。かわいさは「ぴょこぴょこ弾む愛らしさ」。日本の交通系マスコットの「やわらかい平塗り」で、光沢やグラデは使わない。
