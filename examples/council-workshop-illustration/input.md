# 入力：知恵の評議会の5つの道具（リポジトリ群）

> 対象: `AI評価者たちによる「知恵の評議会」/` 配下の5リポジトリ。各 README から本質を抽出した入力スロット。

親ディレクトリは「AI評価者たちによる『知恵の評議会』」＝多声で価値を見抜く評議会が屋台骨。

## 1. soul-voice-teller（書く側）

「書くことは魂を運ぶこと」を旨とする小説執筆スキル群（19スキル）。
**人間が作者・AIは起草装置・personaは作者の鏡**。作者の魂・声・禁じ手・美学を persona に映し、voice-ledger に声を蓄積して読み返す。「著者（人間）の魂を運ぶ」。

## 2. elevate-draft-engine（磨く側）

複数のAIに独立した視点から答えを書かせ衝突させて、**どの単一視点も持たない一段高い答え**を生む。
**DIVERGE（8人の創作者＝strategist／differentiator／humanist／futurist／designer／visionary／implementer／storyteller が独立に極端へ分岐）→ SYNTHESIZE（止揚＝否定・保存・高次化）**。

## 3. wisdom-council-layer（見抜く側・価値）

生成AI時代に「作る能力」でなく「真に価値あるものを見抜く能力」が希少になった。
複数の評価者が別々の視点で多声評価し、**相違は平均せずそのまま保存**（disagreement is a signal）。反通俗（anti-generic）。評価は生成と分離。

## 4. novel-council-layer（見抜く側・小説）

小説評議会。物語の濁流から「読む価値のある物語」を見抜く。
**物語は時間の中で読まれる**（時間の質・情報の分布・語り手の距離・余白の設計・文体と時間の一致・再読の深さ・読後変位の7問）。wisdom-council の姉妹プロジェクトとして同じ多声方式・評価基準は小説独自。

## 5. distill-essence-engine（蒸留する側）

あらゆる入力（小説・記事・詩・文字起こし・メモ・論文・URL）の本質を、**一枚の画像プロンプトへ蒸留する**汎用変換エンジン。多→一。フォーマット×様式の2軸で指定するだけ。
