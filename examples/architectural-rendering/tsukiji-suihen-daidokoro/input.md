# 築地市場跡地再開発・オルタナティブ提案《水辺の台所》

> 本提案は**設計案（オルタナティブ・ビジョン）**であり、法的手続きの評価や現計画の違法性判断を行うものではない。現状の要件・問題・「本来あるべき姿」を、設計言語へ翻訳した「あり得たかもしれない」計画案である。

## 現状の計画（要件）

- 事業者：築地まちづくり株式会社（三井不動産・トヨタ不動産・読売新聞グループ本社）
- 所在地：中央区築地五丁目・六丁目。都有地 約19万㎡（東京ドーム約4個分）、70年定期借地権（年間貸付料約100億円超）
- 総延床面積 約126万㎡、総事業費 約9,000億円、開業 2030年代前半（2032年度完成目標）
- 8〜9棟構成：5万人収容の多目的スタジアム（約40〜110m）／ライフサイエンス・商業複合棟（約190m）／MICE・ホテル・レジデンス棟（約210m）／オフィス棟（約210m）／レジデンス棟（約180m）／ホテル棟×2（約150m）／舟運・シアターホール複合棟（約50m）ほか
- コンセプト「ONE PARK×ONE TOWN」。デザインモチーフは旧築地市場の「扇」。陸海空のモビリティハブ（舟運・ヘリポート・空飛ぶクルマ）。敷地4割緑化

## 現状の計画が抱える問題

1. **本質の転倒**：築地市場は83年間「日本の台所」だった。小池都知事は「築地は守る」「食のテーマパーク機能を有する市場」と公約したが、後に「選択肢の一つ」と後退。計画の核は5万人スタジアムと超高層オフィス・レジデンスになり、食文化は「フードホール」程度に矮小化された。
2. **超高層化**：190〜210mの超高層ビル群は海風を遮り、ヒートアイランドを悪化させ、下町のスケールと静けさを壊す。
3. **読売・巨人軍の思惑**：読売グループ参加により、スタジアムは巨人の新本拠地、東京ドーム跡地は高級マンションになるのではと広く報道（読売側は「移転を前提とした計画ではない」と否定）。
4. **手続きへの疑義**：対抗馬が失格となった「出来レース」疑惑、1㎡月4497円という低額貸付（不動産価値は20兆円超とも試算）、都幹部の三井不動産グループへの天下り報道（うち8人が都市整備局出身とされる）など。住民参加・公聴が不十分で、近隣住民の声が届いていない。

## 本来あるべき築地市場跡地再開発とは何か

築地市場の本質は**「日本の台所」＝働く水辺の市場**。敷地が扇形なのは、貨物列車と舟運（水と陸）から食を引き込むため——**食が水と陸から集まり、市（まち）へ広がる「台所」の形**だった。本来あるべき再開発とは、この「台所」＝**食と水と日常のスケール**を、超高層の「国際都市」でなく、水辺の日常として継承すること。

**核心＝「超高層をやめて、水辺の台所へ。」**

## 要件（R1〜R6）

| # | 要件 |
|---|---|
| R1 | 食文化の継承（「日本の台所」の記憶を、フードホールでなく実質として継承） |
| R2 | 水辺の開放（隅田川・築地川の水辺と浜離宮の緑を市民に開く） |
| R3 | 下町のスケールと景観（超高層をやめ、海風と静けさを守る） |
| R4 | 現実の機能（交通結節・防災・経済——ただし食・水・日常を主役に） |
| R5 | 民主的手続き（出来レース・公約反故への対抗として住民参加と透明性） |
| R6 | 成果物＝計画内容のイメージ図（必要なら複数枚可）＋イメージボード |

## 設計戦略（3戦略の合成）

3戦略はそれぞれ現計画の**別の「問題」を別のスケールで解く**ため、そのまま合成できる：

| 戦略 | 解く問題 | スケール | 由来 |
|---|---|---|---|
| ①低層・段状化（負ける建築） | 超高層が海風と下町を壊す | 高さ | 隈研吾「負ける建築」×インゲルス「読む丘」 |
| ②水辺の開放（水の洞窟） | 水辺が市民に閉ざされる | 水辺 | 伊東豊雄「水の洞窟」×ヌーヴェル「脱物質化」 |
| ③食の継承（市場の町） | 食文化がフードホールに矮小化 | 街路 | コールハース「密集のバザール」 |

- **①低層・段状化**：190〜210mの超高層をやめ、水辺へ向かって**段状に低くなる丘**（緑化屋根）に。海風が通り、下町のスケールを保つ。屋上は歩ける緑として浜離宮と連続。→ R3・R4
- **②水辺の開放**：隅田川・築地川の水辺を**市民に開く**。建築を水辺で「脱物質化」して水と緑を連続させ、舟運（食が水から来た記憶）と船着き場を活かす。→ R2・R4（「開かれた水辺」は手続きの開放性のメタファー）
- **③食の継承**：地上は**屋根のある市場の街路**——屋台・暖簾・提灯が連なる「市場の町」として、築地場外市場と連続する。スタジアムのにぎわいではなく、毎日の市場のにぎわいを。→ R1・R5

**固有×間接の一点**：築地の「扇」は、水と陸から食が集まる台所の形だった。その扇を、超高層のモチーフでなく、**水辺に開く低層の台所**として再生する。

## 概念の説明（イメージボードに載せる文）

**キャプション**：「超高層をやめて、水辺の台所へ。——築地に、扇の形のまま開く市場の町を。」

**説明**：築地市場は83年間、日本の台所でした。現計画はその本質を「国際競争力」「5万人スタジアム」「190〜210mの超高層」に置き換え、食文化をフードホールに矮小化しています。この提案は反転します——高さを負けて水辺へ段状に低くし（低層・段状）、隅田川と浜離宮の緑を市民に開き（水辺の開放）、地上は屋根のある市場の街路として場外市場と連続させます（食の継承）。築地の「扇」は水と陸から食が集まる台所の形——それを超高層でなく、水辺に開く台所として再生します。
