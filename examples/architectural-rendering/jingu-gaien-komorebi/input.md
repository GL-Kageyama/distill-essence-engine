# 神宮外苑再開発・オルタナティブ提案《木漏れ日の杜》

> 本提案は**設計案（オルタナティブ・ビジョン）**であり、法的手続きの評価や現計画の違法性判断を行うものではない。観点（風致と樹木の保全・手続的正義）を設計言語へ翻訳した「あり得たかもしれない」計画案である。

## 観点（call4.jp から）

「**100年の歴史と3000本超の樹木を未来へ**」——風致地区・神宮外苑の景観と環境を守り、次世代へ残す。あわせて**手続的正義**への異議：
1. **制度の濫用**＝「公園まちづくり制度」を逸脱適用して高層ビルを可能にした
2. **非科学的判断**＝環境アセスメントで必要な情報が提出されず、科学的議論が不十分
3. **非民主的決定**＝市民参加（公聴会・縦覧）がないまま非公開会議・秘密裏の風致地区変更で進行

観点の核心は「**木と歴史を、建築と手続きより上位に置く**」こと。

## 現状の実態（対立の構図）

- 現計画：神宮球場・秩父宮ラグビー場を建替え再配置＋高層ビル、**619本伐採**、2036年完了見込み
- いちょう並木 4列128本（健全 A ランクは52本のみ）、樹齢100年超のイチョウ18本（移植困難）
- ICOMOS ヘリテージ・アラート（2023、計画撤回要求）、坂本龍一ら反対、市民の約7割が伐採反対
- 訴訟継続中（2026年5月、住民側の伐採許可取消請求は「原告適格なし」で却下）

## 要件（R1〜R6）

| # | 要件 |
|---|---|
| R1 | 樹木・景観の保全（いちょう並木＋既存樹木を可能な限り残す） |
| R2 | 歴史・風致の継承（100年の景観、風致地区の性格を壊さない） |
| R3 | 現実の機能（球場の老朽化・耐震・再整備という実需に答える） |
| R4 | 民主的手続き（透明性・市民参加を計画に内在させる） |
| R5 | 手法＝alternative-design の「固有×間接」＋独自の思考 |
| R6 | 成果物＝計画内容のイメージ図（必要なら複数枚可）＋イメージボード |

## 設計戦略（3戦略の合成）

**核心＝「木を主役に、建築を従者に。」** 現計画の本質問題は「建築（高層ビル・球場）が主役で、木が従者」になっていること。提案はこれを反転する。

3戦略はそれぞれ現計画の**別の「問題」を別のスケールで解く**ため、そのまま合成できる：

| 戦略 | 解く問題 | スケール | 由来 |
|---|---|---|---|
| ①地中化（負ける建築） | 建築が「土地」を奪う | 地表 | 隈研吾「負ける建築」 |
| ②透明な膜（軽さ・透明化） | 建築が「視線と木」を遮る | 入口 | 妹島和世・西沢立衛（SANAA） |
| ③木と一体化（木・光の天蓋） | 屋根が「嵩（かさ）」として圧する | 屋根 | ヌーヴェル「光の雨」×隈「木漏れ日」 |

- **①地中化**：神宮球場・秩父宮ラグビー場のフィールドを**セミ地下（掘り込み式）**とし、観客席の上部は低い**緑の丘**に。地表レベルは連続する森・公園・いちょう並木のまま残す。**高層ビルは建てない**（風致地区の性格を守る）。→ R1・R2・R3
- **②透明な膜**：地上に姿を見せるのは、薄いガラスと白による**透明な入口＝ヴェール**のみ。森の間を縫う細いガラスの回廊が、木を遮らず地下の球場へ下りていく。建築は消える。→ R2・R4（「透明」は手続きの透明性の建築的メタファー）
- **③木と一体化**：球場を覆う屋根は**木の格子（ルーバー）の天蓋**。木漏れ日を床へ落とし、屋根そのものが「第二の林冠」となって木との境界を消す。→ R1・R2

## 概念の説明（イメージボードに載せる文）

**キャプション**：「木を主役に、建築を従者に。——神宮外苑に、森の下へ沈む球場を。」

**説明**：現計画は建築（高層ビル・球場）を主役にし、100年のいちょう並木と3000本の樹木を従者にしました。この提案はそれを反転します。球場を地中に沈めて地表を森に返し（地中化）、地上に現れるのは木を遮らない透明な入口だけにし（透明な膜）、屋根は木漏れ日を落とす木の天蓋にします（木と一体化）。建築は「負け」、木が100年後も主役であり続ける——伐採を最小にし、風致地区の景観を守り、それでいて球場を耐震・最新設備で再生する。地表の森は誰にでも開かれ、計画そのものが「見通せる」＝手続きの透明性を空間にしたものです。
