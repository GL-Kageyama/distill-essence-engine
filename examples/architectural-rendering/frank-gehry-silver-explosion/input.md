# 入力：フランク・ゲーリーの「あり得たかもしれない」作品（オルタナティブ・ヒストリー）

> 建築イメージの作例シリーズ第 8 弾。実在の建築家の作風を、実際には建てなかった建物種へ一歩延長して、その写真用プロンプトを作る。今回は**フランク・ゲーリー**。

## 前提（なぜ「天文台」か）

フランク・ゲーリーの設計思想の核は **「脱構築＝ボリュームの断片化と不規則なライン、ねじれた形状・歪んだ面・折り曲げられた線」「反射するチタン」「魚／船のモチーフ」** にある。ビルバオ・グッゲンハイムは「地面から湧き出るように立ち現われ、渦巻くような躍動感のある造形」で、「旋回中の船」や「水面を割って進む銀色の魚の群れ」を連想させる。外装の 33,000 枚のチタンパネル（厚さ 0.38mm）は「魚の鱗」のように見え、光の変化で銀色から黄金色へ表情を変える「生きた皮膚」である。ディズニー・コンサートホールは「形態が折り重なるように構成」され「構造自体が芸術作品となる流動的でダイナミックな建築」とされる。

この思想が最も自然に指すのに、ゲーリーが**実際には手がけていない**建物種が「天文台・プラネタリウム」である。星へ向かって破裂する途中で凍った彫刻——脱構築の「断片化・ねじれ・爆発」と、反射するチタンの「生きた皮膚」が、宇宙という最も動的な対象とそのまま重なる。したがって「銀の爆発」は、実在しないが「あってもおかしくなかった」架空の枝分かれとして立つ。

## フランク・ゲーリーの固有語彙（作例に反映する根拠）

- **脱構築主義**：「ボリュームの断片化と不規則なライン」「ねじれた形状、歪んだ面、折り曲げられた線」を特徴とする潮流の旗手。1979 年の「ゲーリー自邸」で波形トタン板や金網などローコストの工業用材による「完結した形態を排除」した破壊的イメージを示した。→ 作例の「断片化・ねじれ・折り曲げられた衝突する形態」。
- **ビルバオ・グッゲンハイム（1997）**：「地面から湧き出るように立ち現われ、渦巻くような躍動感」。形態は「旋回中の船」や「水面を割って進む銀色の魚の群れ」を連想させる。外装は 33,000 枚の**チタンパネル**（0.38mm）、「魚の鱗」のような凹凸で光の変化により銀色から黄金色（銅色・ローズゴールド）へ表情を変える「生きた皮膚」。→ 作例の「反射するチタンの魚の鱗のような曲面」。
- **ディズニー・コンサートホール（2003）**：「さらに先を行く躍動感と流動感を備えたフォルム」で「形態が折り重なるように構成」。「構造自体が芸術作品となる流動的でダイナミックな建築」。
- **魚モチーフ**：巨大な魚を建物に取り付けるなど自由奔放。兵庫県の「フィッシュ・ダンス」も代表作。魚は有機的デザインの重要なモチーフ。
- **手法**：二次元図面に還元しにくい複雑な形態、模型スタディ重視。鋼材・チタン・ガラスを用いた曲面構成。

## 架空作品の仕様（架空・非実在）

- **作品名**：《銀の爆発》Silver Explosion（仮称）
- **種別**：小規模な天文台・プラネタリウム（未実現の想定）
- **立地**：丘または湖畔の開けた敷地。空へ開かれた場所
- **構造/空間**：
  - 脱構築的な**断片化し、ねじれ・歪み・折り曲がった**複数の形態が衝突・折り重なる
  - **反射するチタン／ステンレス**の曲面。魚の鱗のようなパネルが、光の変化で銀→金へ表情を変える「生きた皮膚」
  - 建物は**「凍った爆発」**——地面から湧き出て渦巻き、星へ向かって破裂する途中で止まった彫刻
  - 魚／船のモチーフ（水面を割る銀の魚の群れ）
  - 継ぎ目のない白い面・白い骨格・木・生の灰色コンクリート・ガラスの箱・水は使わない（反射する皺だらけの金属の彫刻への還元）
