# 《白地図》 → ロケーションボード（澪ノ町の地図）

- 入力: 長編小説・全12章『白地図』の世界設定（[world.md](../../../../soul-voice-teller/examples/hakuchizu/構想/world.md)・[premise.md](../../../../soul-voice-teller/examples/hakuchizu/構想/premise.md)・[章立て.md](../../../../soul-voice-teller/examples/hakuchizu/構想/章立て.md)）。物語の全場所。
- format: ロケーションボード（location-board・物語の場所×地理・複数パネル一枚・人物なし）
- style: 手彩色の古地図（荒い紙・手書き抽象）。[gimmick 解説図](../hakuchizu-gimmick-diagram/prompt.md)・[キャラクター・キービジュアル](../hakuchizu-character-key-visuals/prompt.md) と同一——柔らかい4色＋自然な濃淡の滲み。

## 内容（Content）

②選択＝**物語の全場所と、その空間関係**を一枚の地図に固定する。澪ノ町は「白地図」そのもの——記憶の解像度でしか存在しない町。だからこのロケーションボードは、単なる町の地図ではなく「**色が戻りつつある白地図**」として描く。反復の舞台（下町通り）を最大パネルに据え、その周囲に各場所を配置する。

場所（空間関係）：
- **下町通り**（最大・反復の舞台。灯が歩く）
- **暖簾の店**（下町通り沿い・朱）
- **路地**（通りから枝分かれ・群青）
- **橋**（水路を渡る）
- **祭の庭**（町の奥・金彩）
- **遠くの鳥居**（町の外れ）

③翻訳＝覚えられた場所は四色の薄塗りウォッシュで、忘れられた場所は純白＋薄い鉛筆グリッドで示す——これがこの世界の「場所の状態」である。境界は濡れたインクの縁。人物は置かない（地図であってシーンでない）。

⑧ガード＝線画だけの領域を作らない（忘れられた側も紙の質感・グリッド・にじみ始めた淡い縁を残す）。特定色に寄せない（朱・群青を主とし、黄土・金彩は控えめ）。第10章の逆転は明かさない。

## フォーマット（Format）

一枚のボードに複数パネルを地理として連結する。反復の舞台（下町通り）が最大。各場所は自身の認識可能な状態（覚えられた＝色／忘れられた＝白）で、人物なし。パネルはコラージュでなく地図として繋がる。一枚の場所基準でも、一枚の雰囲気絵でもない——物語が起きる場所の地図。

## 様式（Style）

手彩色の古地図の彩色の仕方（線画＋薄塗りウォッシュ＋濃淡の滲み）を適用する。朱と群青を主とし、黄土・金彩は控えめ。忘れられた側は白地＋鉛筆グリッドだが、線画だけにせず紙の質感・にじみ始めた淡い縁を残す。全体が黄色に寄らない。白地は黄色みのない純白（クリーム・象牙色にしない）。

## 補足

- **白と色の対比を地図の本質として描く**：澪ノ町は「白地図」。覚えられた場所＝色、忘れられた場所＝白＋鉛筆グリッド、という世界法則がそのまま町の地理になる。だからこのボードは単なる地図でなく「色が戻りつつある白地図」。
- **人物は入れない**：地図であってシーンでない（灯の不在は、色の戻り方＝濡れたインクの縁としてだけ示される）。
