# 《白地図》 → キャラクター設定画（灯）

- 入力: 長編小説・全12章『白地図』の人物設計（[characters.md](../../../../soul-voice-teller/examples/hakuchizu/構想/characters.md)・[world.md](../../../../soul-voice-teller/examples/hakuchizu/構想/world.md)）。灯（あかり）＝主人公・澪ノ町を唯一覚え続ける女。
- format: キャラクター設定画（character-sheet・モデルシート・伝達＝制作仕様）
- style: 手彩色の古地図（荒い紙・手書き抽象）。[gimmick 解説図](../hakuchizu-gimmick-diagram/prompt.md)・[キャラクター・キービジュアル](../hakuchizu-character-key-visuals/prompt.md) と同一——柔らかい4色＋自然な濃淡の滲み。

## 内容（Content）

②選択＝灯を「顔を出さない」人物として仕様化する。灯は「覚え続ける＝支払う」女そのもの——中年の女、地味な服、基本は背中か輪郭、白くなる手で示す（顔はほとんど出さない）。だからこの設定画が固定するのは「**描くべきもの**」と「**決して描かないもの**」の境界である。正面・斜め・側面の顔は**白い紙（未指定）**のまま残し、背面だけを実体として描く。後続工程への仕様は「顔は描くな。背中・輪郭・白くなる手で示せ」という、消極の指定そのもの。

③翻訳＝表情も心情も描かない。身体の印だけを注記として引き出す——白くなる手、輪郭の端の透け、地味だが野暮ったくない服（色味は控えめ・黄土や茶に寄らない）、小さく静かな佇まい（背を丸めない）。**年齢はぼかす**——中年という事実は、老いの印や表情で描かず、佇まいの静けさとしてだけ滲ませる（はっきり「おばさん」に描かない）。名前「灯＝あかり」は、色そのものではなく「色を返して燃え尽きる明かり」として、白く透ける輪郭に滲ませる。シートは**表の姿（背を向けて歩く無名の女）**を固定し、内（娘の墓を塗り戻す悲しみの記録者）は注記では説かない。

⑧ガード＝顔を正面から描かない（作品のルール）。「表情」の列は置かない——灯は表情を見せない。第10章の逆転（澪が母を墓に変えていた）は明かさない。

## フォーマット（Format）

白地・多面図4面（正面／斜め／側面／背面）を**同一の身長線と目線**に載せる。ニュートラルな A ポーズ、腕はシルエットから離す。ただし正面・斜め・側面の頭部は**白い紙のまま（顔は描かない）**とし、そこに引き出し線で「顔は描かない——背中・輪郭・白くなる手で示す」と注記する。背面だけを実体として描く。下段は表情の列ではなく、注記の列（「表情なし——顔を出さない」）を置く。右に拡大図——白くなる手、輪郭の端が白く透ける様、地味な服。接地影・背景は描かない。

## 様式（Style）

手彩色の古地図の**彩色の仕方（線画＋薄塗りウォッシュ＋濃淡の滲み）**を人物にも適用する——薄い鉛筆の線画の上に、作品固有の四色（朱・群青・黄土＋金彩の微光）を薄塗りで、朱と群青を主とし黄土・金彩は控えめに、ところどころ自然な濃淡の滲みを残す（全体が黄色に寄らない）。ただし設定画の白地と衝突する部分は **format が勝つ**——接地影・背景は描かず、シート自体を「雰囲気の絵」でなく「読める仕様」にする。灯の白化はグラデーションでなく**紙の白への同化**で示す。

## 補足

- **「顔を描かない」がこの設定画の本体**：モデルシートは本来顔を固定するが、灯は作品が顔を出さない人物。ゆえに正面・斜め・側面の顔を空白（未指定）にし、後続工程への「消極の指定」として読ませる。
- **年齢はぼかして示す**：灯は中年の女だが、老いの印や「おばさん」の表情で描かない。年齢は佇まいの静けさ・輪郭の柔らかさとしてだけ滲ませる。
- **体型・服も野暮ったくしない**：背を丸めた体型や黄土・茶の「おばさん」色で描かない。小さく静かに立つ佇まいと、控えめで清潔な服（色味はクールな落ち着いたトーン）で、野暮ったさを避ける。
- **format が style に勝つ箇所**：接地影・背景シーン・「雰囲気の絵」は置かない（character-sheet の規則）。手彩色の古地図は**彩色の仕方（線画＋ウォッシュ＋濃淡）**としてだけ入る。
- **隠れたロール（第10章の逆転）は明かさない**。表の姿（背を向けて歩く無名の女）に留める。
