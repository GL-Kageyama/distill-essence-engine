# 入力：semantic-guide-loom（知恵の評議会の姉妹リポジトリ）

> 対象: `AI評価者たちによる「知恵の評議会」/semantic-guide-loom`（ローカル姉妹リポジトリ）。README・CLAUDE.md・docs/templates.md・docs/timeline.md から本質を抽出した入力スロット。

## これは何か

**テーマが、台本になり、映像になる。** 意味のある台本から、説明の映像を焼くエンジン。
解説動画・社内の説明動画・研修の導入を、**AI の映像生成を使わず、決定的に**組み立てる。
掛け合いでも、語りだけでもよい。型を替えれば、同じ台本が別の絵になる。

```
調査 → 設計 → 人物 → 台本 → 演技 → 読み → 敷き音 → 焼く
```

焼くのは 5 段——素材（表情シート → 口の 3 状態）、声（1 行 → 1 つの WAV）、
組み立て（間・声量・章の印 → 1 本の WAV）、時刻（`mix.yaml` の実尺 → `timeline.json`）、
描画（Pillow で 1 コマずつ → ffmpeg で 1 本）。`engine/make.sh` が 5 つを順に通す。

## 決定的な差（本質）

既存の AI 映像生成は、プロンプトから絵を作る。**このエンジンは作らない。**
台本が声になり、**声の実尺が時刻を決め**、**型が絵を描く**。同じ台本からは同じ映像が出る。
生成のたびに絵が変わらないから、説明の映像を版として直せる。

## 3 つの芯

### ① 時刻は、音の実尺から取る

- `timeline.json` の cue の頭尾は、`mix.yaml` の voice stem の `start` と WAV の長さから出る。
- **矢印は一方向**——絵は音の実尺を読む。音は絵を知らない。
- 台本の `pause_before` を足し直して時刻を作らない。`assemble.py` が各 cue の頭尾の無音を
  切るので、足し直すと 1 コマずつずれる。
- ゆえに台本を書き換えても、絵の側の時刻を手で直す必要はない。

### ② 型を替えれば、同じ台本が別の絵になる

型は 2 つの部品からなる。

| 部品 | 置き場 | 何を持つか |
| --- | --- | --- |
| 数 | `references/templates/<型>/template.yaml` | 画布・色・書体・位置・間合い |
| 並べ方 | `engine/layouts/<layout>.py` | `build(tl, cast, fps, W, H)` → `draw_frame` |

- 色違い・位置違いは **YAML 1 枚**。並べ方が違えば **Python 1 本**。
- **型は作品を知らない。** 特定の題・人数・章の数を型に書かない。意味は作品
  （`script.yaml` / `video.yaml`）が持つ。

### ③ 1 コマは、状態を持たない

- `draw_frame(t, fi)` は**時刻だけから絵を決める**。前のコマを覚えない。
- `--still` / `--start` で途中から焼いても、同じ時刻なら同じ絵が出る。
- 詳細カードの切替も、`timeline.json` の `details[].start` を `bisect` で引く。状態を積まない。

## いま動くもの

- 型は 2 つ。`dialogue-bust`（掛け合い・胸像）と `narrate-slide`（語り・スライド）。
- 見本は 4 本。`cyber-basics`（4 分 47 秒・1280×720）・`making-a-guide`（51 秒・1920×1080）・
  `black-swan-ai`（15 分 4 秒）・`hubble-mirror`（17 分 14 秒）。`hubble-mirror` は
  調査・設計・評価の往復まで通した。

## その他の固定方針

- **意味は作品、絵は型。** 題・章・字幕・時刻は作品が持ち、色・位置・間合いは型が持つ。
- **人物はデータ。** 欲・怖れ・矛盾・感情の型は `characters/<id>.character.yaml`。
  コードに固有名を書かない。
- **音の道具の正本は `semantic-audio-loom`。** 声（`build_voice.py`）と組み立て
  （`assemble.py`）は写さず、パスで呼ぶ。
- **焼く時にネットを見ない。** 調査は焼く前の段だけ。
- **多言語化はしない。** 日本語の音声と字幕のためのエンジン。
