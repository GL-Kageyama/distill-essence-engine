## ① 何が来たか（理解）

- **この構想の核は、事業計画の中身ではなく、設計の論理にある。** 3本柱（生業・表現・生活）は順位づけず、**通貨の違う下限**を置く——生業は金額、表現と生活は時間。順位をつけると下位が必ず削られるから、順位をやめた。
- **時間は生活と表現から先に引く。** 生業は残りを埋める。「残余は必ず減ります」。
- **退出は段階的で、関門は年1回の契約更新だけ。** 最初の関門（2027年1〜3月）は、実績1〜2件の状態で来る。
- **いま確定しているのは、文書雛形 v1.0 の1本だけ。** 草稿43本、番号付き44本、タスク88件（未完了87・完了1）、全体像の未決9件。そして README は言う——**「確定が1本しかないのは、意図的です」**。判断が済んでいない文書を確定に上げると、決めたことと決めていないことの区別が付かなくなるから。
- **つまり現在地は、「決まっているのは中身ではなく、決め方の形だけ」**である。これがこの一枚の言いたいことである。

## ② 語る一点（選定）

**確定しているのは、白い雛形一枚だけ。本文は空で、ただ一欄、「状態 確定」だけが朱で囲まれている。**

**なぜこの一点か。** 43本の草稿をダッシュボードに並べるのは、**直接すぎて、どこにでもある**——プロジェクト管理の画になる。この構想にしかない事実は、**唯一の確定文書が、空の文書雛形だ**ということである。中身は一つも決まっていない。決まっているのは、決めたことと決めていないことを分けて置くための**器の形**だけ。**空の雛形は、失敗の証拠ではなく、区別を保つための道具**である——README が「意図的」と言っている通りに。

**支える二点**（最小限）：

1. **周りは鉛筆の草稿。** 重なり、傾き、訂正線、余白の矢印。草稿は「まだ決めていない」ことを、失敗ではなく**作業の痕跡**として持つ。草稿の一枚には、v0.1 を消して v0.2 に直した跡がある——v0.2 で柱の分類が「収益の有無」から「生業・表現・生活」に変わり、下限の通貨が入った版である。
2. **右余白に、空のチェックボックスが九つ。** どれも空欄。**「9」とは書かない。** 数えるのは見る人の仕事である。一つだけ、鉛筆の矢印が草稿の山へ向かう——No.7（契約交渉に出す実績を、いつまでに何件作るか）。**未決は、箇条書きではなく、空欄のまま置く。**

## ④ 同一の世界（頁と紙）

- **一枚の紙。** 机も、手も、人も、場面もない。**頁そのものが世界**である。
- **紙は淡い冷たい灰白の罫線紙。** 平ら、乾いた質感、重い影なし。**温かいクリーム色にしない。**
- **鉛筆は冷たい石墨の灰色。** 線は少し緩い。訂正線・矢印・丸囲みが、頁の文法として働く。
- **印刷物は一つだけ。** 文書雛形。白く、真っ直ぐで、活字の小さい欄名。**この対比が、この一枚の意味である。**
- **朱は一点だけ。** 「状態 確定」を囲む朱の鉛筆。他の赤・黄・橙はない。**2027.1–3 の印も、濃い鉛筆にとどめる。**
- **文字は短い日本語ラベルのみ。** 段落なし。注記の一行も描かない——下部は罫線だけの余白で終える。

- **数を変えない**：確定1、草稿43、タスク88（未完了87）、未決9。画像に書くのは確定1と草稿43だけ。未決は九つの空欄で置き、数字を書かない。

- **収入の数字・将来の段階を、現在地に混ぜない。** 階段は草稿の上の小さな鉛筆の sketch にとどめる。
