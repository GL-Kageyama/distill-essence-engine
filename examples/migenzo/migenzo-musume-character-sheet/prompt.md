# 《未現像》 → キャラクター設定画（娘）

- 入力: 長編小説・全12章『未現像』の人物設計（[characters.md](../../../../soul-voice-teller/examples/migenzo/構想/characters.md)・[world.md](../../../../soul-voice-teller/examples/migenzo/構想/world.md)）。娘＝現像されないまま無限に残る者・名を持たない。
- format: キャラクター設定画（character-sheet・モデルシート・伝達＝制作仕様）
- style: 暖色フィルム・ドキュメンタリー（暗室）。[選抜スチル](../migenzo-stills/prompt.md) と同一——暖色セピア（Kodak Portra 400 / Fujifilm Superia）の色味＋フォトリアルな質感。
- trace: false（通常モード＝3欄のみ）

## 内容（Content）

②選択＝娘を「現像されない」人物として仕様化する。娘は「現像されないまま無限に残る者・名を持たない」。源は外見を与えない——顔も名も決して現れない。だからこの設定画が固定するのは、輪郭のある少女の姿ではなく**「現像されないこと」そのもの**である。多面図の身体は淡いシルエット（未指定）に留め、顔の位置は**白い紙（現像されない）**のまま残す。唯一の実体として、**「小さな手」（レンズを内側から押さえる）**を、右側の拡大図にだけ置く。

③翻訳＝少女の外見も表情も描かない（源にない）。注記だけを引き出す——「顔は現像されない」「外見は源にない——現像されない」「表情なし——死者」。娘の唯一の実体は小さな手——レンズを内側から押さえる（撮るな、と押さえる）手で、その拒否の仕草そのものが、この世界では「シャッターを降ろすこと」に等しい。小さな手は写真的に（生身の質感で）描く。

⑧ガード＝源が与えない外見（髪・年齢・服装）を捏造しない。表情の列は置かない（死者・変化しない）。顔も名も出さない。第10章の逆転（娘が自ら拒んでいた）は、この設定画では「小さな手」としてのみ示し、言葉では明かさない。

## フォーマット（Format）

白地・多面図4面（正面／斜め／側面／背面）を**同一の身長線と目線**に載せる。ニュートラルな A ポーズ、腕はシルエットから離す。身体は淡い暖色の未指定シルエット（少女の佇まい）に留め、正面・斜め・側面の顔は**白い紙（現像されない）**のままにし、そこに引き出し線で「顔は現像されない——唯一出るのは小さな手（右の拡大図を参照）」と注記する（背面は顔なし・頭の輪郭のみ）。下段は表情の列ではなく、注記の列（「表情なし——死者・現像されない」）を置く。右に拡大図——レンズを内側から押さえる小さな手（掌と指を広げてシャッターを遮る）。接地影・背景は描かない。

## 様式（Style）

白地（黄色みのない純白）。身体と小さな手は暖色フィルム・ドキュメンタリー（暗室）の色味（暖色セピア）で描き、小さな手は**フォトリアル（写真的な生身の質感）**にする。アニメ調にしない。接地影・背景・フィルム粒のボケは置かず、白地は黄色みのない純白。小さな手の拡大図だけは、暖色フィルムの質感（ノスタルジックな家族写真の温み）をわずかに残してよい（唯一の実体＝唯一の生身の痕）。

## 補足

- **白地に戻す・人物（小さな手）はフォトリアル**：白地（純白）に戻し、暖色フィルムの全面適用はやめる。娘の顔＝現像不能＝白は、白地のなかの空白として残す（第12章の白に直結する幹）。小さな手だけがフォトリアル（写真的な生身の質感）。
- **「現像されないこと」がこの設定画の本体**：身体は淡い未指定シルエット、顔は白、唯一の実体「小さな手」を右の拡大図にだけ置くことで「現像されないこと」を仕様として読ませる。
- **小さな手は唯一の生身の痕**：拡大図の小さな手だけに、暖色フィルムの「家族写真の温み」をわずかに残す。拒否の手が、この世界で唯一の実体であり、唯一の救済の形（脂痕と同根）。
- **隠れたロール（第10章の逆転＝娘が自ら拒んでいた）は、手の仕草としてのみ示し、言葉では明かさない**。
