# distill-essence-engine → アプリ画面（様式差し替え：フラットデザイン）

- 入力: [design-series-constants.md](../design-series-constants.md)（ブランドブリーフ）
- format: アプリ画面（app-screen・検証済みカード・Layout (design)）

> **様式検証のケース**。[design-format-app-screen](../design-format-app-screen/prompt.md) は**同じ入力・同じフォーマット**でスイス型を使っている。差は様式だけ——あちらは「グリッドとタイポグラフィの規律」。こちらは「平らな単色面・ノーグラデ・ノー影」。蛇管も黄金の一滴も、同じUI骨格が違う様式で語られる。

## 内容（Content）

②選択＝**蒸留の操作そのものを画面にする**（フォーマット検証と同じ一画面・一状態）。入力スロット＝積み重なるコンテンツシート、圧縮の行程＝画面の背骨の蛇管、出力＝黄金の一滴が落ち着く単一のプロンプト欄、一次アクション「Distill」は唯一目立つ。フッターにはブランドの掟の一言「To compress is to choose.」をライトグレーの平らな一行で——キャッチラインもまた不変素材として画面に残す。

③翻訳＝要素は同じだが**形の語彙が変わる**：フラットUIでは、フラスコも蛇管も単色の平坦な面として描く。シート＝角の立った矩形、蛇管＝平らなコイルの輪郭線、一滴＝単色の円。立体的な描写は一切しない——金色は**平らな金の面**、白熱は**平らな白の面**。キャッチラインも単色の平らな文字列として、ライトグレーのフッター一行に。

## フォーマット（Format）

アプリ画面＝一画面 × 一状態。縦型モバイル比、実UI。トップバー・内容領域の明確な階層・一貫した余白・一次アクションは一つ。ラベルは短く正しく一度だけ。クリーンなグリッド。

## 様式（Style）

フラットデザイン＝**平らな単色面**（グラデなし・影なし・奥行きなし・ベベルなし）・単純な幾何・**クリスプなエッジ**・広い余白・白とライトグレーのニュートラル＋**アクセント色は一つ**。このブランドでは、フラットUIの「明るい白地」はブランドの掟が紺の地に置き換える——平らな紺の面の上に、唯一のアクセント（金橙）が立つ。フラットであることは失わない。
