# php2shell — 一枚インフォグラフィックの入力

> 事実の台帳は [../php2shell-manga/input.md](../php2shell-manga/input.md) を正とする（CVE・修正版・影響範囲・出典・事実と演出の切り分け）。ここには**一枚に畳むための選別**だけを置く。

## 何を一枚にするか

4ページ版は「一夜の運用室」を四つの場面に分けた。一枚版は、その四つを**縦一本の矢印**に束ねる。

- 矢印は、白板に描かれた `request` → `PHP` → `app` の流れそのもの。用紙の上端から下端まで一本で走る。
- 上では矢じりが無い（`app` の手前で死んでいる）。下端で、更新のゲートは通るが**矢じりは破線のまま**。`再起動` の目印の先で、初めてベタの矢じりに閉じる。**更新と再起動は別の関門**であり、図がそれを言う。
- この一本が、原因・被害・広がり・対応の四つを、説明ではなく**同じ線の状態**として見せる。

## 選んだ一点

**書く前の用紙に、判がひとりでに下りる。** 係員の手は行の途中で離れ、引き出しは詰まっている。名前欄の「佐藤」だけが埋まり、残りは白い。

## 選んだ間接

窓口。4ページ版と同じ机・同じ係員・同じフック。一枚版では、その窓が通りに並ぶ（広がり）ところまで描く。

## 四つの帯（上から下へ）

| 帯 | 見出し | 一点 | 数字・文字 |
|---|---|---|---|
| 1 | 終わる場所 | 半筆の用紙に、ひとりでに下りる「有効」。背後の白板に、矢じりの消えた流れ図 | 用紙の隅に小さく `CVE-2026-109618` |
| 2 | 残るもの | 前の客の上着を着た次の客。襟の名札は「佐藤」、ポケットに鍵と電話。フックは空 | 襟の内側に小さく `CVE-2026-109619`。`php-fpm` 03:00 → `sh` 03:12 |
| 3 | 広がり | 同じ窓が通りに並ぶ（閉じた店、自転車、二十歩ごとに同じ窓）。どの窓にも同じ机・同じ係員・同じ空のフック | `258万台` → `版を返した158万台` → `115万台が8.1以前`（同じ母数）／別枠に `7割`。出典も分ける |
| 4 | 通す方法 | 更新のゲートでは矢じりは破線のまま。再起動の目印を通って初めて、ベタの矢じりが閉じる。ディスクは新版、動いているプロセスは旧版 | 修正版 `8.2.35 / 8.3.36 / 8.4.27 / 8.5.12`、`8.1 以前は修正版が出ない` |

## 落としたもの

- コドモン・刈谷市・国内各社の緊急メンテ・CERT-EU。**一枚では因果の説明が要る事実**であり、帯を一つ食う。4ページ版の P3 が担う。
- `WordPress 43%`。`7割` と並べると数字が四つになり、一目で掴むという目的に反する。
- 混乱の実況（ログの切れ目、cron、`.cache/idx.php`、`svc-backup`）。**想定されるパターン**の細部は4ページ版の P2 が担う。
- 人物の名前・会社名・時刻の物語（22:58 / 07:31）。一枚版に物語は要らない。時刻は `03:12` と `22:40` だけ残す（どちらも意味を持つ時刻）。

## 事実と演出

- 事実：CVE-2026-109618 / 109619、CVSS 9.2、修正版 `8.2.35 / 8.3.36 / 8.4.27 / 8.5.12`、PHP 5.4 以降が対象、8.1 以前は EOL（修正版が出ない）、認証の前に実行される、Censys の `258万台`（版の自己申告なので上限）、`158万台` のうち `115万台` が 8.1 以前、W3Techs の `7割`。出典には年月を添える。
- 演出：窓口、係員、上着、名札「佐藤」、`php-fpm` の PID と起動時刻、ゲート、矢印の欠けた矢じり、通りの閉じた店と自転車。ベタは二点だけ（判のインクと、最後に閉じる矢じり）。
- **断定しない**：確認された大規模侵害として描かない。4ページ版と同じく、上着は「前の客の上着を着せられた次の客」であって盗人ではない。
- 数字は同じ母数の三つを一列に。`258万台`（ネットから見える）→ `そのうち、版を返した158万台` → `115万台が8.1以前`。`7割` は測定系が違うので別枠にし、出典も分ける。
- `8.1 以前は、もう修正版が出ない。` を一行。数字が痛い理由まで渡す。
- 頭に公表日 `2026年10月21日`。CVE 二件は、用紙の隅（109618）と襟の内側（109619）に小さく割り当てる。
