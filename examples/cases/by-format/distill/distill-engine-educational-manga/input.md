# 入力：リポジトリ自身（distill-essence-engine）を教える学習漫画

> 対象: 概念。このリポジトリ＝あらゆる内容を、本質だけを残して一枚の英語の画像プロンプトへ蒸留するエンジン、を教師キャラが読み手に教える学習漫画。

## 概念の骨格

| このエンジン | 教えるべきこと |
|---|---|
| 任意の入力（小説／記事／詩／文字起こし／メモ／論文）を受け取る | ① どんな内容でも来る |
| 固有×間接＝真実を、委ねて示す | ② 本質は「固有×間接」で決まる |
| 二本の直交軸：圧縮（フォーマット）＝何を見せるか × 様式（スタイル）＝誰の声で | ③ 二つの軸 |
| 8原則：①理解→②選定→③翻訳→⑤構成→⑥様式→⑦ネガティブ（④一貫性・⑧忠実性は手順でなく横断する制約） | ④ 8原則の流れ |
| 出力は一枚の英語の画像プロンプト | ⑤ 一枚の英語になる |

## 語る一点

「あらゆる内容が、本質だけ残して一枚の英語の画像プロンプトになる」。教師キャラが5つの手順で教え、最後にフレームの外の読者を指して「いま君が読んでいるこのマンガも、じつはその一枚だ」と言う——**自己言及**。このマンガ自体がエンジンの出力の例である、を一枚の因果として畳む。

## 期待する雰囲気

印刷の網点（ベン・デイドット）と太い墨線、CMYKプロセスカラー、ポップな平塗り。教える明快さ。
