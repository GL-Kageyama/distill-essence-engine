- 入力: [input.md](input.md)（構想メモ④ 世界モデル生成器）
- format: 図解（diagram）—— 縦方向パイプライン＋末端の放射
- style: クリーンライン・ラボ（clean-line-lab）＋ユーザー指定「奥にありとあらゆるイメージが多層」を**標本瓶の内部**として具現
- 用途: 理解（自己）。圧縮は「多 → 一 → 多 → さらに多」の機構を一枚の実験図として示すことで実現
- **改訂**: ①6ジャンルを「平たい単一アイコン」から「それぞれの豊かなミニチュア世界」へ強化（ユーザー要望: 各ジャンルのイメージが貧困）②各ジャンルからさらに細い蔓が分岐して伸びる「派生の成長」を追加（ユーザー要望: 各ジャンルがもっと派生して伸びていく）。③アスペクト 3:4 → 2:3 に変更（下部の「派生の庭」が息ができるように）。④「!」（びっくりマーク）を撤去——解決状態は記号でなく、瓶の奥まで運ばれる金そのものが担う（ユーザー要望）

## 内容（Content）

一枚の縦型実験図。**小説を書く → ストック → 解析 → 抽出 → World Model Database → 各ジャンルへ派生 → さらに伸びていく**の全流れを、教科書の装置として一筆で示す。焦点は**深い標本瓶＝World Model Database**（金の一点アクセント）で、その奥に「ありとあらゆるイメージ」が層として重なる。瓶の底からは**派生の庭**——6つの豊かなミニチュア世界が弧を描いて並び、それぞれが蔓を伸ばしてさらに分岐する。

- **頂部（作る → ストック）**: 小さな書き机とインク壺、白い原稿の整った束。束の上に淡いペール「?」＝未処理の物語たち。
- **中部（解析 → 抽出）**: 原稿が小さな虫めがねの解析器を通り、**5本の細い抽出塔**に分かれる。各塔はひとつの淡いエンブレムを担う——世界（丘と小さな太陽）、人物（小さな立つ人影）、ルール（「∴」の刻まれた石板）、因果（つながる3つの輪）、感情（渦を巻く小さな心）。
- **焦点（World Model Database）**: 5つの淡い流れが大きな標本瓶の口に注がれる。瓶の奥で状態が変わる——**口から下へ、線維状の段階的前線が金を運ぶ**（因果、グラデーションではない）。金色の面の下に**透明な層が瓶の奥へ後退する**: 丘の城、星空、街の稜線、開いた海——ありとあらゆるイメージが薄い墨線で層をなす。金が奥まで運ばれたこと自体が解決状態を表す（記号は置かない）。
- **底（派生の庭）**: 瓶の底から**6本の細い注ぎ口**が弧を描いて開き、**6つの豊かなミニチュア世界**をそれぞれ淡い台座タイルに届ける。各シードの心臓に淡い金の滴が宿る——
  - **ゲーム**: 小さな勇者が市松模様のオーバーワールドの地図に立ち、小道が遠くの旗へ曲がる
  - **漫画**: 3コマの小さな開いたページ。中央のコマで駆ける人影がスピード線と小さな爆発記号を伴う
  - **映像**: 小さなカチンコの脇に4フレームのフィルム片——それぞれドア・窓・月・人影の違うミニシーン
  - **小説**: 開いた本の見開きから、線の茎を伸ばして小さな城が頁から生え出る
  - **TRPG**: 小さな丸机にサイコロひとつ、キャラクターシートのカード、扉のあるダンジョン盤のタイル
  - **その他（未定義の可能性）**: 小さな空の輪郭枠から一枚葉の芽が一本伸び、脇に小さな「…」
- **成長（もっと派生）**: **各シードから2〜3本の細い蔓が立ち上がり、小さな形（小さな旗・小さなタイル・小さな音符・小さな星）へ分岐する**——派生がさらに伸び続け、上端に向かうほど疎で軽くなる。蔓の先端にも瓶と同じ金の滴がひとつ。

図解として分かりやすい表層と、瓶の中に封じた多層の奥行き、そして**底で増え続ける派生**。文字を排し、物体の形だけで読ませる。

## フォーマット（Format）

縦型図解（diagram）。縦長 2:3 のポートレート。装置を中央に置き、周囲は広い余白。上から下への単一の階層フロー（作る → ストック → 解析 → 抽出 → 瓶 → 派生 → 成長）を強調点ひとつで構成。**多層のイメージは瓶の内部にだけ封じ**、外側は最小要素＋余白を保つ。**派生の庭は6つの台座タイルを弧に並べて過密を避け**、蔓は細く疎に描いて空気を保つ。文字は書かない——媒体は場面の形で識別させる（勇者と旗＝ゲーム、コマの頁＝漫画、カチンコとフィルム＝映像、城の生える本＝小説、机とサイコロ＝TRPG、空枠と芽＝その他）。

## 様式（Style）

クリーンライン・ラボ（clean-line-lab）: 教科書の実験図のような細い精密な墨線・淡いパステルの平塗り（ミント・淡黄・淡青・オフ白の紙）・フラットな色・最小の陰影・静かで端正。飽和アクセントは**瓶の金ひとつだけ**——瓶の奥の前線から注ぎ口、シードの心臓、蔓の先端まで、同じ金が「模型の本質」として流れ通す。状態変化は「線維状・段階的前線が一点から進む」因果として描く。記号は小シンボルに限定（「?」「∴」「…」）——文字なし。ユーザー指定の「奥にありとあらゆるイメージが多層」は、この様式の中で「標本瓶の内部＝透明な層の奥行き」として具現する（金の前線の下に、薄い墨線の世界が層をなして後退）。「各ジャンルが伸びていく」は、同じ線言語による細い蔓の分岐で具現する。
