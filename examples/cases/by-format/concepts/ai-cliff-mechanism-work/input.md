# 企業AI活用の失敗と克服（Pivot 動画・n69Q4y71e3o）

概念：水平型AIでは生産性の崖を越えられない。機能特化（垂直）の一点に特化したAIエージェントだけが、4つの壁を越えて劇的な生産性を実現する。

- URL 入力: https://www.youtube.com/watch?v=n69Q4y71e3o（ピボット・インタビュー「大企業のAI活用はなぜ失敗する？4つの壁の克服法」。ゲスト＝ナレッチワーク CEO 麻野浩司）。`python3 scripts/fetch.py url:https://...` で実フェッチした文字起こしを入力に使用。
- MIT 発表のデータ：企業のAI導入は **95% が失敗**。成功＝P&L レベルの ROI を確認できる（売上アップ・コストダウン・利益増）。確認できたのは 5% のみ。
- ユースケースは2つ——**全社型（水平）**（従業員用コパイロット・チャットボットを全社共通に配る。便利になるが、劇的な生産性は生まない）と**機能特化型（垂直）**（研究開発・調達／サプライチェーン・セールス・カスタマーサービスなど、それぞれに特化する）。**垂直＋AIエージェント**（人間の代わりに業務を遂行する AI）の組み合わせで初めて劇的な生産性が実現する。
- 垂直AIの実現を阻む **4つの壁**：
  1. データの壁——データが集約・整理されていない（営業の相談データが残っていない、商品資料の版が乱れている等。営業エージェントでは 95% 以上がここで最初につまずく）。
  2. 業務の壁——業務プロセスや判断ルールが設計されていない（「この課題にはこの商品・このプロセスではこのアクション」を AI に教えられない）。
  3. 実装の壁——整理した業務を AI エージェントに落とし込めない（業務理解と実装の往復が難しい。実装力のあるエンジニアは業務に詳しくない）。
  4. ユーザーの壁——現場の社員が使わない。**一番大きい壁**。克服にはハウでなくワイ（なぜ今仕事が変わるのか・これからどういう役割に変わるのか）を腹落ちさせ、「作る」ことより「使う・変える」こと。
- 未来：Sierra（Bret Taylor）のようにカスタマーサポート特化の垂直AIエージェント企業が伸びる。今後 2〜3 年が勝負。最初にやりきったところが圧倒的な競争優位。
- 語る一点＝**生産性の崖（95%失敗）を越えるのは、水平の便利さではなく、垂直の一点に特化したAIエージェントだけ**（しかも4つの壁を1つずつ、最後のユーザーの壁まで越えて）。
