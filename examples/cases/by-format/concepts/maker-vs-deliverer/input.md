# 入力：「作る」と「届ける」の非対称（創作論メモ）

> 対象: 概念（創作論の考察メモ）。「世界一の店も、誰にも届かなければ無意味」という比喩から、AI時代における「作る」と「届ける」の偏りを示す一枚のイラストにする。

## メモ本文

> とても美味しい料理店（世界一クラス）でも、誰も知らない、なかなか辿り着けない、では意味がない。
> これは、創作論全般に言える。
> ジブリで言えば、宮崎駿は作る人、鈴木敏夫は届ける人。
> AI時代に鑑みれば、AIで作れること自体は、カバーしようとみんなしているが、つい、届けることがおざなりになっている。
> AIを使えば、「届ける」もカバーできる余地があるのに

## 骨格（対比の構造）

| 作る（宮崎駿） | 届ける（鈴木敏夫） |
|---|---|
| 世界一の味を作る | その味を人に知らせ、届ける |
| 完成した作品・料理 | そこへ至る道・評判・読者／客 |
| AI時代、みんなが殺到する側 | ついおざなりになる側 |
| 光・温かさ・完璧 | 不在・放置・空白 |

## 語る一点

「完成した光と、途切れた道」。断崖の上に世界一の店が完成し、湯気を立てて輝いている。けれど、そこへ登るはずの道は途中で途切れ、峡谷の闇が横たわって誰も辿り着けない。光はすべて店の内側に閉じ、道へは一滴も届かない——**「作る」は完成、「届ける」は不在**という非対称が一枚で語られる。

## 期待する雰囲気

分かりやすくありつつ、外連味（演出）のある。図解のラベルではなく、劇場のスポットライトのような明暗の対比と、遠くに灯る宝石のような店の静かな皮肉で描く。
