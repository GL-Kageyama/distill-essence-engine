## 内容（Content）

一枚の横長イラスト。**海の断面が幅いっぱいに広がり、水面が水平線として画面を横切る**。中央に**氷山＝世界モデル**——水面より上の小さな頂に、見える表層（物語）として淡い原稿の束。水面より下の大きなガラスの腹には、世界モデルの**積層する地層**——淡い丘、星空の帯、街の稜線、開いた海——が薄い墨線で奥へ後退する。**下部が広い氷山**が「見えない部分の大きさ」そのものを表す。

**説明文（日本語ラベル＝「名前——役割」、同じ線言語でクリーンに、はっきり読める大きさで描く）：**

- 頂の原稿の束の脇 → **「物語——見える表層」**
- ガラスの腹の地層の上 → **「世界モデル——物語を生む母体」**
- 採掘柱 → **「概念深掘りエンジン——見えない部分を掘り出す」**
- 瓶の口の脇 → **「世界モデル生成器——掘った下部を構造化・蓄積」**
- 虫めがね・天秤 → **「評価レイヤー——世界を検品し、弱い箇所を戻す」**
- 戻りの蔓に沿って → **「弱い箇所を戻す」**（ループの説明）

**装置（ラベルを除く描写）：**

- **①（左下）深掘り**: ガラスの腹の左脇へ降りる細い垂直の採掘柱。**5つの淡いエンブレムを担う小さな断片**を引き上げる——世界（丘と小さな太陽）、人物（小さな立つ人影）、ルール（「∴」の石板）、因果（つながる3つの輪）、感情（渦を巻く小さな心）。各断片は淡い金の粒を宿す
- **④（中央）世界モデル生成器＝氷山そのもの**: 採掘柱が注ぐ5つの淡い流れを受けて、瓶の奥で**粗い繊維状・段階的な金の前線が一点から進む**（因果。グラデーションではない）。同じ金が引き上げた断片・進む前線・そして底から生える小さな芽の原稿まで流れ通す——**解決状態は記号でなく、金そのものが担う**（「!」は置かない）
- **⑤（右下）評価**: ガラスの腹の右脇に向けた小さな虫めがねと、その下の小さな天秤。地層の一枚に**淡い灰色の「?」**が浮かぶ＝弱い箇所
- **戻りのループ**: ⑤の虫めがねから細い蔓が弧を描いて**氷山の頂を越え、空を渡って①の採掘柱へ還る**——淡い灰色の粒を運び、**弱い箇所が①へ戻って再び掘られる。ループが閉じる**
- **④の出力（表層）**: 氷山の底から小さな芽が一本、淡い原稿を一枚伸ばす＝世界が物語を生む
- 記号は「?」「∴」のふたつ。いずれも状態変化に参加する（「?」＝弱い箇所、「∴」＝ルールの石版）

図解として読み取れる三構想の循環（左→中央→右→空を越えて戻る）と、氷山＝世界モデルという一つの焦点。ラベルは最小限の小文字で、装置に沿って控えめに配置する。支援（採掘柱・虫めがね・天秤）は最小限に控え、左右の空と海は広い余白。

## フォーマット（Format）

イラスト（illustration）。横長 16:9 のランドスケープ。**氷山＝世界モデルを中央にひとつ**、採掘柱（①）を左下、虫めがね＋天秤（⑤）を右下に置き、ループは「左→中央→右→空を越えて戻る」の横の流れとして読ませる。戻りの蔓は細く疎に、頂を越える弧で空気を保つ。氷山の外側（左右の空・海）は広い余白＝呼吸。**説明文は日本語のラベルのみ**——装置の脇に置き、**はっきり読める大きさ（視認性優先）で、過密にしない**（「物語——見える表層」／「世界モデル——物語を生む母体」／「概念深掘りエンジン——見えない部分を掘り出す」／「世界モデル生成器——掘った下部を構造化・蓄積」／「評価レイヤー——世界を検品し、弱い箇所を戻す」／「弱い箇所を戻す」）。他に文字は書かない——媒体は形でも読ませる（地層＝世界の厚み、天秤＝検品）。

## 様式（Style）

クリーンライン・ラボ（clean-line-lab）: 教科書の実験図のような細く正確な墨線・淡いパステルの平塗り（ミント・淡黄・淡青・生成り紙）・影最小のフラットな色彩・静かで端正。焦点には**単一の飽和アクセント＝温かい金色ひとつ**——採掘された断片から前線、芽の原稿まで、同じ金が「世界モデルの本質」として流れ通る。状態変化（採掘→折り込み）は「粗い・繊維状・段階的な波面が一点から進む」因果として描く。**説明文はカードの「文字なし」規約を逸脱してラベルとして許容**——同じ細い線言語でクリーンに、**はっきり読める大きさで**、状態変化に参加する形で描く。記号は「?」（弱い箇所）「∴」（ルール）だけ。クワイエット——図解っぽさやミームにしない。
