# ①理解（Understand）— 何が来たかを掴む

**種別**：小説（太宰治「走れメロス」、ギリシャ伝説＋シルレルの詩より）

**主題**：信実（人を信じる力）が不信（暴君ディオニスの「人は信じられぬ」）に勝つこと。

**登場要素**：
- メロス — 村の牧人。純朴・単純・正直。妹の結婚式の買い出しに市へ。
- セリヌンティウス — 石工。無二の友。人質となる。
- 暴君ディオニス — 人を信じられず、妹婿・世嗣・妹・皇后・賢臣まで殺した王。
- 妹 — 十六歳。花嫁となる。
- フィロストラトス — セリヌンティウスの弟子（終盤で「遅かった」と叫ぶ）。

**感情の推移**：激怒 → 決意 → 不安 → 疾走 → 絶望（疲労と裏切りの誘惑）→ 泉で希望回復 → 疾走 → 間に合う → 赦し。

**転換点**：
1. 王との三日の約束（セリヌンティウスを人質に）。
2. 濁流が橋を壊す（絶望の壁）。
3. 泉の水で希望回復（絶望→希望の反転）。
4. 磔台で友の両足に齧りつく（間に合う）。
5. 互いに頬を殴り合い、抱擁（不信の払拭と信実の成就）。

**繰り返すモチーフ**：走る／日没（期限）／泉／緋のマント／裸体／頬を殴る・抱擁。
