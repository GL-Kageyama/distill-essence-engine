# 入力：AI使いと式神使いの類比（現代 × 平安）

> 対象: 概念（生成AIを使う人間と、陰陽師の式神使いの間に類比を見出す）。二つの時代を鏡合わせに並べ、その共通点を示す一枚のイラストにする。

## 類比の骨格（共通点）

| 平安の式神使い | 現代のAI使い |
|---|---|
| 陰陽師が文字（呪文・式札）を書く | 人間が文字（プロンプト）を打つ |
| 書いた文字が力を帯び、**紙の式神**が立ち上がる | 打った文字が応答し、**光のAI**が立ち昇る |
| 机に向かう一人の人間（使用者） | 机に向かう一人の人間（使用者） |
| 見えない力（式神）を使役する | 見えない力（AI）を使役する |
| 使用者は人間のままで、力は外にある | 使用者は人間のままで、力は外にある |
| ろうそく・行灯の灯りの中で | モニターの灯りの中で |

## 語る一点

「書く手と、呼び出される光」。平安の陰陽師が式札に墨を落とすと札の文字が温かな金色に光り、白い紙でできた小さな式神が札からふわりと立ち昇る。同じ机の同じ高さで、現代の使い手がキーボードを打つと、スクリーンから同じ金色の光の球が立ち昇る。**同じ机・同じ姿勢・同じ仕草・同じ光——変わるのは時代の道具だけ。**
