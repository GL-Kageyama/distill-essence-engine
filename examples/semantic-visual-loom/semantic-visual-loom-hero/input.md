# 入力：semantic-visual-loom（知恵の評議会の姉妹リポジトリ）

> 対象: `AI評価者たちによる「知恵の評議会」/semantic-visual-loom`（ローカル姉妹リポジトリ）。README・docs/usage.md・CLAUDE.md から本質を抽出した入力スロット。

## これは何か

物語を、フィルムにするところまで運ぶ基盤。**生成モデルが作るのは標本であり、独立した生成どうしは互いを覚えていない**——だから状態は生成の外に置く。その器が**制作台帳**であり、**1本のファイル**が連続性と開示を一緒に持つ。

単位は**ショット**——**1ショットは1つの変化のために在る。長さは従属変数である。**

```
物語・プロット・草稿 → ショットの列 → 各ショットの §1–20 仕様 → §18 の英語 7 スロット → 生成器
```

⚠️ **生成はこの基盤の中では走らない。** 走るのは**事前検証**——生成の前に、仕様の段で矛盾を鳴らすこと——だけである。

## 決定的な差（本質）

既存の AI 映像ツールは**1プロンプト＝1動画**で、状態をプロンプトへ毎回書き直す。30本作ると、**8本目で誰が何を知っていたかが分からなくなる。**

| | よくある形 | この基盤 |
| --- | --- | --- |
| 単位 | 1プロンプト＝1動画 | **1ショット＝1生成**。作品はショットの列である |
| 状態 | プロンプトに毎回書き直す | **制作台帳**が持つ（連続性＋開示） |
| 文字 | 生成器に描かせる | **文字チャンネル**として分離し、合成で焼く |
| 検収 | 目視 | **事前検証**——仕様の段で矛盾を鳴らす |

**実測**——デモ `projects/hitosara/`（「一皿ができるまで」）は **10 ショット**、**台帳 1 枚**から出ている。

| 何を | 実測 |
| --- | --- |
| ショット数 | 10（`projects/hitosara/shots/`） |
| 検査の層 | **27 層（`L0`–`L26`）**＋スキーマの形状検証。単一判定ではない |
| 検査器の自己検査 | **176 例中 176 例が期待どおり** |
| デモに対する検査 | **違反 13 件 / 註 21 件**（⚠️ 註は「読んだが違反ではないもの」） |
| 生成器へ渡るもの | **§18 の英語 7 スロットだけ**（`Master` / `Visual` / `Motion` / `Camera` / `Audio` / `Negative` / `Style Motion`） |
| 動画のテイクの `adopted: true` | ⚠️ **1 本も無い** |

⚠️ **この基盤が本当に言っていることは、映像には映らない**——**10 ショットは、台帳 1 枚から出ている。** それが**映像が自分だけでは言えない唯一の主張**である。

## 4 段フロー

```
分解 → 設計 → 台帳 → ショット
```

⚠️ **4 本とも Claude Code のセッションへの指示であって、プログラムではない。このリポジトリに 4 本のコードは無い。** 名前空間は `/semantic-visual-loom:breakdown` `:design` `:ledger` `:shot`。

| 段 | 渡すもの | 出るもの |
| --- | --- | --- |
| ① 分解 | 物語・プロット・草稿 | ショットの列＋作品台帳＋開示の変化点 |
| ② 設計 | ショット 1 本 | §1–20 の仕様＋画像仕様（**§18 の 7 スロットが生成器へ渡る**） |
| ③ 台帳 | ショット 1 本 | **育った台帳**＋**参照集合**（固定されるもの）＋**禁制集合**（映してはならないもの） |
| ④ ショット | 戻ってきたもの | テイク ⚠️ **採用はしない** |

⚠️ **検査器は②がディスクに乗るまで何も読めない**——ショットの記録は `duration` を要求し、それを決めるのは②である。

## 資材の分離（再利用の設計）

- **参照集合**（何を固定するか）と**禁制集合**（何を映してはならないか）は、**台帳という 1 点から導かれる**。⚠️ **2 つに割らない。**
- **生成は標本である。** 生成器が作るのは採用候補であって作品ではない。**採用は選別であり、著者が編集者である。**
- ⚠️ **⑥構成と⑦検収は書けない**——`clips[]` は定義上**採用テイクの列**であり、**動画のテイクに `adopted: true` が 1 本も無い。** **動かせないのであって、難しいのではない。**

## その他の固定方針

- **ショットは単位、役割は横断軸**——受け入れ基準は役割ごとに違う。単一の基準を全ショットに当てると、**当てた基準を満たすショットだけが残り、作品が同じ場面の反復になる。**
- **運動も横断軸**——役割が「そのショットの仕事」を決めるのに対し、運動は全ショットの下を流れる。**映画では運動が地であり、静止が特殊である。**
- ⚠️ **違反 0 件は「正しい」ではない。** 註と、検査されていない範囲を読む。
- ⚠️ **`L25` は `media/` を開かない**——記録と実物が食い違っても鳴らない。
- 文書の正典は英語、ミラーは接尾辞方式で**同じディレクトリ**（16 文書 × 3 言語）。
