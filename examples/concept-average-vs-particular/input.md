# 入力：平均 × 固有

生成AI時代、だれでも同じ水準のアウトプットを出せるようになった。価値の中心は「作る能力」から「見抜く能力」へ、そして「固有の一点を生むこと」へ移った。

- **平均**：多くの生成物は「正しいが誰のものでもない」——リスクを避け、平均を最適化し、紋切型に収束する。単独では何も間違えず、何も語らない。
- **固有**：たったひとつ、何かを間違える覚悟で独自の一点を目指すもの。借り物の記号に頼らず、その物語自身の小道具と仕草で真実を語る。
- **対比**：平均は「均一に並ぶ多くの同じもの」。固有は「その中でただ一つ、異なる光を放つもの」。

一枚の絵で、この「平均と固有」の対比を象徴的に示したい。ラベルや文字でなく、絵そのものが語る。
