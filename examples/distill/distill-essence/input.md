# 蒸留エンジン（distill-essence-engine）

概念：あらゆる入力を「そのもの自身の仕組み」で語る、一枚の英語画像プロンプトへ蒸留するエンジン。

- 入力は概念・URL・動画・長い文章——どんなものでもよい。
- しかし出力はいつも一点：本質だけを残し、他を削る。借り物の記号（電球・雨・鎖など）で説明しない。
- 本質とは「固有×間接」——特定のそのことを、そのこと自身の言葉で語る。概念が機能文書という仕組み（計画・手順・接続・働き・証明・記録）になる。
- 抑制＋一点のアクセント：余計なものを消し、本質が決する一点にだけ色を落とす。
- 語る一点＝**本質は一点の固有で、間接に語る**（概念がそのもの自身の仕組みになる）。
