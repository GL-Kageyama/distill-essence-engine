# 蒸留エンジン → 概念図・青図・設計図（出力サンプル）

- 入力: 概念「蒸留エンジン」（[distill-essence/input.md](../distill-essence/input.md) と同一）
- format: 概念図（conceptual-illustration）—— 固定。様式軸のみ差し替え
- style: 青図・設計図（blueprint-plan）—— 0.1.24 追加・検証済み（power-blueprint-plan 判定 PASS）
- 目的: 伝達（蒸留エンジンを、設計図という機能文書で解説する出力サンプル）
- trace: false（通常モード＝3欄のみ）

## 内容（Content）

蒸留エンジンを**設計図**として描く。語る一点＝本質は一点の固有で、間接に語る。断面図（section cut）で、エンジンの内部が見える——入力（概念・URL・動画・長い文章）が上から注がれ、蒸留の層を通り、下の一点（一枚の英語画像プロンプト）に落ちる。層は上へ行くほど狭く、本質でないものが押し出され、下の層の土台になる。赤鉛筆の印は、概念が「そのもの自身の仕組み」へ変わる蒸留の層に落ちる。小さな丸い人物が、同じ製図線で、エンジンに一つの入力を注ぐ。

## フォーマット（Format）

概念図：一枚の象徴的な絵で全概念を畳み込む。ビジュアルメタファー＝設計図そのものが概念の固有素材（断面＝蒸留の内部）。主従＝蒸留の層が主役、寸法線は従属の文法。テキストは担い手にしない（寸法線のみ）。

## 様式（Style）

青図・設計図：深いプルシアンブルーの地に細い白の製図線。寸法線・延長線・中心線。平坦・陰影なし・グラデーションなし。一点の赤鉛筆の印＝設計が決する点。語彙は `references/styles/blueprint-plan.md`。
