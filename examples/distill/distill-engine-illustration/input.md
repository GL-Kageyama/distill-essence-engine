# 入力：リポジトリ自身（distill-essence-engine）の本質

> 対象: 概念。あらゆる内容を、本質だけを残して一枚の画像プロンプトへ蒸留するエンジン、を表す一枚のイラスト。

## 概念の骨格

| 蒸留装置 | このエンジン |
|---|---|
| 多様な原料を入れる | 任意の入力（小説／記事／詩／文字起こし／メモ／論文 …）を受け取る |
| 加熱して本質を濃縮する | ①理解→②選定→③翻訳で本質だけを選び取る |
| 一滴の精が残る | 一枚の英語画像プロンプトが残る |

**比喩の対応**：フラスコ＝受け取った多様な入力、蛇管＝圧縮の工程（選定・翻訳）、黄金の一滴＝画像プロンプト。

## 語る一点

「多が一になる瞬間」。フラスコに多様な淡い断片（ページ・吹き出し・メモ・詩行）が漂い、蛇管を昇るにつれて細く融け合い、先端で**一滴の黄金**になる。多が一へ濃縮される、その因果を一枚に。

## 期待する雰囲気

教科書の実験図のような明快さと、静かなかわいさ。クリーンなライン・淡いパステル。図解（矢印やラベル）でなく、静かで丸みのある一枚のイラストとして。
