# 入力 — サイバー攻撃を「入口・足場・目的・出口」の四段に畳む

> 種別＝**調査ノート／解説の材料**。物語でも記事本文でもない。読んだのは、`07_参考資料` の8本（基礎概念・脅威と攻撃手法・防御技術・管理策・法規制・AI・中小企業の実務）と、そこが参照する一次情報（IPA「情報セキュリティ10大脅威 2026」、AI事業者ガイドライン第1.2版、総務省のAIセキュリティガイドライン）。作るのは、**私人が世の中の攻撃を「名前」ではなく「段」で整理する4枚**。**画像は生成しない**（`CLAUDE.md` §Verification。引くのは著者）。

## ① 何が来たか（理解）

### 名前は増える。段は減らない。

世の中のサイバー攻撃の情報は、**名前の洪水**である。フィッシング、ランサムウェア、ビジネスメール詐欺、サプライチェーン攻撃、APT、ディープフェイク、プロンプトインジェクション——名前は毎年増え、同じ手口が名前を変える。私人が名前を覚えても、次の名前には間に合わない。

**段は減らない。** どの攻撃も、**入口から入り、足場を作り、目的を果たし、出口で大きさが決まる**。名前はこの四段のどこかに必ず落ちる。落ちない名前は、いまの自分には関係がない。

この4枚は、**攻撃のカタログではなく、攻撃の地図**である。私人が持つべきは、名前の一覧ではなく、**四つの段のどこに自分がいるか**という位置感覚である。

### 四段モデル

| 段 | 問い | 下位の分類（例） | 接点の物 | キャプション |
|---|---|---|---|---|
| 1/4 入口 | どこから入るか | メール／電話／Web／機器 | スマートフォン | 入口は、あなたの端末の上にある。 |
| 2/4 足場 | 何を足場にするか | アカウント／端末／クラウド／回線 | 鍵 | 足場は、あなたの鍵の上にできる。 |
| 3/4 目的 | 何を狙うか | 金／情報／踏み台／信用 | 財布 | 目的は、あなたの暮らしの中にある。 |
| 4/4 出口 | どこで大きさが決まるか | 気づく／止める／戻す／届ける | レバー | 出口は、あなたの側にある。 |

**順番は優先順位ではない。** 四段は流れの順であって、危険度の順ではない。実際の攻撃は段を飛ばし、繰り返し、並行して進む。このモデルの値は、**新しい名前をどこかに置けること**にある。

**下位の分類は網羅ではない。** 各段の四つは、私人の生活に現れる代表例である。五つ目があっても、モデルは壊れない。

### 私人の現在地（IPA 2026）

IPA「情報セキュリティ10大脅威 2026」の**個人編は10項目・順位なし（五十音順）**である。順位が付くのは組織編だけで、個人編に順位を付けるのは誤りである。

個人編の10項目は、この四段にほぼ収まる。

| 段 | 個人編の項目（例） |
|---|---|
| 入口 | フィッシングによる個人情報等の詐取／メールやSNS等を使った脅迫・詐欺の手口による金銭要求／不正アプリによるスマートフォン利用者への被害 |
| 足場 | インターネット上のサービスへの不正ログイン／インターネット上のサービスからの個人情報の窃取 |
| 目的 | インターネットバンキングの不正利用／クレジットカード情報の不正利用／スマホ決済の不正利用／サポート詐欺（偽警告）による金銭被害／ネット上の誹謗・中傷・デマ |
| 出口 | どの項目も、気づく・止める・戻す・届けるで被害の大きさが変わる |

**重要な留保**：個人編に「AI」という独立項目はない。AI関連の項目は組織編3位の「AIの利用をめぐるサイバーリスク」である。したがって、この4枚では**AIを第五の段として描かない**。AIは、入口（声・顔・文面の複製）と目的（詐欺の説得力）を強める**増幅器**として、各段の中に溶かす。この区別を崩すと、日本の一次情報と食い違う。

## ② 語る一点（選定）

**シリーズの一点＝攻撃は「名前」で来ない、「段」で来る。私人が知るべきは手口の一覧ではなく、入口・足場・目的・出口のどこに自分がいるかである。**

**なぜこの一点か。** 名前は毎年増え、同じ手口が名前を変える。名前を覚える防御は、次の名前で破れる。段は減らない。どんな新しい手口も、入口から入り、足場を作り、目的を果たし、出口で大きさが決まる。**四段は、名前を置くための棚である。** この4枚は、その棚を一枚ずつ描く。

### 4枚の分担

| | 1/4 入口 | 2/4 足場 | 3/4 目的 | 4/4 出口 |
|---|---|---|---|---|
| 一点 | 入口は、一つではない | 入った者は、足場を探す | 目的は、四つに分かれる | 被害の大きさは、出口で決まる |
| 下位 | メール／電話／Web／機器 | アカウント／端末／クラウド／回線 | 金／情報／踏み台／信用 | 気づく／止める／戻す／届ける |
| 接点 | スマートフォン | 鍵 | 財布 | レバー |
| 灰色の線 | 四本が一点に集まる | 四つを順に回る | 四本が一点に集まる | レバーで切れる |
| 金 | 画面の左端の一点 | 鍵の頭の一点 | 財布の留め金の一点 | レバーの支点の一点 |
| キャプション | 入口は、あなたの端末の上にある。 | 足場は、あなたの鍵の上にできる。 | 目的は、あなたの暮らしの中にある。 | 出口は、あなたの側にある。 |

### 各枚の一点

- **1/4 入口**：**入口は、一つではない。** 攻撃は、人が信じているチャネルから入る。メール、電話、Web、機器。四つの引き出しは、どれも同じ大きさで並ぶ——**優劣ではなく、並列**である。四本の灰色の線が一点に集まり、スマートフォンに着く。**入る場所は違っても、着く先は同じ**。
- **2/4 足場**：**入った者は、足場を探す。** アカウント、端末、クラウド、回線。一度入った者は、奪ったものを次の足場にする。灰色の線は四つを順に回り、最後に鍵に着く。**足場が増えるほど、被害は広がる**。鍵は、足場の代表である。
- **3/4 目的**：**目的は、四つに分かれる。** 金、情報、踏み台、信用。同じ手口でも、狙いは違う。四本の線は右の縁の一点に集まり、そこから一本だけ財布へ伸びる。財布は閉じている。**中身は一つに決めつけない**。**目的は、あなたの暮らしの中にある**。
- **4/4 出口**：**被害の大きさは、出口で決まる。** 気づく、止める、戻す、届ける。灰色の線は、気づくから止めるへ進み、レバーで切れる。切れた先から、淡い青の線が戻すと届けるへ伸びる。**同じ攻撃でも、出口の四つで大きさが変わる**。金は、レバーの支点にある。

### 潰す誤読

| 誤読 | なぜ嘘か | だから描かないもの |
|---|---|---|
| (a) 攻撃者は悪い人 | 攻撃者は人物ではなく、**段と経路**である。フードの人物を描くと、問題が「悪い人がいる」に縮む | ハッカー・フード・マスク・スカル |
| (b) 赤い警告 | 攻撃は**静かで、淡く、手続き的**である。赤と警報は、汎用のサイバー警告ポスターになる | 赤い警告・警報・点滅・雷 |
| (c) 四段は優先順位 | 四段は**流れ**であって、危険度の順ではない。番号を順位と読ませると、対策の順序を誤る | 1位・2位・順位の数字・王冠・メダル |
| (d) 四段で全攻撃を網羅 | 四段は**名前を置く棚**であって、全手口の一覧ではない。足すほど、どの段も薄くなる | 攻撃名の一覧・10大脅威の全項目・年表 |
| (e) AIは第五の段 | AIは**増幅器**。個人編にAI項目はない。第五の段にすると、一次情報と食い違う | ロボット・光る脳・回路基板・AIの顔 |
| (f) 金は「正解」 | 金は**あなたの位置**であって、正しい行動ではない。金を正解の印にすると、行動メモになる | チェックマーク・「正解」の文字・勝利の矢印 |

## ③ 翻訳（抽象 → 視覚）

| 抽象 | 具象へ |
|---|---|
| **入口は一つではない** | **四つの開いた引き出し。** メール（小さな画面の封筒）、電話（受話器）、Web（白い窓）、機器（USB）。四本の灰色の線が、右の縁の小さな点に集まり、棚のスマートフォンに着く |
| **足場は積み重なる** | **四つの引き出しを巡る一本の線。** アカウント（札の付いた鍵）、端末（ノートPC）、クラウド（細い線で上につながる箱）、回線（ルーター）。線は四つを順に回り、最後に棚の鍵に着く |
| **目的は四つに分かれる** | **閉じた財布。** 金（カード）、情報（IDカード）、踏み台（矢印の入る箱）、信用（白い名札）は、四つの引き出しが示す。四本の線は右の縁の一点に集まり、そこから一本だけ財布へ伸びる。**中身は一つに決めつけない** |
| **出口で大きさが決まる** | **レバーで切れる線。** 気づく（淡黄のランプ）、止める（弁）、戻す（戻り矢印の箱）、届ける（封をした書面）。灰色の線はレバーで切れ、淡い青の線が戻すと届けるへ伸びる |
| **あなたの位置** | **金の測量点。** 小さな円と短い縦線と横線。**攻撃の線が接点の物に触れる、その一点**に置く。4枚とも同じ高さ。ラベルは「あなた」 |
| **攻撃は静かである** | **淡い灰色の線。** 太くない。矢印は小さい。赤も、光も、音もない。**目立つのは、金の一点だけ** |

## ④ 同一の世界（4枚の文法）

- **一枚の図。** 各枚は分割しない。パネルも、枠も、コマもない。上から下へ読む。
- **同じ配置。** 左上に小さな番号（1/4〜4/4）、上に大きな見出し、その下に小さな副見出し、左に**四つの引き出しの棚**、右中段に**接点の物**と**金の測量点**、下に一行のキャプション。右上と左下は余白。**中央対称にしない。**
- **同じ棚。** 四つの開いた引き出しを2×2に並べる。前面に短いラベル、中に小さな物。引き出しの縁は細いインク線と淡い灰の断面。**重いハッチも、3Dの陰影も置かない。**
- **同じ接点。** 右中段の細い棚に、接点の物を一つ。4枚とも同じ位置、同じ大きさ。スマートフォン、鍵、財布、レバー。
- **同じ金。** 金は**攻撃の線が物に触れる一点**だけ。4枚とも同じ形・同じ高さ。**金は「あなた」**。正解の印でも、警告でもない。
- **同じ線。** 攻撃は淡い灰色の細い線。小さな矢印。4/4だけ、レバーの先から淡い青の線が伸びる。**灰色は攻撃、青は回復、金はあなた**。
- **同じ文字。** 短い日本語だけ。見出し、副見出し、四つのラベル、`1/4`、`あなた`、キャプション一行。**本文も、長い説明も、画面の中の文字も置かない。**
- **同じ色。** 生成り、淡い灰、淡いミント、淡い青。**淡黄は4/4のランプだけ**。飽和するのは金の測量点だけ。
- **同じ余白。** 右上と左下を空ける。要素を詰めない。**情報の階層は、余白で作る。**

## ⑧ 変えないもの（忠実）

- **順位を付けない**：四段は流れの順。1位・2位と書かない。番号は `1/4` の位置表示だけ。
- **網羅しない**：各段の四つは代表例。五つ目を足してもモデルは壊れない、と本文に残す。
- **AIを第五の段にしない**：AIは増幅器。個人編にAI項目はない、という一次情報の形を保つ。
- **数字を画像に入れない**：被害額・件数・成功率は input.md に置く。画像は関係だけを描く。
- **私人を愚かにしない**：被害者を描かない。手も、顔も、涙も、パニックも描かない。**この4枚は、責める画ではない。**
- **行動メモにしない**：キャプションは「〜しなさい」ではなく「〜である」。金は「あなたの位置」であって「正解」ではない。
- **財布は一例**：3/4の財布は、四つの目的を代表しない。四つは引き出しが示す。財布は「あなたの暮らしの中」の一例である。中身は描かない。
- **実在のロゴ・人物を描かない**：銀行・SNS・キャリアのロゴ、実在の顔。画面の中の文字は置かない。
- **攻撃を格好よくしない**：ネオン、回路、フード、スカル、マトリクス。**攻撃は淡く、静かで、手続き的**である。
