# 入力：都庁プロジェクションマッピング「あり得たかもしれない」5案 —《渦より立つ東京》

> 建築イメージの作例シリーズの派生。実在の**東京都庁第一本庁舎**をキャンバスに、実際には上映されなかった**もう一つの投影マッピング**（オルタナティブ・ヒストリー）を15案作り、その写真用プロンプトを生成する。今回は「**東京、そして日本の古今を象徴する、印象的なモチーフ**」を、どれも別の**種類**から選び、かつ建築との**関係**（動詞）も別にする。15案は、元画像の**渦**を共通の発生装置として、一つの連作《渦より立つ東京》をなす。**三つの楽章**：01〜05 は**東京の貌**（都市の人流・演劇・夜景・気象・光）、06〜10 は**日本の貌・古層**（工芸・考古・庭・書・音）、11〜15 は**日本の貌・現代風俗**（機械・食・宿・入浴・遊び）——都市から古層へ、そして今の日常へ降りてくる。

## 前提（なぜ「オルタナティブ」か）

東京都庁第一本庁舎（丹下健三・1991年・48階・約243m・ツインタワー）の東側壁面には、2024年2月25日から**「TOKYO Night & Light」**としてプロジェクションマッピングが**通年・常設**上映されている。都民広場から無料で観覧でき、初日には「最大の建築物へのプロジェクションマッピングの展示（常設）」として**ギネス世界記録**に認定された。30分おきに約10〜15分の上映で、内容は**ゴジラ／パックマン／ガンダム**など**ポップカルチャーのIP**が主役である。

本作は、その「実在の上映」の並行宇宙を描く。ポップカルチャーの借用ではなく、**東京そのものを象徴する芸術的なモチーフ**5種を、どれも別の種類から選び、この建築に食い込む形で立たせる。「あってもおかしくなかった」もう一つの東京の肖像。

## 元画像の参照（reference）

## 渦という共通の発生装置（元画像との対話）

元画像の**渦を巻く光**は、単なる「捨てる旧物」ではない。これを**都民広場の渦＝都市の渦**として転用し、5案すべての**発生装置**にする。どの案も、この渦が「回ってほどけ、別の東京へ変わる」ことから始まり、終わると渦に戻る。

| 案 | 渦の立ち上がり方（開始の一歩） |
|---|---|
| 01 渋谷 | 渦がほどけて、交差点の人の螺旋（集散そのもの）になる |
| 02 歌舞伎 | 渦が花道のすり足の回り＝役者の回りになり、見得で静止する |
| 03 東京湾 | 渦が渦潮＝海になり、埋め立ての螺旋として湾へ広がる |
| 04 雷雨 | 渦が積乱雲の螺旋となり、上空で渦巻いて稲妻を吐く |
| 05 ネオン | 渦が回転看板の螺旋となり、看板が螺旋を描いて登る |
| 06 金継ぎ | 渦が割れた器の底になり、切れ込み（割れ目）から金の釉が流れ出る |
| 07 縄文 | 渦が縄文の渦巻文そのものになり、広場の渦が日本最古の渦文と重なる |
| 08 枯山水 | 渦が砂紋の渦巻きになり、白砂に梳かれた渦として広がる |
| 09 書 | 渦が筆の起筆（筆先の渦）になり、一筆へ展開する |
| 10 風鈴 | 渦が風の渦になり、風が渦巻いて鈴を揺らす |
| 11 自販機 | 渦が深夜の光の溜まりになり、ぽつんと一人で灯る |
| 12 回転寿司 | 渦が回転レーンそのものになり、螺旋のレーンが塔を登る |
| 13 カプセル | 渦が眠りの螺旋（夜の深さ）になり、全階が眠る |
| 14 銭湯 | 渦が湯気の螺旋になり、湯気が塔を立ち上る |
| 15 ガチャ | 渦がハンドルの回転になり、カプセルが溢れ出る |

これにより5案は「5枚の別案」ではなく、**一つの都市が身に着ける五つの貌**として連続する。渦を使うこと自体が⑧に忠実（画像に既にある要素）かつ particular（この一枚にだけある要素）。

## 建築のポテンシャル（各案が食い込む形）

| 建築の部位 | 形 | マッピングが活かす力 |
|---|---|---|
| **ツインタワー** | 東西に並ぶ二本の垂直な塔（243m/48F） | 「二つの◯◯」——二つの貌・二つの岸・二本の避雷針・二つの看板壁 |
| **中央の切れ込み** | 二塔の間の深い谷／柱間の空 | 「渡るもの／割れるもの」——橋・幕・稲妻・路地。視線が通る肺 |
| **格子ファサード** | 縦横のピンストライプの金属グリッド | 「繰り返し」——縞・隈取りの線・街の窓・看板の列。写像の走査線 |
| **都民広場** | 半円形の開けた広場＋鏡のような磨き床 | マッピングの「舞台」＋**渦**（共通の発生装置）。床への反射で上下が交わる |
| **高さ** | 243m | スケールの逆転——塔が街を抱き、街が塔に降りる |

丹下の外観は「壮麗なゴシック教会のようだ」「ノートルダム大聖堂に似たプロポーション」と評され、壁面に映像が映っても「超然たる雰囲気は変わらない」。この**権威ある垂直性**こそ、各案が折り合う基準線。

## 5案のコンセプト（全モチーフ・全関係が別種）

「建築との関係」を**対応づけ（二塔＝◯◯の半分）に固定しない**。関係の動詞を案ごとに変える（**回す／演じる／着る／受ける／積む**）。これが5案を単なる「お題の投影」から、**この建物にだけ起こる出来事**へ持ち上げる。モチーフの**種類**も重複しない（人流／演劇／夜景地図／気象／光）。

## 各案の時間アーク（開始 → 転回 → 余韻）

プロジェクションマッピングは本来、動きと音楽を伴う**時間的メディア**（実在上映も10〜15分番組）。そこで各案を**3モーメントのアーク**で設計し、**転回（＝最大の瞬間）だけを静止画プロンプト**に落とす。モーションとミュージックは、その瞬間を「来る／去る」として支える設計注記（詳細は prompt.md）。

- **開始**：渦が立ち上がり、モチーフが建築に染み込む（第1モーメント）。
- **転回**：モチーフが建築と衝突・停止する最大の瞬間（第2モーメント）＝ **静止画の対象**。
- **余韻**：モチーフが解けて渦へ戻る（第3モーメント）。

静止画は「塔が◯◯をまとった一枚」ではなく、**動きの頂点で止まった一枚**（admiration＝予測を超えつつ必然）であるべき。ここに時間の非対称（各案で「遅い／一瞬／速い」の割り振りが異なる）を織り込む。
