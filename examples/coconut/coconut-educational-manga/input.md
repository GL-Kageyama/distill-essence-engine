# 入力：arXiv 2412.06769（Coconut）を教える学習漫画

> 対象: 論文。**Training Large Language Models to Reason in a Continuous Latent Space**（連続潜在空間で推論するようLLMを訓練する）。
> 著者: Shibo Hao, Sainbayar Sukhbaatar, DiJia Su, Xian Li, Zhiting Hu, Jason Weston, Yuandong Tian（Meta FAIR / UC San Diego）。COLM 2025採録。
> `https://arxiv.org/pdf/2412.06769` のHTML全文（v4）から抽出した内容。数値は本文に忠実。

## 概念の骨格

| この論文 | 教えるべきこと |
|---|---|
| CoT（Chain-of-Thought）は「言葉で考えさせる」 | ① 言葉は伝えるため。考えるためじゃない |
| 神経科学：言語ネットワークは推論中ほぼ不活性。言語はコミュニケーションに最適化 | ② 人間は言葉なしでも推論する |
| 最後の隠れ状態（last hidden state）を単語にデコードせず、次の入力埋め込みとしてそのままフィードバック | ③ 連続思考（continuous thought）＝言葉にしない思考 |
| `<bot>`／`<eot>` で言語モード（話す）と潜在モード（黙って考える）を切り替え | ④ 話す／黙るのスイッチ |
| 言葉を書き出す＝単一経路へ早期コミット。連続思考＝複数候補を並列に保持 | ⑤ 一本道 vs 枝分かれした木（幅優先探索） |
| ProsQA（探索が必要な論理推論）で CoT 77.5% → Coconut 97.0%、トークン 49.4 → 14.2 | ⑥ 探索が要る問題で言葉に勝つ |
| 枝分かれ探索は誰も教えていないのに創発。言語思考を1歩ずつ連続思考へ置換する多段階カリキュラムが前提 | ⑦ 探索は自然に生まれた。カリキュラムなしでは失敗 |

## 機構（詳説）

標準LLMは `H_t = Transformer(E_t)`、次の単語は `softmax(W h_t)`。Coconut はこの **最後の隠れ状態 `h_t` を単語トークンにデコードせず、そのまま次の入力埋め込みとしてモデルに戻す**。これを「continuous thought」と呼ぶ。連続思考は完全に微分可能で、勾配降下により end-to-end で最適化できる。

- **言語モード**＝標準的な次トークン自己回帰生成（声に出して話す）。
- **潜在モード**＝直前トークンの最後の隠れ状態を次の入力として使う（`<bot>`〜`<eot>` の区間。黙って考える）。この区間では `softmax(W h_t)` による単語出力は定義されない（探索目的で計算は可能）。
- **多段階カリキュラム**：最初は普通の CoT で訓練し、第 k 段階で CoT の最初の k 個の言語推論ステップを `k×c` 個の連続思考に置換（c＝1言語ステップを何個の潜在思考で置換するか）。損失は質問部と潜在思考部をマスク——連続思考は「消した言語思考の圧縮」でなく「将来の推論を予測しやすくする表現」を学習する。**カリキュラムなしで最終段階を直接訓練すると失敗**（GSM8k 14.4%、ProntoQA 52.4%、ProsQA 76.1%）。

## 実験結果（抜粋）

| 手法 | GSM8k（数学） | トークン | ProntoQA（論理） | トークン | ProsQA（探索型論理） | トークン |
|---|---|---|---|---|---|---|
| CoT | 42.9 | 25.0 | 98.8 | 92.5 | 77.5 | 49.4 |
| No-CoT | 16.5 | 2.2 | 93.8 | 3.0 | 76.7 | 8.2 |
| Pause Token | 16.4 | 2.2 | 77.7 | 3.0 | 75.9 | 8.2 |
| **Coconut** | **34.1** | 8.2 | **99.8** | 9.0 | **97.0** | 14.2 |

- **探索が必要な ProsQA で最大の差**：CoT 77.5% → Coconut 97.0%（約20ポイント上回る）を、トークンは約3分の1（49.4→14.2）で達成。CoT は存在しないエッジの幻覚（hallucination）や誤った目標への経路出力を頻発。
- **数学（GSM8k）**は CoT（42.9%）に届かない（34.1%）が、No-CoT・Pause Token は上回り、精度と効率のトレードオフで優位。
- **推論時間**（A100、秒/ケース）：ProsQA で CoT 0.47 → Coconut 0.15。生成トークン数にほぼ比例。

## 潜在推論の解釈（創発する幅優先探索）

- **BFS は一切明示的に教えていない**のに、推論時に複数の代替ステップを並列に符号化する挙動が創発。CoT のように単一の決定的経路に早期コミットしない。
- **ProsQA のケーススタディ**：第1連続思考後は第1候補「lempus」の予測確率 0.33 が最高だが、第2連続思考後は別候補「rorpus」が 0.87 に。greedy に追わず、経路を探索的に絞り込む。
- **価値関数としての解釈**：連続思考後の各概念の予測確率を「暗黙の価値関数」とみなすと、目標に近いノードほど判定が正確・高確信になる。**決定的判断を遅延させ、終端近くで正確な評価をする**ことが複雑な計画タスクで CoT の貪欲法を上回る理由。
- **デコード解釈**（GSM8k）：第1連続思考を言語へデコードすると計算の中間変数（数量の差・割り算の結果）に対応することが多い。

## 語る一点

「考えるのに言葉はいらない」。CoT は考えを全部**話させる**——言葉は伝えるためであって考えるためではないから、一本道の文章に早々とコミットして引き返せない。Coconut は最後の隠れ状態を**言葉にせずそのまま自分へ戻す**ことで、黙ったまま複数の候補を枝分かれに並列保持し（幅優先探索）、確信が持てた時にだけ言葉にする。探索が要る問題で言葉より正確に、しかも3分の1の語数で解く。この枝分かれ探索は誰も教えていないのに自然に生まれ、言語思考を1歩ずつ連続思考へ置き換える訓練カリキュラムがその前提になる。
