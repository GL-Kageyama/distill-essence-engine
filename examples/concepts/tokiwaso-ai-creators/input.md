# 入力：トキワ荘 AIクリエイター version（概念）

> 対象: 概念。1952–54 年、東京・椎名町の木造アパート「トキワ荘」に、手塚治虫をはじめとする若いマンガ家たちが集まった——日本の戦後マンガの揺籃。その同じ場所を、2020 年代の AI クリエイターの共同生活として読み替える。**建物は実在のまま。デジタルは一部だけ滲む。**

## 読み替えの骨格（残るもの・変わるもの）

| 1950 年代のトキワ荘 | AI クリエイター version |
|---|---|
| 風呂なし・共同炊事場の木造二階建て | 同じ建物、同じ間取り（変わらない） |
| 原稿を描く若者 | 生成し、選び、直す若者 |
| 締切と原稿料 | 納期とクレジット |
| 互いの原稿を回し読みする | 同じ画面を覗き込む |
| 編集者が原稿を取りに来る | 通知が届く |
| 新しい表現（マンガ）に群がる | 新しい表現（生成 AI）に群がる |
| 夜、豆電球と原稿 | 夜、豆電球と画面と——窓の外の光 |

## 語る一点

**宵、障子が一枚開いている。三人の住人がいる。誰も、その開口を見ていない。**

開いた障子の外は、黄昏。**繊細なのは空だけ**——雲が層をなし、マゼンタと金が影の深いシアンに沈む。その下、開口の下端に、**屋根は大きく平らな暗いシルエットで二、三枚だけ**。瓦は描かない。**いちばん遠い屋根の稜線だけが細かい正方形へほどけ**、その先はもう屋根ではなく、**光の格子の帯が水平に地平まで走っている**。その開口から、**一本だけ**光の柱が畳へ差し込む——柱の縁も、空気の中で細かい格子として見える。柱の中に埃が浮いている。

室内に灯りは三つ。天井の裸電球（暖かい橙）、畳の上のノート PC の画面（冷たい青白）、そして窓から差し込む柱（マゼンタと金）。**三つの中でいちばん強いのは、窓の光。機械の光は、窓の光より弱い。**

三人は顔を見せない。**二人は寄り添って、同じ画面を見ている**——胡座をかいた一人の前に PC が開き、もう一人が隣に肩を寄せ、頭を近づけて同じ冷たい画面を覗き込む。**画面でこの二人だけがひとつの形になる**。三人目は離れてちゃぶ台に向かい、紙にペンを走らせている。片手で紙を押さえ、**もう一方の手は畳の上に開いたまま忘れられている**。

**誰も開口を見ていない。** 二人は画面の中に、一人は紙の中にいる。**畳の上に忘れられた、開いた手のひら一本だけが、そちらを向いている。**

## 期待する雰囲気

ノスタルジーではなく、**同じ夜の別のバージョン**。感傷に寄せない。デジタルは機械として室内に置かず、**世界の縁が升目へ解ける**という一点だけで示す。**交流は説明しない——二人の距離が説明する。** 静かで、少し寒い。ただし冷たくはない。
