# 走れメロス → スプライトシート

- 入力: [melos-imageboard/input.md](../../melos-imageboard/input.md)（走れメロス）
- format: スプライトシート（未検証・ゲーム素材）—— フォーマット軸のみ差し替え
- style: ピクセル（検証済み）

## 内容（Content）
同一キャラ（メロス）の走るポーズ列。立ち→走り出し→疾走→疲労→到着。

## フォーマット（Format）
グリッド・正方形タイル、各セルで一貫したピクセルサイズと配色、アニメ用に連続した動作。

## 合成プロンプト（Merged）
A pixel-art sprite sheet of Melos running, 8 cells on a grid. The same character in sequence: standing, first step, sprint, full dash with the mantle streaming, stumbling, fatigue, recovering, arriving. Consistent pixel size, consistent palette (black, crimson, skin, sky blue) across all cells, the same ground line and character height in every cell, sequential motion for animation, hard-edged pixels. No anti-aliasing, no gradients, no photorealistic, no 3D render.
