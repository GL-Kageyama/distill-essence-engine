# 入力：Suicaオルタナティブ案㉕ ヒヨコ「ヒヨコ」（はじまる・新しい一日）

> 対象: 架空のSuica新イメージキャラクター候補（非公式・本投票3案とは別の、あり得たかもしれない案）。既存キャラ（ペンギン・リス・ウサギ・モグラ）の模倣を避けた独自案。

## キャラクターの骨格

| 項目 | 内容 |
|---|---|
| モチーフ | ヒヨコ。生まれたばかりのひな。やわらかい黄色 |
| 通称案 | 「ヒヨコ」 |
| 体色 | やわらかい黄色（Suicaの緑と相性の良い、春を思わせる配色）＋小さな目 |
| 概念（動詞） | **はじまる・新しい一日** |
| 性格 | 小さくて、ぴょこぴょことした健気さ。静かに朝を迎える |

## なぜSuicaに合うか（ブランドとの対応）

- **はじまり＝朝**：ヒヨコは生まれたばかり＝「はじまり」。毎朝の通勤＝新しい一日のはじまり＝Suicaとともに。
- **黄色＝緑と相性**：やわらかい黄色はSuicaの緑と相性が良く、カードに並ぶと春のように明るく映える。
- **小さい＝健気**：小さな体で、ぴょこぴょこ付いていく健気さ。
- **くちばし＝タッチ**：小さなくちばしで、カードをそっとタッチする仕草そのもの。

## 語る一点（物語）

小さなヒヨコが、朝の改札にちょこん。黄色い体が、緑のカードのそばでぽっと明るい。くちばしでそっと「ピッ」。今日という新しい一日が、ここからはじまる。

- 黄色＝Suicaの緑と相性の良い春の色。
- はじまり＝朝の通勤＝新しい一日。
- くちばし＝改札のタッチ。

## 使用シーン（イメージボードの小パネルで描く）

> ※ 実際のSuicaカードでは、キャラはカード面の**右端**に、**やや小ぶりに**印刷される（既存ペンギンを置き換え）。

1. 朝の改札で、新しい一日のはじまりをちょこんと迎える。
2. くちばしで、カードをそっとタッチする。
3. 朝の光の中で、静かに一日の始まりを見守る。

## 期待する雰囲気

小さくて、明るくて、はじまりの健気さ。黄色い丸い体・小さなくちばし・ぴょこぴょこした愛嬌。日本の交通系マスコットの「やわらかい平塗り」で、光沢やグラデは使わない。
