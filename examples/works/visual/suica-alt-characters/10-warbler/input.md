# 入力：Suicaオルタナティブ案⑩ ウグイス「ウグイス」（告げる・発車を告げる）

> 対象: 架空のSuica新イメージキャラクター候補（非公式・本投票3案とは別の、あり得たかもしれない案）。既存キャラ（ペンギン・リス・ウサギ・モグラ）の模倣を避けた独自案。

## キャラクターの骨格

| 項目 | 内容 |
|---|---|
| モチーフ | ウグイス（鶯）。「ホーホケキョ」と鳴く春告鳥。発車・到着を知らせる |
| 通称案 | 「ウグイス」（＝春告鳥。旅立ちを知らせる） |
| 体色 | ウグイス色（＝Suicaグリーンそのもの）＋白い腹＋ほんのり桜色の頬 |
| 概念（動詞） | **告げる・知らせる（発車を告げる）** |
| 性格 | 声が澄んでいて気持ちがいい。発車の合図を、やわらかく正確に告げる |

## なぜSuicaに合うか（ブランドとの対応）

- **告げる**：ウグイスは「ホーホケキョ」と春の訪れを告げる「春告鳥」。駅では発車・到着・乗り換えを「告げる」＝アナウンスの化身。
- **ウグイス色**：ウグイスの体色「ウグイス色」は、そのままSuicaグリーン。ブランドカラーを体そのものが持つ（カワセミ・カエルと同型）。
- **澄んだ声**：発車メロディや駅アナウンスのように、やわらかくて澄んだ声。通勤の耳に心地よい。
- **春・旅立ち**：春告鳥＝新しい一日の始まり＝通勤の朝。旅立ちと再会を告げる。

## 語る一点（物語）

朝のホームに、澄んだ声が一つ。「まもなく、次の電車が参ります」。それはウグイスの「ホーホケキョ」。ウグイス色の小さな鳥が、枝の上から発車を告げ、あなたの一日の始まりをやわらかく押し出す。

- ウグイス色の体＝Suicaグリーンそのもの。
- 開いた小さなくちばし＝発車を告げる声。
- ほんのり桜色の頬＝春・旅立ちの温かさ。

## 使用シーン（イメージボードの小パネルで描く）

> ※ 実際のSuicaカードでは、キャラはカード面の**右端**に、**やや小ぶりに**印刷される（既存ペンギンを置き換え）。

1. 朝のホームで、木の枝（＝案内標）に止まって発車を告げる。
2. 改札の上で、カードをタッチする人に「いってらっしゃい」とひと鳴き。
3. 電光掲示板のそばで、行先を「知らせる」。

## 期待する雰囲気

清らかで、声が澄んで、朝に爽やか。小さく丸い体・ウグイス色・短く開いたくちばし。かわいさは「小さな体から響く澄んだ声」。日本の交通系マスコットの「やわらかい平塗り」で、光沢やグラデは使わない。
