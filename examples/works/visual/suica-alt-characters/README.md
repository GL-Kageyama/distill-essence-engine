# Suicaオルタナティブ・キャラクター15案

> 2026年9月、JR東日本が「Suicaのペンギン」後継の新イメージキャラクター候補を3案発表し投票を開始した。本ディレクトリは、その**本投票3案とは別に「あり得たかもしれない」オルタナティブ案を15つ**、`distill-essence-engine` で画像プロンプトまで蒸留したもの。**非公式の創作演習**であり、JR東日本の公式発表・商標とは一切関係ない。

## 前提：守ったもの（Suicaのブランド骨格）

- **スイスイ**：Suicaの語源。ペンギンが「スイスイ泳ぐ」滑らかさ。新キャラにも「滑らかに動く」を必須とした。
- **スイカグリーン**：ブランドカラー。15案すべて、体色または身に着けるものでこの緑を持つ。
- **毎日のパートナー**：「Suica Renaissance」が掲げる「移動・決済から生活のデバイスへ」。単なる動物でなく「生活に寄り添う存在」を前提にした。
- **25年の暖かさ**：老若男女・国内外に愛される、丸く・親しみやすく・やや控えめな佇まい。

## 各ディレクトリの構成

```
01-kingfisher/
├── input.md    # キャラクターの概念（モチーフ・色・物語・使用シーン・ブランド対応）
└── prompt.md   # 3欄（内容/フォーマット/様式）＋合成プロンプト（英語）
```

各 `prompt.md` は、`distill-essence-engine` の出力規約どおり **合成プロンプトは英語** で、**1枚のイメージボード（imageboard）**を出す。

- **大きな焦点（キャラ単体）**：キャラだけが表示される、背景なしの全身。
- **小パネル（使用イメージ）**：実物のSuicaカードを、**既存ペンギンを廃して新キャラがカード面の右端に印刷された**形で使う実写シーン（朝の改札タッチ／テーブルの上／雨の帰り道／夜の終電／夕方の駅前など）。
- **短文キャプション**：「カワセミ ── 先を照らす」のように、動物の種類名＋コンセプトを1行で添える。

## 画像の生成・合成手順

1. `prompt.md` の合成プロンプトを画像生成AI（ChatGPT Image / Firefly / Midjourney / SD など）に貼って、**1枚のイメージボード**を生成する。
2. 実物のSuica写真を使う場合は、大きな焦点のキャラ単体を背景透過で生成し、**カード面の右端**に印刷風に合成する（既存ペンギンは載せない）。
3. 使用イメージでは、キャラはカードに「印刷された」形（ペンギンに代わる位置）にする。

## 様式（style）について

本15案で使う「**やわらかい平塗りマスコット（soft flat mascot）**」は、本15案を初回ケースとしてレジストリ（[references/registry.md](../../references/registry.md)）に**登録済み**。検証は**待ち**（判定は追って `examples/EVALUATION.md` へ）。

> なお、①〜⑨は**細い輪郭線**、⑩〜⑮は**輪郭線なし（線なしフラット）**のバリアントで描いている。輪郭線なしの案は、キャラ単体・カードに合成したキャラの双方とも縁取りを付けない。
