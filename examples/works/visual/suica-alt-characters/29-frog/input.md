# 入力：Suicaオルタナティブ案㉙ カエル「カエル」（帰る・無事に帰る）

> 対象: 架空のSuica新イメージキャラクター候補（非公式・本投票3案とは別の、あり得たかもしれない案）。既存キャラ（ペンギン・リス・ウサギ・モグラ）の模倣を避けた独自案。

## キャラクターの骨格

| 項目 | 内容 |
|---|---|
| モチーフ | カエル。緑の体。ぴょんと跳ぶ。四本足（前足2本＋後ろ足2本） |
| 通称案 | 「カエル」 |
| 体色 | やわらかい緑（Suica緑そのもの）＋白い腹＋大きな丸い目 |
| 概念（動詞） | **帰る・無事に帰る** |
| 性格 | 小さくて、健気で、必ず帰る |

## なぜSuicaに合うか（ブランドとの対応）

- **帰る＝交通の本質**：カエルは「帰る」の語呂。通勤＝行って、無事に帰る。毎日の「帰る」をそっと見守る。
- **緑＝Suica緑そのもの**：カエルの緑は、自然の色そのものがSuicaの緑。カードに並ぶと、そのまま馴染む。
- **ぴょん＝前へ進む**：ぴょんと跳んで、前に進む。でも必ず帰る。前に進みながら、帰る場所を持つ。
- **四本足＝IP展開**：前足が「手」になるので、カードを持ったり、跳ぶポーズを取らせたりしやすい。丸い体と大きな目で、キーホルダー・フィギュアに載せやすい。

## 語る一点（物語）

緑のカエルが、ぴょんと跳んで前に進む。大きな目で、行き先と帰る場所を見ている。前足の手でそっと「ピッ」。今日も、無事に帰る道を、静かに見守る。

- 帰る＝無事に帰る、待つ人の安心。
- 緑＝Suica緑そのものの自然色。
- 前足の手＝改札のタッチ。

## 使用シーン（イメージボードの小パネルで描く）

> ※ 実際のSuicaカードでは、キャラはカード面の**右端**に、**やや小ぶりに**印刷される（既存ペンギンを置き換え）。

1. ぴょんと跳んで、前に進む。
2. 前足の手で、カードをそっとタッチする。
3. 改札のそばで、無事に帰る道を静かに見守る。

## 期待する雰囲気

小さくて、健気で、帰る安心。緑の丸い体・白い腹・大きな目・前足の手。かわいさは「必ず帰る健気さ」。四本足で、腕や脚でポーズを取らせやすい。日本の交通系マスコットの「やわらかい平塗り」で、光沢やグラデは使わない。
