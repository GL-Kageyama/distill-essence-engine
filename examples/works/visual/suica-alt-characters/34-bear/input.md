# 入力：Suicaオルタナティブ案㉞ クマ「クマ」（守る・大きな安心）

> 対象: 架空のSuica新イメージキャラクター候補（非公式・本投票3案とは別の、あり得たかもしれない案）。既存キャラ（ペンギン・リス・ウサギ・モグラ）の模倣を避けた独自案。

## キャラクターの骨格

| 項目 | 内容 |
|---|---|
| モチーフ | クマ。二足で立ち上がる姿が象徴的（立ちキャラ）。四本足で、前足が腕になる |
| 通称案 | 「クマ」 |
| 体色 | こげ茶（森の土）＋クリーム色の腹＋丸い耳 |
| 概念（動詞） | **守る・大きな安心** |
| 性格 | 大きくて、静かで、見守る |

## なぜSuicaに合うか（ブランドとの対応）

- **守る＝安全・安心**：大きな体で、静かに見守る。交通の安心＝守る、という本質に寄り添う。
- **立ち上がる＝見守る**：二足で立ち上がる姿は、そっと見守る姿そのもの。腕を振って迎えられる。
- **こげ茶＝森の土**：深いこげ茶は、森の緑に溶け込む自然な色。カードに並ぶと、どっしり落ち着く。
- **立ちキャラ＝IP展開**：前足が腕になるので、腕を振ったり、カードを持ったり、抱きしめるポーズも取らせやすい。ぬいぐるみの定番。

## 語る一点（物語）

こげ茶のクマが、二足で立ち上がって、そっと見守っている。大きな体で、でも静かに。腕の手でそっと「ピッ」。今日も、あなたの道を、大きな安心で守る。

- 守る＝安全・安心、静かな見守り。
- こげ茶＝森の土、緑に馴染む。
- 腕の手＝改札のタッチ。

## 使用シーン（イメージボードの小パネルで描く）

> ※ 実際のSuicaカードでは、キャラはカード面の**右端**に、**やや小ぶりに**印刷される（既存ペンギンを置き換え）。

1. 二足で立ち上がり、腕を振って迎える。
2. 腕の手で、カードをそっとタッチする。
3. 大きな安心で、静かに寄り添う。

## 期待する雰囲気

大きくて、静かで、守りの健気さ。こげ茶の丸い体・クリーム色の腹・丸い耳・腕の手。かわいさは「大きな安心で守る健気さ」。**立ちキャラ（二足で直立）**で、腕でポーズを取らせやすい。日本の交通系マスコットの「やわらかい平塗り」に、**ごくわずかな手書き感**（やさしい色鉛筆の質感）を添える。光沢や強いグラデは使わない。
