# 入力：Suicaオルタナティブ案㊵ サル「サル」（のぼる・つかむ）

> 対象: 架空のSuica新イメージキャラクター候補（非公式・本投票3案とは別の、あり得たかもしれない案）。既存キャラ（ペンギン・リス・ウサギ・モグラ）の模倣を避けた独自案。

## キャラクターの骨格

| 項目 | 内容 |
|---|---|
| モチーフ | サル。賢く、手先が器用。二足で立つ（立ちキャラ）。四本足で、前足が腕になる |
| 通称案 | 「サル」 |
| 体色 | やわらかい茶（こげ茶）＋白い腹＋器用な手 |
| 概念（動詞） | **のぼる・つかむ** |
| 性格 | 賢くて、軽やかで、前へ |

## なぜSuicaに合うか（ブランドとの対応）

- **つかむ＝器用な手**：手先が器用。カードをそっとタッチする手そのもの。未来をつかむ。
- **のぼる＝前へ**：木にのぼり、前に進む。一歩ずつ、上へ、先へ。
- **茶＝木**：こげ茶は、木の幹の自然色。緑と自然に調和する。
- **立ちキャラ＝IP展開**：前足が腕になり、器用な手。ポーズが豊富で、ぬいぐるみ・フィギュアに載せやすい。

## 語る一点（物語）

茶色のサルが、二足で立ち、器用な手を差し出す。賢く、軽やかに。腕の手でそっと「ピッ」。今日も、未来を、やさしくつかむ。

- つかむ＝器用な手、未来をつかむ。
- のぼる＝一歩ずつ、上へ前へ。
- 腕の手＝改札のタッチ。

## 使用シーン（イメージボードの小パネルで描く）

> ※ 実際のSuicaカードでは、キャラはカード面の**右端**に、**やや小ぶりに**印刷される（既存ペンギンを置き換え）。

1. 軽やかに立ち、器用な手を差し出す。
2. 腕の手で、カードをそっとタッチする。
3. 前へ、上へ進むのを軽やかに見送る。

## 期待する雰囲気

賢くて、軽やかで、前進の健気さ。こげ茶の体・白い腹・器用な手。かわいさは「未来をつかむ健気さ」。**立ちキャラ（二足で直立）**で、腕でポーズを取らせやすい。日本の交通系マスコットの「やわらかい平塗り」で、光沢やグラデは使わない。
