# 入力：Suicaオルタナティブ案⑲ コアラ「コアラ」（つかまる・ともに揺れる）

> 対象: 架空のSuica新イメージキャラクター候補（非公式・本投票3案とは別の、あり得たかもしれない案）。既存キャラ（ペンギン・リス・ウサギ・モグラ）の模倣を避けた独自案。

## キャラクターの骨格

| 項目 | 内容 |
|---|---|
| モチーフ | コアラ。木にしがみつく。抱きつく手＝通勤電車の吊革につかまる姿 |
| 通称案 | 「コアラ」 |
| 体色 | やわらかいグレーの丸い体＋白い腹＋Suicaグリーンの耳の内側＋大きな鼻 |
| 概念（動詞） | **つかまる・ともに揺れる** |
| 性格 | 静かでのんびり。ぎゅっと抱きついて、揺られながら寄り添う |

## なぜSuicaに合うか（ブランドとの対応）

- **しがみつく＝吊革**：コアラが木にしがみつく姿は、通勤電車で吊革につかまる人そのもの。同じように揺られ、同じ景色を見る＝毎日の寄り添い。
- **抱きつく＝安心**：木にぎゅっと抱きつく＝「つかまっていれば安心」＝Suicaが毎日の移動を支える安心。
- **のんびり＝焦らない**：一日の大半を眠るのんびり屋。急かさない穏やかさ。
- **手のひら＝タッチ**：木をつかむ手のひらが、改札でカードをそっと握ってタッチする仕草そのもの。

## 語る一点（物語）

満員電車で、小さなコアラが吊革にぎゅっとつかまっている。揺れても、寄りかかって、ほっとひと息。木をつかむのと同じ手のひらで、カードをそっと握って「ピッ」。今日も、あなたと一緒に同じ景色を見て、同じように揺れる。

- しがみつく手＝吊革＝つかまる。
- 耳の内側のSuicaグリーン＝ブランドカラーの目印。
- 大きな鼻＝のんびりした愛嬌。

## 使用シーン（イメージボードの小パネルで描く）

> ※ 実際のSuicaカードでは、キャラはカード面の**右端**に、**やや小ぶりに**印刷される（既存ペンギンを置き換え）。

1. 車内の吊革に、ぎゅっとつかまって揺られる。
2. 改札で、手のひらでカードをそっと握ってタッチする。
3. 木（＝柱）に抱きついて、帰りを静かに待つ。

## 期待する雰囲気

静かでのんびり、寄り添う安心。丸い体・大きな鼻・しがみつく手。かわいさは「つかまって揺られる健気さ」と「寄り添う穏やかさ」。日本の交通系マスコットの「やわらかい平塗り」で、光沢やグラデは使わない。
