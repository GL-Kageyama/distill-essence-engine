# 入力：Suicaオルタナティブ案⑮ ゾウ「ゾウ」（支える・移動を支える）

> 対象: 架空のSuica新イメージキャラクター候補（非公式・本投票3案とは別の、あり得たかもしれない案）。既存キャラ（ペンギン・リス・ウサギ・モグラ）の模倣を避けた独自案。

## キャラクターの骨格

| 項目 | 内容 |
|---|---|
| モチーフ | ゾウ（象）。力持ちで頼りになる。長い鼻で器用に物を掴む |
| 通称案 | 「ゾウ」（＝象。大きな体で支える） |
| 体色 | やわらかいグレー＋Suicaグリーンのスカーフ＋大きな耳 |
| 概念（動詞） | **支える・頼りになる（移動を支える）** |
| 性格 | 穏やかで頼りがいがある。大きな体で、毎日の移動をどっしり支える |

## なぜSuicaに合うか（ブランドとの対応）

- **支える**：ゾウは大きな体で荷を運び、人を支えてきた。Suicaが25年、毎日の移動を支えてきた信頼と重なる。
- **頼りになる**：ゾウは力持ちで、何があっても動じない。駅の混雑も、遅延も、どっしり受け止める安心感。
- **器用な鼻＝タッチ**：ゾウの長い鼻は、小さな物を器用に掴める。改札でカードをそっとタッチする仕草。
- **長寿・縁起**：ゾウは長寿の縁起物。長く愛されるSuicaの象徴。

## 語る一点（物語）

朝の駅に、大きなゾウがどっしりと立つ。Suicaグリーンのスカーフを揺らし、長い鼻でそっと、行き交う人を「いってらっしゃい」と送り出す。あなたの一日を、今日も大きな背中で支える。

- 大きな体＝移動を支える頼もしさ。
- Suicaグリーンのスカーフ＝ブランドカラーをまとう。
- 長い鼻＝器用なタッチの仕草。

## 使用シーン（イメージボードの小パネルで描く）

> ※ 実際のSuicaカードでは、キャラはカード面の**右端**に、**やや小ぶりに**印刷される（既存ペンギンを置き換え）。

1. 朝の駅で、大きな体で通勤客をどっしり支える（＝見守る）。
2. 改札のそばで、長い鼻でそっとカードのタッチを手伝う。
3. 駅前の広場で、疲れた人を背中に休ませる。

## 期待する雰囲気

穏やかで、頼りがいがあり、どっしり。大きな体・長い鼻・大きな耳。かわいさは「大きな体の安心感」と「器用な鼻の愛嬌」。日本の交通系マスコットの「やわらかい平塗り」で、光沢やグラデは使わない。
