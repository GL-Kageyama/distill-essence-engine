# 入力：Suicaオルタナティブ案㊳ ブタ「ブタ」（たのしむ・ゆたか）

> 対象: 架空のSuica新イメージキャラクター候補（非公式・本投票3案とは別の、あり得たかもしれない案）。既存キャラ（ペンギン・リス・ウサギ・モグラ）の模倣を避けた独自案。

## キャラクターの骨格

| 項目 | 内容 |
|---|---|
| モチーフ | ブタ。丸くてのんびり。二足で立つ（立ちキャラ）。四本足で、前足が腕になる |
| 通称案 | 「ブタ」 |
| 体色 | やわらかい桃色＋丸い体＋小さな鼻 |
| 概念（動詞） | **たのしむ・ゆたか** |
| 性格 | のんびりで、穏やかで、日々をたのしむ |

## なぜSuicaに合うか（ブランドとの対応）

- **たのしむ＝道すがら**：通勤の道すがらを、のんびりたのしむ。寄り道や、小さな発見を喜ぶ。
- **ゆたか＝心のゆとり**：ふくよかな丸さは、心のゆとり。焦らず、日々を味わう。
- **桃色＝花の色**：やわらかい桃色は、花の色。緑の葉に映える自然な補色で、カードに並ぶとやさしく映える。
- **立ちキャラ＝IP展開**：丸い体、前足が腕になる。貯金箱のイメージで親しまれ、ぬいぐるみ・キーホルダーに載せやすい。

## 語る一点（物語）

桃色のブタが、二足で立ち、のんびり日々をたのしむ。丸い体、小さな鼻。腕の手でそっと「ピッ」。今日も、道すがらを、ゆたかにたのしむ。

- たのしむ＝道すがら、小さな発見。
- 桃色＝花の色、緑に映える補色。
- 腕の手＝改札のタッチ。

## 使用シーン（イメージボードの小パネルで描く）

> ※ 実際のSuicaカードでは、キャラはカード面の**右端**に、**やや小ぶりに**印刷される（既存ペンギンを置き換え）。

1. のんびり立って、日々をたのしむ。
2. 腕の手で、カードをそっとタッチする。
3. 道すがらの小さな発見を、ゆたかに喜ぶ。

## 期待する雰囲気

のんびりで、穏やかで、たのしみの健気さ。桃色の丸い体・小さな鼻・腕の手。かわいさは「日々をゆたかにたのしむ健気さ」。**立ちキャラ（二足で直立）**で、腕でポーズを取らせやすい。日本の交通系マスコットの「やわらかい平塗り」で、光沢やグラデは使わない。
