# 入力：Suicaオルタナティブ案⑦ トンボ「トンボ」（前進・勝ち虫）

> 対象: 架空のSuica新イメージキャラクター候補（非公式・本投票3案とは別の、あり得たかもしれない案）。既存キャラ（ペンギン・リス・ウサギ・モグラ）の模倣を避けた独自案。

## キャラクターの骨格

| 項目 | 内容 |
|---|---|
| モチーフ | トンボ（蜻蛉）。後ろへ飛べず、前にしか進まない「勝ち虫」。古名「あきつ」は日本の雅称 |
| 通称案 | 「トンボ」（＝勝ち虫。後ろへ戻らない＝前へ進む） |
| 体色 | Suicaグリーンの細長い体＋透明な羽＋白い帯 |
| 概念（動詞） | **前進する・後退しない（前へ）** |
| 性格 | すっきり爽やか。迷わずまっすぐ前へ飛ぶ。夏のホームの風 |

## なぜSuicaに合うか（ブランドとの対応）

- **勝ち虫**：トンボは後ろへ飛べず、前にしか進まないことから「勝ち虫」と呼ばれる縁起物（武士は兜や刀にトンボをあしらった）。「後退しない」＝通勤・挑戦の前進を象徴する。
- **前へ**：列車は前へしか進まない。トンボの「前にしか飛ばない」＝定時・直進・目的地へ一直線。
- **スイスイ**：トンボは水面を滑るように飛び、ホバリングも自在。Suicaの「スイスイ」の飛翔版。
- **アキツシマ**：トンボの古名「あきつ」は日本の古称（秋津島）。夏の風物詩として老若男女に親しまれる。

## 語る一点（物語）

夏の朝、ホームにスッと降り立ったトンボが、あなたの目の前を、後ろを見ずにまっすぐ前へ飛んでいく。乗り換えも、目的地も、迷わず一直線。透明な羽が「ピッ」の音とともに光る。Suicaグリーンの細長い体が、線路の先へ一直線に伸びる。

- 透明な羽＝改札の「ピッ」の瞬間を留める光。
- Suicaグリーンの細長い体＝線路の先へ伸びる直進のライン。
- 前にしか飛ばない＝後退しない（勝ち虫）。

## 使用シーン（イメージボードの小パネルで描く）

> ※ 実際のSuicaカードでは、キャラはカード面の**右端**に、**やや小ぶりに**印刷される（既存ペンギンを置き換え）。

1. 昼の明るい改札で、カードをタッチする手のそばを、まっすぐ前へ飛ぶ。
2. ホームの上を、線路に沿って一直線に飛ぶ。
3. 夏の駅前で、水たまり（＝改札の水面）にスッと止まる。

## 期待する雰囲気

すっきり爽やかで、迷いがない。細長い体・透明な羽・大きな目。かわいさは「すらりとした形」と「まっすぐ前へ進む潔さ」。日本の交通系マスコットの「やわらかい平塗り」で、光沢やグラデは使わない。
