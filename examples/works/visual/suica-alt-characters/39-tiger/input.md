# 入力：Suicaオルタナティブ案㊴ トラ「トラ」（つよく、まっすぐ）

> 対象: 架空のSuica新イメージキャラクター候補（非公式・本投票3案とは別の、あり得たかもしれない案）。既存キャラ（ペンギン・リス・ウサギ・モグラ）の模倣を避けた独自案。

## キャラクターの骨格

| 項目 | 内容 |
|---|---|
| モチーフ | トラ。寅の縁起物。二足で立つ（立ちキャラ）。四本足で、前足が腕になる |
| 通称案 | 「トラ」 |
| 体色 | やわらかい橙＋黒い縞＋白い腹 |
| 概念（動詞） | **つよく、まっすぐ** |
| 性格 | 力強くて、静かで、まっすぐ |

## なぜSuicaに合うか（ブランドとの対応）

- **つよく＝安心**：力強い姿は、静かな安心。毎日を、どっしり支える。
- **まっすぐ＝前へ**：まっすぐ前へ進む。迷わず、目的地へ。
- **橙×黒＝秋の縞**：やわらかい橙と黒の縞は、秋の自然色。緑に映える。
- **立ちキャラ＝IP展開**：前足が腕になり、縞模様が特徴。ぬいぐるみ・キーホルダーに載せやすい。

## 語る一点（物語）

橙色のトラが、二足で立ち、まっすぐ前を見る。黒い縞、白い腹。腕の手でそっと「ピッ」。今日も、力強く、まっすぐ、前へ。

- つよく＝静かな安心、どっしり支える。
- まっすぐ＝迷わず前へ。
- 腕の手＝改札のタッチ。

## 使用シーン（イメージボードの小パネルで描く）

> ※ 実際のSuicaカードでは、キャラはカード面の**右端**に、**やや小ぶりに**印刷される（既存ペンギンを置き換え）。

1. 力強く立ち、まっすぐ前を見る。
2. 腕の手で、カードをそっとタッチする。
3. 静かに、まっすぐ前へ進むのを見送る。

## 期待する雰囲気

力強くて、静かで、まっすぐの健気さ。橙色の体・黒い縞・白い腹・腕の手。かわいさは「力強くまっすぐ進む健気さ」。**立ちキャラ（二足で直立）**で、腕でポーズを取らせやすい。日本の交通系マスコットの「やわらかい平塗り」で、光沢やグラデは使わない。
