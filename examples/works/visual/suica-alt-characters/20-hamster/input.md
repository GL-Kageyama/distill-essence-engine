# 入力：Suicaオルタナティブ案⑳ ハムスター「ハム」（貯める・すこしずつ貯める）

> 対象: 架空のSuica新イメージキャラクター候補（非公式・本投票3案とは別の、あり得たかもしれない案）。既存キャラ（ペンギン・リス・ウサギ・モグラ）の模倣を避けた独自案。

## キャラクターの骨格

| 項目 | 内容 |
|---|---|
| モチーフ | ハムスター。頬袋に餌をすこしずつ貯める。小さく丸い体 |
| 通称案 | 「ハム」 |
| 体色 | やわらかいクリーム色の丸い体＋Suicaグリーンのふくらんだ頬＋小さな丸い目 |
| 概念（動詞） | **貯める・すこしずつ貯める** |
| 性格 | 小さくて穏やか。こまごまと貯め込んで、安心を蓄える |

## なぜSuicaに合うか（ブランドとの対応）

- **頬袋＝チャージ**：ハムスターが頬袋に餌を貯める＝Suicaにチャージする。すこしずつ貯めて、安心を蓄える。
- **小さくても安心**：小さな体に、明日の分までこっそり貯める＝毎日の備え＝Suicaの残高。
- **穏やか**：静かに、こまごまと動く健気さ。焦らない。
- **小さな手＝タッチ**：小さな手で、カードをそっと握ってタッチする仕草そのもの。

## 語る一点（物語）

小さなハムスターが、頬袋をふくらませて、改札のそばにちょこん。すこしずつ、明日の分までこっそりチャージを貯めて、今日も安心して出かける。小さな手で、そっと「ピッ」。

- 頬袋＝チャージ＝安心の蓄え。
- Suicaグリーンの頬＝ブランドカラーの目印。
- 小さな丸い目＝健気な愛嬌。

## 使用シーン（イメージボードの小パネルで描く）

> ※ 実際のSuicaカードでは、キャラはカード面の**右端**に、**やや小ぶりに**印刷される（既存ペンギンを置き換え）。

1. 頬袋をふくらませて、改札をちょこんと通る。
2. 小さな手で、カードをそっと握ってタッチする。
3. ポケットのそばで、明日の分までチャージを貯めて待つ。

## 期待する雰囲気

小さくて、穏やかで、蓄える健気さ。丸い体・ふくらんだ頬・小さな手。かわいさは「すこしずつ貯める安心」と「小さな健気さ」。日本の交通系マスコットの「やわらかい平塗り」で、光沢やグラデは使わない。
