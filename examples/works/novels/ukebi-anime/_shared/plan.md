## なぜ設定画と立ち絵を分けるか

`character-sheet` は1枚に正面・斜め・横・後ろを並べる。**人間が読む仕様書としては最良だが、生成の参照には使えない。** 1枚に4体写っている絵を参照に渡すと、モデルは4体を描こうとする。だから仕様書（sheet）と参照画像（単体の立ち絵）を別に焼く。立ち絵は、採った設定画を参照に渡して作る。

## 一貫性は二段で作る

1. **文字で固定する。** `_shared/characters/<名>.md` の同一性 block を、その人物が出る全プロンプトへ逐語で貼る。
2. **絵で固定する。** 採用した設定画と立ち絵を参照画像として渡す。

**第1陣の2枚が通るまで先へ進まない。** ここが全部の同一性を握る。

## 共通 block

`_shared/common.md`＝文字・空と天候・光・パレット・人数・描画の六つ。全アセットが貼る。火は `_shared/fire.md`。人物は `_shared/characters/<名>.md`。**貼る順序も `common.md` の末尾に在る。**

## 様式の割り当て

- **設定画＝`cel-shade`（平光）。立ち絵＝`one-lamp-cel`。** 設定画は仕様書なので平光でよい。**立ち絵は火を灯す**——`package.md` §4 が火の参照画像を求めるので、掌の火を当てて焼く（2026-11-11、評価者の指摘で割り当てを二つに割った。当初の「設定画・立ち絵＝cel-shade」は古い）。**パレットは各人物の台帳の材質色**（土と灰、灰と焦げ茶、褪せた藍など）——共通パレットは火の下の画のもので、平光の設定画には乗らない。
- **場面・キービジュアル・表紙・ポスター・サムネイル＝`one-lamp-cel`。** 唯一の光源、空気だけが柔らかい。魂火は `_shared/fire.md` の block を逐語で貼る。
- **所作の板（`key-pose-board`）＝`cel-shade`。** 計画では「板＝灯ひとつ」としたが、**運動を読む板に炎の陰影を乗せると形が読めない。** 所作の板は光を持たない。灯ひとつは場面の板が持つ。
- **記憶＝`one-lamp-cel` のまま。** 火の中に像が結ぶ。別の様式にしない（design「別の様式にしない」）。

## 検品の二段

- **プロンプトの検品（焼く前）。** 評価者を回す——`aesthetic-critic`（様式の一貫）、`anti-generic-filter`（平均へ落ちていないか）、`hook`（見たくなるか）。**テキストしか見ていない。** 絵の出来は保証しない。
- **絵の検品（焼いた後）。** `package.md` §4 の共通の禁＋形式ごとの項目。

## 台帳との食い違い（2026-11-11 に見つけ、同日裁定）

採用した踏切の板が、`台帳/舞台装置/` の四箇所と食い違っている。**板を焼いたとき、台帳を読まずに `design.md` と `package.md` から書いた。** 以後の26本はこの板を基準にするので、先に決める必要がある。

1. **道の舗装。** 台帳 `踏切.md`「舗装は無い。砂利と土。轍が二本」。板は**亀裂の入った舗装路**。
2. **腕木の塗装。** 台帳 `遮断機.md`「白と黒の帯。帯の幅は均一。文字・番号は無い」。板は**無地の錆びた鉄**。板を焼いたとき「縞は文字と警告色を招く」と判断して外したが、**台帳が禁じているのは黄色であって白黒ではない。**
3. **警報灯。** 台帳 `踏切.md`「標識・信号機・ランプは無い」。板は腕木の先に**消灯した丸い灯**を置いた。
4. **カメラ。** 台帳 `踏切.md`「基本は低い位置。レールの高さから。線路の消失点を画面に残す」。板は**道の上の目の高さで、消失点を外した**。

5. **火の数（2026-11-11、プロンプト作成中に見つけた）。** `package.md` §4 のキービジュアルの block が、同じ一画面に**火を二つ**書いている——「掌の上に青白い魂火をひとつ載せている」と「二人のあいだの線路の上に、青白い火がひとつ浮かぶ」。**光は魂火ひとつ**（design）なので、二つは同時に成り立たない。しかも台帳は「宙に浮かせない」と言い、表紙の項は「二人のあいだの火を画面の中央に」と言う。**四つが食い違っている。**

**→ 裁定（2026-11-11）。**

- **1・2・3 は台帳へ戻す。** 以後の26本は砂利と土・白黒の帯・灯なしで焼く（場面の板5本はすでにその側で書いた）。採用済みの踏切の板は**その一枚だけ例外**として残す——焼き直さない。
- **4 は台帳を直した。** `踏切.md` の「線路の消失点を画面に残す」を「残してもしなくてもよい（画面中心に置くと鏡像が出る）」へ。
- **5 は「二人のあいだに浮く火ひとつ」**。`package.md` のキービジュアルの「掌の上に載せている」を落とし、`台帳/舞台装置/魂火.md` の位置の項に例外を二つ（彼の居ない画／彼が向き合う画）として書いた。

## 評価者の検品（2026-11-11、26本とも書き終えたあと）

`aesthetic-critic-ja` と `anti-generic-filter-ja` を4本に分けて全26本へ当てた。指摘のうち、**画面が壊れるもの・正本に反するもの**を直した。

**直したもの**

1. **火の block の「影はひとつ」。** 二人の画ではひとつの光が二つの影を落とす。正本を `it casts one shadow for each body it lights` へ直し、13本へ貼り直した。検品の一行も「届く体ごとに影がひとつ」へ。
2. **「赤はレールだけ」が縁の赤を殺していた。** `the only red outside the fire` へ（6本）。パレットの `rust red` と `only` が喧嘩していた。
3. **共通 block の逐語が崩れていた。** 光の一行（`No moonlight, no starlight…`）が13本に無く、パレットが12本で言い換えられ、文字の block が11本で `Japanese or English` を落とし、人数の block が5本に無かった。**すべて正本の文へ戻した。**（`art-board-crossing` だけは焼いた絵の記録なので触っていない）
4. **低いカメラが Merged に無かった**（ep01・ep02・キービジュアル・表紙・ポスター）。場面の板5本のうち Merged に持っていたのは3本だけだった。一文を足した。
5. **表紙の光の向き**（レールの高さの火が「頭の上から」照らしていた）と**ポスターの上限**（「腰から下」と「顎の下面」が同じ文に在った）。下から・胸まで、へ揃えた。
6. **ポスターのレールが下端の五分の一を突き抜けていた**（題字の場所が空かない）。下端で止めた。`for type` も落とした（文字を正向きに呼ぶ唯一の語だった）。
7. **所作の板**——花は三つが同じ立ち姿、送り火は八つとも `he stands` で1と4・3と6が同型。手の高さを五つ／八つに配り直し、悼むは**口でなく喉と肩**へ（block の「口は閉じている」に戻した）。
8. **設定画の「共有の水平ガイド線」**が「線を描くな」と衝突（送り火・花の Format と検品）。想像の線へ揃えた。
9. **顔の ground の収束**——サチとトワが同じ顔だった（頬骨・目幅・長い顎・長い鼻）。トワを二軸動かした。フミとナギは既定の顔の側だったので、それぞれ二軸（目の高さ／顎の長さ、目幅／鼻の長さ）。
10. **フミのペン**（固有は「置いた後も指がペンの形を保つ」なのに、四面とも握らせていた）、**コダマの両手**（block の「上げた両手」が絵に出ない）、**名なしの子の背**（前後が分からない）、**判の握り**（尺度が二つで互いを消していた）。

**裁定して直したもの（2026-11-11）**

- **キービジュアルとポスターの重なり。** ポスターの彼を**四分の三、火のほうへ**振り、開いた両手を体の少し前へ出した。表紙＝火（縦軸）、ポスター＝人、キービジュアル＝二人と火、サムネイル＝火だけ、と四枚が分かれる。
- **花の立ち絵の火の大きさ。** `package.md` が「参照画像：花（第4話）」と指定しているので、**梅ほど**（`a plum`）にした。第1話の握り拳（送り火の立ち絵）とは別の段。台帳にも一行足した。
- **`台帳/舞台装置/台帳.md` の席。** 「誰も座らない」と「第4話で花が座る」が同じ項に並んでいた。**「第4話まで誰も座ったことがない。第4話で花が座る」**へ直した（草稿第4話「誰も座ったことがない…その席に、誰かが座っている」に合わせた）。
- **ep09 の焦点。** 火を彼の体の後ろへ半分隠し、**背の縁を光で切る**一文を足した。最も明るい点は火のまま、目は彼のシルエットの縁へ行く。

**裁定して直さなかったもの**

- **サチの足跡・名なしの子の小さな輪を設定画に置かない。** 焦げ跡は**台帳の頁のもの**で、人物の一枚ではない。六人とも同じ扱いにした（各 prompt に理由を書いてある）。インセットは三つのまま。

## 計画を曲げた箇所（2026-11-11、26本を書き終えた時点）

計画の表と実際の prompt が違う四箇所。**理由は各 `prompt.md` の冒頭にも書いた。**

1. **記憶の野 → `concept-board`。** 一枚に四面を並べる設定画は「同じ物を別の角度から」を固定する型で、記憶には向かない。記憶が固定すべきは**現れ方の型**ひとつ。
2. **キービジュアル → `illustration`。** `scene-board` は制作の立ち位置を固定する板。キービジュアルは売る一枚。
3. **所作の板 → `cel-shade`。** 上記。
4. **立ち絵だけが `one-lamp-cel`。** 計画と `common.md` は「設定画・立ち絵＝平光（光源なし）」だったが、`package.md` §4 が火の参照画像を求めるので、立ち絵2枚は掌の火を当てて焼く。**規則の側を二つに割った。**
5. **場面の板は台帳の側で焼く。** 採用済みの踏切の板（舗装・無地の腕木・消灯した灯）に合わせず、砂利と土・白黒の帯・灯なしで焼いた。**食い違いは未裁定なので、裁定が出たら 5 本を作り直す。**
