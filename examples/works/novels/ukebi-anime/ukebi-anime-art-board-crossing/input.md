# 入力 — 境の踏切（美術ボード用の抜粋）

出典：`soul-voice-teller/examples/works/novels/ukebi-anime/構想/design.md` と
`届ける/package.md` §4 の共通の禁。全文ではなく、この一枚に要る部分だけを抜く。

## 舞台（design「世界」）

- **境**：生死のあわい。駅にも町にも続かない線路。誰も渡らない踏切。
  上がったままの遮断機。雨は降らないのに空気は濡れている。時間が流れない。朝がない。
- **彼方**（送り先）：見せない。レールの先に、話ごとに違う光が一瞬だけ見える。
  → ボードには入れない。話ごとに変わるものは基準板に置かない。

## 光（design「視覚の規則」）

- 魂火が唯一の光源。bloom も lens flare も無し。
- 火は青白いのに、赤くも見える。青と赤のあいだで揺れる。
- 火は話ごとに少しずつ小さい。第9話で炭ほど。第10話で消える。
- 第10話の最後、画面は白くなる。白は頁。新しい光源ではない。

## 文字（design「視覚の規則」）

- 画面に読める文字を置かない。日本語・英語・実在の文字はすべて無し。
- 看板・標識・名札・掲示・頁の字・字幕を置かない。
- 台帳の印は文字でなく、火の跡。魂ごとに形が違う。最初の頁には、跡すらない。

## 共通の禁（package.md §4）

```
画面に読める文字を置かない。看板・標識・名札・掲示・字幕・ロゴ・数字を置かない。
日本語・英語・実在の文字を描かない。人物名は日本語で指定し、ローマ字にしない。
魂火が唯一の光源。bloom、lens flare、グローを入れない。
空に太陽・月・星を置かない。雨を降らせない。濡れた砂利と水たまりだけを置く。
群衆を置かない。三人以上の人を置かない。
```

## この一枚で固定したいもの

パレット、光の方向、表面の質感、ディテール水準。後続の全カットがこれに合わせる。
人物は入れない。時刻はひとつ。ドラマチックなアングルは使わない（後の撮影で使い回せない）。
