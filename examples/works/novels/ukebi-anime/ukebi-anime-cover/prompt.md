## 内容（Content）

**②選択＝この一枚が運ぶのは「縦の軸に載った火ひとつ」の一点。** 表紙の型は**焦点を小さく、上に余白を広く**。ゆえに人を大きく描かない。**火が焦点で、二人はその下と上に小さく居る。**

**③翻訳＝三つ。** 中央の火、上へ抜ける黒、下の濡れた砂利。

**台帳・package の食い違い（未裁定）。** キービジュアルの項を参照——火は一つ。この表紙も (2)（二人のあいだに浮く）を採る。

## フォーマット（Format）

2:3 の縦。**上三分の一は無地の黒。** 中央に上げたままの腕木二本。下に濡れた砂利と水たまり。

- **彼は手前下、彼女は奥上。** 二人とも小さい。
- **火は画面の中央。** 二人のあいだ。炭ほどではなく握り拳ほど——表紙の焦点なので小さくても読める大きさ。
- **余白を多めに。** 文字・ロゴは無し。

## 様式（Style）

灯ひとつ。**人物はセル、空気は写実。**

**衝突と解決**：

1. **「上に黒い空」と「空を描かない」** → 上は**空でなく、光の届かない黒**。地平線も星も月も無い。**黒を「空」と呼ばない。**
2. **「焦点は小さく」と「火が読める」** → 火は中央で**画面の幅の十分の一ほど**。ゆえに輪郭を閉じ、芯を明るく保つ。
3. **「二人を置く」と「余白」** → 二人は**火より小さい**。彼女はさらに小さい（奥）。
4. **「縦の軸」** → 火・腕木・線路を**同じ縦軸**に載せる。左右に振らない。
