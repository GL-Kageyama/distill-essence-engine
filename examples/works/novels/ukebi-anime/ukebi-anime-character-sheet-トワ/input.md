# 入力（トワ）

原典 `soul-voice-teller/examples/works/novels/ukebi-anime/台帳/人物/トワ.md` から逐語。

## 同一性（固定する）

- **体格**：細い。背は高い。姿勢は崩さない。
- **髪**：黒。長い。結ばない。顔の半分を隠す。
- **服**：一枚の質素な衣。色は灰。襟は緩い。帯は無い。
  模様・刺繍・文字は無い。袖は手首まで。
- **顔**：目を伏せる。顎を上げられても、目は上げない。
- **手**：指が細い。爪は短い。手を握らない。開いたまま。
- **首**：顎の下から喉まで、画面に出す。手が触れる場所。

## 飢えの見せ方

- 値踏みされる。動かない。逃げない。
- 目を伏せたまま、自分で顎を上げる。自分で数える音をなぞる。数が終わるのを待つ。
- 値がついても、表情を変えない。安堵も、屈辱も出さない。

## 台帳の印

**伏せた目。** 焦げた二本の弧が、頁に並ぶ。まぶたの形。

## 禁止（揺れ）

- 裸、肌の露出を増やす、暴力、血。
- 値札、数字、文字の入った帳面。
- 泣く、笑う、顔を背ける。
- 見る者の顔。指輪や腕輪の装飾。
