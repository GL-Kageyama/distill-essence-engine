# 入力（花の設定画）

原典 `soul-voice-teller/examples/works/novels/ukebi-anime/`。

## `台帳/人物/花.md` から（逐語）

- **体格**：送り火より頭一つ低い。細い。肩は落ちている。
- **髪**：長い。黒に近い藍。結ばない。毛先は濡れたように重い。
- **服**：暗い藍の制服。上着とスカート。襟に線は一本だけ。校章・名札・リボンの文字は無い。靴は黒。靴下は暗い色。
- **顔**：表情は少ない。眉も口も動かさない。目だけが先に動く。視線が動いてから、首が遅れて向く。首が向かないこともある。
- **シルエット**：まっすぐ立つ。腕は前で組まない。手は体側。
- **濡れ**：雨は画面に無い。髪と肩だけが暗く重い。滴は落とさない。
- **禁止（揺れ）**：笑顔、泣き顔、怒り。表情で意味を足さない。制服の装飾、文字の入った校章、リボン。傘、鞄、携帯。手ぶらで立つ。走る、飛びつく、抱きつく。
