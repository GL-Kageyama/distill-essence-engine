# 入力（キービジュアル 16:9）

原典 `届ける/package.md` §4「キービジュアル（16:9）」から逐語。

```
夜の踏切。どこにも続かない線路が二本、画面の奥へ伸びる。枕木は黒い。レールの錆だけが赤い。遮断機の腕木が二本、上がったまま、六十度で止まっている。雨は降っていない。空気は濡れていて、砂利と水たまりが光を返す。空は黒く、太陽も月も星も無い。

画面の手前左に、送り火。暗い藍のコート、膝丈。短い暗い藍の髪。手が大きい。直立し、腕は体側。顔は火の下から照らされ、目は細い。表情を作らない。両手を軽く開き、掌の上に青白い魂火をひとつ載せている。火は青白いのに、縁だけ赤い。青と赤のあいだで揺れている。

画面の奥右に、花。暗い藍の制服。長い髪。表情は少なく、目だけが動く。雨は降っていないのに、制服だけが濡れたように暗い。彼女は送り火を見ている。手は下ろしている。

二人のあいだの線路の上に、青白い火がひとつ浮かぶ。火が唯一の光源で、二人を下から照らす。影は長い。配色は沈んだ藍、錆の赤、青白。静寂と余白。アニメのキービジュアル。人物は柔らかく、背景は克明に。文字なし。
```
