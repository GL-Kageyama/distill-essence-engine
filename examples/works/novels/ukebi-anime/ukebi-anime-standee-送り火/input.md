# 入力（送り火の立ち絵）

原典 `届ける/package.md` §4「参照画像：送り火（第1話）」から逐語。

```
縦長。暗い無地の背景。青白い魂火がひとつ、画面の下から人物を照らす。火が唯一の光源。影は長い。bloom、lens flare、グローを入れない。

送り火の全身。直立。腕は体側。足は肩幅。中背。肩幅は普通。胴に厚みがない。手だけが大きい。指は長く、節が太い。爪は短い。手は素手。手袋をしない。

暗い藍の短い髪。耳を出す。前髪は眉の上で止まる。暗い藍のコート。丈は膝。襟は立てない。内側は濃い灰色。ボタンは無地。模様・記章・文字は無い。

細い目。薄い眉。口は閉じたまま。表情を作らない。年齢は20代にも40代にも見える。顔は火の下から照らされる。

背景に踏切の線路を薄く置く。読める文字、名札、注釈、矢印を置かない。文字なし。人物名のラベルを描かない。
```

**註＝この block は縦長・暗い無地・火が下から照らす、と指定している。** 立ち絵はこれをそのまま使う（設定画とは別物）。
