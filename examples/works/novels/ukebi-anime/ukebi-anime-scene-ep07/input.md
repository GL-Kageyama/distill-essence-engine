# 入力（第7話「値付ける」）

原典 `構想/design.md`「各話のビート」から逐語。

```
**第7話「値付ける」**
トワ。無価値と値踏みされた女。目が火を透かす。記憶は顎を持つ手と、数える指と、伏せた目。
判が押される。押されたのは花の額でなく、彼の額。中空の印。定型句。
```

台帳 `台帳/舞台装置/判.md`「第7話の動き」から。

```
送り火が判を持つ。花へ向く。花は動かない。
判は花の額の前で止まる。押さない。
送り火は自分の額へ押す。一度だけ。
印は中空。輪郭だけが焦げ、内側は肌のまま。
```
