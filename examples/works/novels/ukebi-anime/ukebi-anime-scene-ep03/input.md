# 入力（第3話「綴じる」）

原典 `構想/design.md`「各話のビート」から逐語。

```
**第3話「綴じる」**
フミ。読まれなかった作家。指が火を頁へ押す。火の形が跡になる。
記憶は机と頁と、誰もいない部屋。最初の頁に跡がないことに気づく。「読んで」。定型句。
```

改稿のショット表 `草稿/ショット表_第3話.md` から。

```
S09 彼は最初の頁を開く。白い。跡が無い。縁の片方だけが内側へ折れている。折り目は古い。折れ目の幅は、指の半分ほど。
S11 彼は初頁の折れ目に指を伸ばす。触れて、止まる。押した頁へ戻らない。
S12 指は折れ目の上にある。そのまま、声がする。「読んで」
S14 彼は台帳を閉じる。頁を両手で揃える。折れた縁が立つ。頁が平らに閉じない。
```
