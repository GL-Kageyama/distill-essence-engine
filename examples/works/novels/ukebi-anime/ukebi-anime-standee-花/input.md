# 入力（花の立ち絵）

原典 `届ける/package.md` §4「参照画像：花（第4話）」から逐語。

```
縦長。暗い無地の背景。青白い魂火がひとつ、画面の下から人物を照らす。火が唯一の光源。影は長い。bloom、lens flare、グローを入れない。

花の全身。直立。腕は体側。手は前で組まない。送り火より頭一つ低い。細い。肩は落ちている。

長い髪。黒に近い藍。結ばない。毛先は濡れたように重い。暗い藍の制服。上着とスカート。襟に線が一本だけ。校章・名札・リボンの文字は無い。靴は黒。靴下は暗い色。

表情は少ない。眉も口も動かさない。目だけが先に動く。雨は画面に無い。髪と肩だけが暗く重い。滴は落とさない。手ぶら。傘・鞄・携帯を持たない。

背景に踏切の線路を薄く置く。読める文字、名札、注釈、矢印を置かない。文字なし。人物名のラベルを描かない。
```

**註＝この block は縦長・暗い無地・火が下から照らす、と指定している。** 立ち絵はこれをそのまま使う（設定画とは別物）。
