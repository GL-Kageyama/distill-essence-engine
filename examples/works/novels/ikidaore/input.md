# 入力：行き倒れの孤児と少女（一場面の指定）

> 種別＝小説の一場面の指定。本文はなく、場面と、そこで確信されることだけが与えられている。

## 原文（利用者の指定・そのまま）

> 行き倒れの6歳の孤児(男児)（もうすぐ亡くなる）と、12歳の娼婦である少女が出会うシーン
>
> 場所は中世ヨーロッパ
>
> 少女の優しさに触れることが、その孤児にとっての人生の目的だったことが、優しい光と共に（孤児が）確信を得る。

## 入力が定めていること

| 項 | 指定 |
|---|---|
| 少年 | 6歳・男児・孤児・行き倒れ・もうすぐ死ぬ |
| 少女 | 12歳・娼婦 |
| 場所 | 中世ヨーロッパ |
| 起きること | 二人が出会う |
| 少年の内面 | 少女の優しさに触れたことが自分の人生の目的だった、と確信する |
| 光 | 優しい光（確信と同じところにある） |

## 入力が定めていないこと（エンジンは足さない）

- **二人の名** —— 与えられていない。ゆえに名は付けない（画像にも書かない）
- **少女が何をするか** —— 与えられているのは「優しさ」だけで、行為は書かれていない。行為の具体化は③翻訳の仕事であり、事件を増やすことではない
- **少年がこの後どうなるか** —— 「もうすぐ死ぬ」の先は書かれていない。この一枚で彼は死なない
- **少女がこの後どうなるか**
- **街の名・国・季節・天候・時刻** —— 「中世ヨーロッパ」だけが与えられている
- **少女が娼婦であることの視覚的な標**（服装の規定・街の習俗など）—— 与えられていないので描かない

## ⑧ 忠実性のための禁止

- 「心優しき娼婦」という定型に寄せない（少女を聖女にしない）
- 「希望→光」「死→光」の借り物の記号を使わない。光は天上から降ろさない
- 救済・奇跡・第三の人物を入れない（この物語のものではない）
- 少女の身体を性的に描かない。描かれるのは介護の身振りだけ
