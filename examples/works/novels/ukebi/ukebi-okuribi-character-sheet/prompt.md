# 受け火 → キャラクター設定画（送り火）

- 入力: `soul-voice-teller/examples/ukebi/`（草稿 draft.md・台帳 series-bible.md・構想 premise.md / design.md・包装 package.md）
- format: キャラクター設定画（character-sheet・0.1.28 新カード・伝達＝制作仕様）
- style: セルシェード（cel-shade・検証済み）

## 内容（Content）

②選択＝**「ただの男」そのものを仕様として書く**こと。送り火には外見の指定がほぼない（草稿は「名もない男」「ただの男」だけ）。⑧忠実の中枢は**無名性**——目を引くものが何もないこと自体が彼の見た目である。だからこの設定画が固定すべき一点は、髪型でも衣装でもなく、その無名さ。装飾を足さないことがデザインになる。

③翻訳＝**装置と書かない**。草稿が与える身体の印だけを注記として引き出す——①手は火をすくい、ぬくもりが残る（第1章）。②額に「該当なし」の判が押される（第6章）。③喉に呑んだ火が留まる（第3章）。三つはどれも「彼が何であるか」を仕様の側から滲ませる。髪・年齢・服装は草稿にないので、世界の調色（沈んだ藍）に接地した最小限の決定だけを置く（服は藍の外套・髪は藍黒の短髪・年齢は不問の「ただの男」）。

## フォーマット（Format）

白地・多面図4面（正面／斜め／側面／背面）を**同一の身長線と目線**に載せる。ニュートラルな A ポーズ、腕はシルエットから離す。下段に表情5面——無名の静止／器官が止まる瞬間／手が喉に触れる（第1章）／受け取られる者の顔／口が開きかける（終章）。右に拡大図——火をすくう手、額の淡い「該当なし」の判、火が留まった喉の脇。影を落とさない・背景を描かない・引き出し線で注記する。

## 様式（Style）

セルシェード＝平坦な彩色面・閉じた線・2段の硬い影。**ただし設定画の白地と衝突する部分は format が勝つ**：人物の面には2段の平坦なセル塗りを許すが、接地影と背景は描かない。彼の「無名性」は装飾の抑えとして cel-shade の「情報が雰囲気に勝つ」と重なる——感情を線や塗りで足さず、注記だけで示す。
