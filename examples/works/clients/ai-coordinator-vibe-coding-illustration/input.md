# 入力——AI活用推進コーディネーター（主な売り＝バイブコーディング講師）を、挿絵一枚に畳む

> 種別＝**役割の記述**。物語でも、記事でもない。来たのは二つの文だけである——**AI活用推進コーディネーターのイラストを作りたい**／**その人物は、バイブコーディング講師としての役割をメインの売りにしている**。
> 作るのは、この役割の**一点**を、横長16:9の挿絵一枚に絞ったもの。**文字は置かない**（挿絵カード）。**画像は生成しない**（`CLAUDE.md` §Verification。引くのは著者）。

## 仕様

| 項目 | 内容 |
|---|---|

| style | クリーンラインラボ（clean-line-lab）——レジストリ済み。細いインク線＋淡いパステル＋一点の金 |

## ① 何が来たか（理解）

- **二つの層がある。** 表の肩書きは**AI活用推進コーディネーター**——組織とAIのあいだに入り、利用場面を見つけ、人と道具をつなぐ役割である。**売りの主軸は、その中の「バイブコーディング講師」**——自然言語でAIに話しかけ、動くソフトウェアを作ることを教える。
- **この二つは、同じ一人の別の顔ではない。** コーディネーターは**組織の側**を向き、講師は**個人の側**を向く。**売りは後者である**——だから一枚も、会議や提案ではなく、**教えている場面**でなければならない。
- **バイブコーディングの本質は、コードを書かないことではない。** **コードを読めない人でも、自分の手で動くものを作れること**である。講師の仕事は、**代わりに書くこと**ではなく、**質問の仕方と、途中で立ち止まる判断を渡すこと**。ゆえにこの一枚で、**講師の手はキーボードに触れない**。
- **AIは描かない。** AIは**画面の中で起きていること**——言葉が、動くアプリになっていること——としてだけ存在する。ロボットも、脳も、回路も、光る魔法も要らない。

## ② 語る一点（選定）

**講師の手は、キーボードの上にない。受講者の両手が、キーボードの上にある。**

**なぜこの一点か。** バイブコーディング講師の仕事は、**自分が打つこと**ではなく、**相手が打てるようにすること**である。**手が空いていること**が、そのまま講義の内容になる。講師が画面を指さず、**受講者の顔を見ている**——教える対象は機械ではなく、**その人**である。**コーディネーターの「人とAIをつなぐ」も、この一点で同じ形になる**——講師は二人のあいだに立たず、**横に座っている**。

**支える三点**（最小限）：

1. **講師の自分のノートPCは、閉じている。** 講師の道具は脇に置かれ、**開いているのは受講者の一台だけ**。教える側の機械が閉じていることが、「主役は受講者の手」を二重に言う。
2. **画面には、コードではなく、もう動いている小さなアプリ。** 角丸の面が三つ、丸いボタンが一つ、下に入力欄が一つ。**入力欄には、短い縦の金のカーソルが一本だけ**——次に打つ言葉の場所。**この金が、画面で唯一の飽和色**である。
3. **講師のバッジは、裏返してある。** 組織の名も、役職も読めない。**肩書きではなく、関係で示す**。コーディネーターであることは、**閉じたノートPCと、裏返したバッジ**で足りる。

**潰す誤読**：

| 誤読 | なぜ嘘か | だから描かないもの |
|---|---|---|
| (a) プログラミング教室 | バイブコーディングは**コードを教えない**。画面にコードを置いた瞬間、この一枚は別の商品になる | コード・ターミナル・黒板・構文・エラーメッセージ・緑の文字 |
| (b) 営業・提案の場 | 売りは**教えること**であって、**売り込むこと**ではない。資料や名刺を置けば、講義が商談に変わる | 提案書・グラフ・名刺・握手・スーツ・プレゼン画面 |
| (c) AIの魔法 | AIは**道具**であり、**魔法**ではない。ロボット・脳・回路・ホログラムは、役割を別の物語にする | ロボット・アンドロイド・光る脳・回路基板・ホログラム・デジタル雨・ネオン・魔法の光 |
| (d) 二人の友情 | これは**仕事の場面**である。肩を組む・ハイタッチ・笑い合うは、講義の緊張を消す | 肩組み・ハイタッチ・過剰な笑顔・ピース・自撮り |
| (e) 講師の自慢 | 講師が**最も明るい・大きい・細密な**存在になれば、主役は講師の腕に戻る。**主役は受講者の手**である | 講師の顔のクローズアップ・講師の手元・講師のノートPCの画面 |
| (f) 文字の説明 | 挿絵は**文字を絵に埋めない**。画面の文字も、バッジの名も、吹き出しも置かない | 活字・ラベル・字幕・ロゴ・透かし・読めるUI・もじばけ |

**削ったもの**：コーディネーターの全業務（会議・稟議・研修設計・ガバナンス）——**売りの主軸ではない**／講師の経歴・実績・肩書き——**文字を持てない**／三人目以上——**一点は二人で足りる**／背景の部署・組織図・部署名——**関係は距離で示す**／AIの擬人化——**画面のアプリで足りる**／コード——**この商品の否定**。

| **講師の仕事は、代わりに書かないこと** | **講師の両手はキーボードから離れている。** 近い手は卓上で開き、手のひらを上に、指は力を抜いて受講者の方へ。遠い手はマグを持つ |
| **教える対象は、機械ではなく人** | **講師の視線は、受講者の顔へ。** 画面ではない。受講者の視線は画面へ。**二本の視線が三角形を作り、金のカーソルで閉じる** |

## ④ 同一の世界（人物と場）

**人物は二人。どちらも実在の人物の似姿ではない。**

- **講師（左）**：30代半ば。短い黒髪、細い丸眼鏡、淡い青のシャツ（袖を肘まで）、くすんだセージのカーディガン、裏返した白いバッジ。**丸い静かな顔、艶のない平らな目**。姿勢は楽で、腰を少し落とす。
- **受講者（右）**：20代前半。短い黒髪のボブ、淡い黄のニット、灰色のゆったりしたズボン。**前傾し、両手をキーボードに置く。** 目は画面に、口は少し開く。
- **場**：平日の昼。窓の外は見せない。**白に近い壁、淡い木の長机、丸いスツール二つ。** 机の上は、開いたノートPC一台、閉じたノートPC一台、マグ一つ、バッジ一つ。**他の物は置かない。**
- **光**：画面の外、左上の窓から。**平坦で、柔らかく、影は最小限。** 画面の光は、受講者の手元と机の縁に**淡く平らに**落ちる（グラデーションにしない）。
- **色**：生成り紙の白、ミント、淡い青、淡い黄、くすんだセージ。**飽和色は、画面の金のカーソル一本だけ。**

## ⑤ 構成（Format）

横長16:9。**左に講師、右に受講者、中央やや右に開いたノートPC。** 講師は**左端で切れ、胴まで**、受講者より**少し手前**——**意図的な非対称**。講師の閉じたノートPCは**左端で半分切れる**。机は画面の下辺で切れ、壁は上三分の一を空ける。**中央対称にしない。** 視線の三角形：講師 → 受講者の顔 → 画面の金のカーソル → 講師。**焦点は一つ**——受講者の両手とキーボード、そしてその先の金のカーソル。**余白は上の壁**、そこに**淡い斜光の帯を一本だけ平らに渡す**（グラデーションにしない）。文字は無し。

## ⑥ 様式（Style）

クリーンラインラボ：**教科書の実験図のような細く正確なインク線**、**淡いパステルの平塗り**（ミント・淡黄・淡い青・生成り紙）、**影は最小限**、**奥行きは線の重みと重なりで作り、落ち影は置かない**、**一点だけ飽和した温かい金**（他の暖色の準アクセントは無し）。人物は丸く静かで、**艶のない平らな目**——可愛さは線言語に従属させ、媚びない。**様式カードのラベル／キャプション節は落とす**——挿絵は文字を絵に埋めないため。これは意図的な逸脱である。

## ⑦ 禁止（Negative）

- **文字を描かない**——活字・題字・ラベル・字幕・吹き出し・画面のUIコピー・数字・ロゴ・透かし・署名・もじばけ。**画面は形だけ**、バッジは空白。
- **コードを描かない**——コード・構文・ターミナル・黒板・エラーメッセージ・緑の文字。
- **AIを擬人化しない**——ロボット・アンドロイド・光る脳・回路基板・ホログラム・デジタル雨・ネオン・魔法の光。
- **教室にしない**——黒板・チョーク・教壇・机の列・生徒・教師の指し棒・制服。
- **営業の場にしない**——プレゼン画面・提案書・グラフ・名刺・握手・スーツ・パンフレット。
- **オフィスのスチル写真にしない**——観葉植物・余分なカップ・ノート・ケーブル・ごちゃつき・二つ目の焦点。
- **感情を煽らない**——過剰な笑顔・涙・ガッツポーズ・ハイタッチ・肩組み。
- **講師を主役にしない**——講師の顔のクローズアップ・講師の手元・講師のノートPCの画面。**主役は受講者の両手。**
- **三人目を置かない**——見学者・同僚・撮影者・人影。
- **写実・3D・グラデ・光沢を避ける**——写真・3Dレンダー・デジタルグラデーション・油絵の質感・重い陰影・ウェブトゥーンの艶・エアブラシ・絵画的な筆致・粒子・紙の質感。
- **実在の人物・組織の似姿にしない**——実在の顔・ロゴ・組織名・肩書き。

## ⑧ 忠実性

- 入力の二文を超えない。**コーディネーターの具体的な業務・実績・所属・経歴を足さない。**
- **講師をプログラマーにしない。** コードを書かせない。**受講者にコードを読ませない。**
- **AIを擬人化しない。** ロボット・脳・回路・魔法を置かない。
- **売り込みの場にしない。** 資料・名刺・握手・スーツ・プレゼン画面を置かない。
- **実在の人物・組織の似姿にしない。** バッジは空白、ロゴなし。
- **感情を煽らない。** 過剰な笑顔・涙・達成のガッツポーズを置かない。**静かな集中のまま**。

- 「バイブコーディング講師としての役割をメインの売りにしている」＝ユーザーの一文。**講義の場面を一枚の主場面にする**根拠。
- **バイブコーディングの定義**（自然言語でAIに指示し、動くソフトウェアを作る）は、この語の一般的な用法。**この一枚は、コードを書かないことではなく、コードを読めない人が動くものを作れることを採る。**

## 未判定

1. **人物の特定**：実在の本人を描くのか、役割の類型か。**今は類型**（実在の似姿ではない）。本人を描くなら、写真参考が必要。
2. **年齢・性別・外見**：今は「30代半ばの講師／20代前半の受講者」で、**性別を強く指定していない**。指定があれば差し替える。
3. **画面の中身**：今は「動いている小さなアプリ＋金のカーソル」。**アプリの種類**（予約・タスク・家計・社内ツール）を特定すると、より particular になる。今は汎用のまま。
4. **文字を置くか**：挿絵カードに従い**置かない**。プロフィール用に肩書きを入れるなら、別フォーマット（名刺・ヒーロー画像）にする。
5. **比率**：16:9。正方形プロフィールにするなら、講師と受講者の距離を詰め、画面の金を中央に寄せる。
