# 入力 — AI時代の「個人とサイバーセキュリティ」を、3枚の断面に畳む

> 種別＝**調査ノート／解説の材料**。物語でも記事本文でもない。読んだのは、IPA「情報セキュリティ10大脅威 2026」個人編、デジタル庁の本人確認ガイドライン（2026年2月）、警察庁の2025年詐欺被害確定値、2026年の報道・ベンダー報告・研究報告。作るのは、**個人が日常で使う3つのチャネル（顔・声・文字）**にAIの複製が入ってくる瞬間と、その対処を、3枚の図解に絞ったもの。**画像は生成しない**（`CLAUDE.md` §Verification。引くのは著者）。

| 項目 | 内容 |

## ① 何が来たか（理解）

### 個人編の現在地

IPA「情報セキュリティ10大脅威 2026」の**個人編は10項目・順位なし（五十音順）**である。順位が付くのは組織編だけで、個人編に順位を付けるのは誤りである。

個人編の10項目：

- インターネット上のサービスからの個人情報の窃取
- インターネット上のサービスへの不正ログイン
- インターネットバンキングの不正利用（4年ぶりに復帰）
- クレジットカード情報の不正利用
- サポート詐欺（偽警告）による金銭被害
- スマホ決済の不正利用
- ネット上の誹謗・中傷・デマ
- フィッシングによる個人情報等の詐取
- 不正アプリによるスマートフォン利用者への被害
- メールやSNS等を使った脅迫・詐欺の手口による金銭要求

**重要な留保**：個人編に「AI」という独立項目はない。AI関連の項目は組織編3位の「AIの利用をめぐるサイバーリスク」である。したがって、この3枚では**AIを独立の脅威として描かない**。AIは、個人編の各項目を「本物に見える」方向に押し上げる**増幅器**として扱う。この区別を崩すと、日本の一次情報と食い違う。

### AIが変えたこと

従来の個人向けの見分け方は、**不自然さ**を探すことだった。誤字のある日本語、不自然な言い回し、口の動きの粗さ、知らない番号、慌てた話し方。2026年時点の生成AIは、その不自然さを**大きく減らした**。

- **文字**：誤字のない日本語、正しい敬語、正しいロゴ、正しい文面。フィッシングの手がかりが「文面の粗さ」から「経路の正しさ」へ移った。ボタンは「ログイン」ではなく、その銀行にしか書けない「お取引の確認」のような一言になる。
- **声**：3秒の音声から声を複製できる（精度85%という報告）。偽の声の連絡を受けた人の77%が金銭を失ったという調査もある。緊急性と家族の声が、判断を飛ばす。
- **顔**：著名人のディープフェイク動画が投資詐欺の入口になる。2025年のSNS型投資詐欺は1,288億円（前年比47.9%増、確定値）。2026年4〜6月の国内ディープフェイク検出は約5万1,600件（前期比約9倍）というベンダー報告もある。
- **経路**：認証はパスキーが本命になった。デジタル庁の2026年2月ガイドラインは、フィッシング耐性のある方式をパスキーとPKIに限定している。パスキーはドメインに紐づくので、偽サイトでは使えない。
- **次の波**：AIブラウザ／エージェントの間接プロンプトインジェクション。2026年のBioShocking、BragJack、PerplexedBrowser、Black Hat USA 2026では解析対象の全AIブラウザが脆弱という報告。個人は拡張機能を減らす、機密操作の前に確認する、エージェントにログイン済みアカウントを渡さない、パスワードマネージャーをロックしたままにする。

**具体的な被害例**：2026年6月、東京都内の80代女性が、著名人のディープフェイク動画をきっかけに約9,500万円をだまし取られた疑いで、受け子とみられる人物が逮捕された（FNN）。実名・実在の著名人は画像に描かない。入力の事実としてだけ留める。

## ② 語る一点（選定）

**シリーズの一点＝AIが本物と見分けにくい複製を作れるのは、顔・声・文字。AIが知り得ないのは、あなたが選ぶ検証の経路と、あなたと相手だけが知っている合言葉。**

**なぜこの一点か。** 個人へのAI攻撃は、新しい種類の犯罪ではない。**すでに信じているチャネル**——銀行のメール、家族の声、著名人の顔——に、**本物と見分けのつかない複製**が入ってくる。従来の見分け方は、どこかに「不自然さ」を探すことだった。AIはその不自然さを大きく減らした。だから、**見た目・声・文字だけを証拠にする防御は、それだけでは足りない**。残るのは、**別の経路で確かめる**ことと、**AIが知り得ない合言葉**である。このシリーズは、その「経路」を3枚で描く。

### 3枚の分担

| | 1/3 顔 | 2/3 声 | 3/3 文字 |
|---|---|---|---|
| 偽物の入口 | 著名人のディープフェイク投資広告 | 家族の声のなりすまし電話 | 完璧なフィッシングメール |
| 本物に見える理由 | 顔・表情・声・背景 | 声・話し方・緊急性 | 誤字のない日本語・正しいロゴ・丁寧な文面 |
| 画面の外の手がかり | 中のスタジオ（リングライト・サーバー） | 玄関の空の靴の場所 | 偽の入口の鍵穴（パスワード穴） |
| もうひとつの経路 | 公式の窓口で確かめる | 一度切り、電話帳の番号にかけ直す／合言葉 | リンクは開かず、公式アプリで確かめる（パスキー） |

### 各枚の一点

- **1/3 顔**：**画面の顔は、舞台の表面にすぎない。** 顔はリングライトに照らされ、画面の裏には小さなスタジオがある。**椅子は引かれ、ヘッドセットだけが机に残る——人はいない。** 見る人は顔だけを見る。図解は、顔の裏の装置を見せる。だから、公式の窓口へ迂回する金の線が要る。
- **2/3 声**：**声は、家の外から来る。** 声の線は窓から入り、電話で止まる。玄関には、子どもの靴の**破線の輪郭**だけがある。親の指が通話を切り、金の線がドアの外へ、**電話帳の番号**へ向かう。
- **3/3 文字**：**文面は、扉の鍵穴を証さない。** メールは完璧で、壁の偽の扉はほぼ同じ形をしている。違いは鍵穴だけ——横長のパスワード穴と、丸いパスキーの鍵穴。金の鍵は、本物の扉にしか合わない。

### 潰す誤読

| 誤読 | なぜ嘘か | だから描かないもの |
|---|---|---|
| (a) AIは悪者 | 攻撃者は人物ではなく、**装置と経路**である。フードの人物を描くと、問題が「悪い人がいる」に縮む | ハッカー・フード・マスク・スカル |
| (b) 警告の赤 | 攻撃は**静かで、淡く、完璧**である。赤と警報は、汎用のサイバー警告ポスターになる | 赤い警告・警報・点滅・雷・爆発 |
| (c) 3枚で全脅威を網羅 | 3枚は**3つのチャネル**であって、カタログではない。足すほど、どの一枚も弱くなる | 10大脅威の一覧・統計・年表・その他の手口 |
| (d) 文字を読ませる | 図解は**関係**を描く。長文は読まれず、意味を文字が持ってしまう | 段落・メール本文・UIコピー・長い見出し |
| (e) AIをロボットで描く | AIは**装置の中**にいる。リングライト・サーバー・波形・生成された文面が、AIの姿である | ロボット・光る脳・回路基板・ホログラム・デジタル雨 |
| (f) パスキーは万能 | パスキーは**強い既定**であって、絶対ではない。金融庁はQR型リアルタイムフィッシング等の留保を示している | 「絶対安全」「100%防げる」という断定 |

### 削ったもの

- IPA個人編の他の7項目（不正ログイン、クレジットカード、サポート詐欺、スマホ決済、誹謗中傷、不正アプリ、脅迫）——**3つのチャネルに絞るため**
- 統計・年表・被害額——**画像は関係を描く。数字は input.md に置く**
- AIブラウザ／エージェントの間接プロンプトインジェクション——**第4のチャネル。3枚に足すと詰まる。別の一枚**
- 実在の著名人・実在の銀行ロゴ・実在のSNSロゴ——**⑧違反。似姿と商標は描かない**
- 被害者の嘆き・パニック——**被害者は愚かではない。手は冷静に、次の一手を選ぶ**
- ハッカー・ロボット・回路・南京錠・赤い警告——**汎用のサイバー記号。意味を持たない**

## ③ 翻訳（抽象 → 視覚）

| 抽象 | 具象へ |
|---|---|
| **顔は、本人を証さない** | **タブレットの断面。** 画面の顔の裏に、小さなスタジオ——リングライト、三脚のカメラ、サーバー、引かれた椅子、ヘッドセット。**人はいない。** 顔は淡く、**左の眉だけわずかに高く、右手のほうを向く**。金は、公式の窓口へ迂回する一本の線だけ |
| **声は、本人の所在を証さない** | **玄関の断面。** 電話は窓から入った線で鳴る。玄関の靴棚には、大人の靴と、子どもの靴の**破線の輪郭**だけがある。親の指が通話を切り、もう一台の電話から金の線がドアの外へ、むすこの電話へ出る。壁には合言葉の紙（`せんたくき`） |
| **文面は、窓口の正しさを証さない** | **ノートPCの断面。** 完璧なメールの「お取引の確認」ボタンから、**壁の偽の扉**へ灰色の線。偽の扉はほぼ同じ形で、鍵穴だけが横長のパスワード穴。本物の扉は電話の中に小さく、生成りの紙にインクの輪郭、丸い金のパスキー鍵穴 |
| **AIは、見た目・声・文字の本物と見分けにくい複製を作れる** | **淡いパステルの装置。** リングライトは淡黄、サーバーは淡灰、波形はミント、壁の偽の扉は淡灰。**どれも飽和しない**——AIは「目立たない」。目立つのは、人間が選ぶ金の経路だけ |
| **もうひとつの経路** | **金の一本線。** 偽物を迂回し、公式の窓口・電話帳の番号・本物の扉へ着く。**金は、常に人間の側**にある |
| **合言葉は、AIが知り得ない** | **壁の小さな手書きの紙。** 「せんたくき」。**生成りの紙**に、灰色のピン。金の線は紙をかすめてドアの外へ続く。**言葉は短く、二人だけが知る** |

## ④ 同一の世界（3枚の文法）

- **一枚の図解。** 各枚は分割しない。パネルも、枠も、コマもない。上から下へ読む。
- **同じ配置。** 左上に小さなシリーズ番号（1/3・2/3・3/3）、上に大きな見出し、左／中央に断面の装置、右に**同じ右手**（2/3だけ、同じ人の左手も）と二台目の電話、右下に**検証済みの行き先——描かれた場所か、その人の電話**、下に一行のキャプション。右上と左下は余白。**中央対称にしない。**
- **同じ色。** 生成り紙、淡いミント、淡い青、くすんだ灰。**淡黄は、偽の温もり——リングライトだけ。** **生成りは、手元の信頼——合言葉の紙、本物の扉の輪郭。** **飽和するのは一点の温かい金だけ**——検証の経路と、その終点。AIの装置はすべて淡い。
- **同じ線。** 細く正確なインク線。断面の切り口は細い線と淡い灰の面、画面の面は小さな破線。**重いハッチも、3Dの陰影も置かない。**
- **同じ手。** 手は一組だけ。**3枚とも同じ手**——細い淡灰の指輪、灰色のニットの袖口、親指に小さな淡い絆創膏。丸く、平らで、艶のない指。**人物は描かない。** 手だけが人間である。**指輪は金ではない。**
- **同じ文字。** 短い日本語だけ。見出し、キャプション、**2つのラベル**。メール本文は淡い線で示し、読ませない。**画面内で読ませるのは `お取引の確認`、`むすこ`、`せんたくき` だけ。** **文字が意味を持ちすぎると、図解ではなくポスターになる。**
- **同じ金の意味。** 金は常に**人間が選ぶ経路**。偽物の側に金を置かない。金を偽物に置くと、意味が反転する。**リングライトの淡黄、指輪の淡灰、カウンターの取っ手の淡灰を、金にしない。**

## ⑧ 変えないもの（忠実）

- **順位を付けない**：IPA個人編は五十音順。1位・2位と書かない。
- **AIを独立項目にしない**：AIは増幅器。個人編にAI項目はない、という一次情報の形を保つ。
- **数字を画像に入れない**：1,288億円・5万1,600件・77%は input.md に置く。画像は関係だけを描く。
- **実在の人物・ロゴを描かない**：著名人の似姿、銀行のロゴ、SNSのロゴ。画面の顔は**発明された特定の顔**——左右非対称の眉、まっすぐすぎる生え際。実在の誰かに似せない。銀行の印は**発明された印**（三本の横線）。
- **パスキーを万能にしない**：ラベルは「パスキー」、キャプションは「公式アプリで確かめる」。input.md に金融庁の留保を残す。
- **被害者を愚かにしない**：手は冷静で、指は止まっている。嘆き・涙・パニック・赤い警告は描かない。**この3枚は、責める画ではない。**
- **合言葉を特定の個人情報にしない**：「せんたくき」は仮の言葉。**あえて平凡で、無意味な語**。誕生日・ペット名・SNSで見つかる語にしない。**他人が推測しにくい語（可能なら二語）**が原則。
- **電話の相手を特定しない**：画面の連絡先は「むすこ」。実在の誰かではない。関係（息子・娘・孫）を変えるなら、玄関の破線の靴も合わせる。
