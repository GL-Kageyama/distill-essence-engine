# 入力 — バイブコーディングのキャラクター「キーボードの上の猫」を、挿絵一枚に畳む

> 種別＝**概念＋仕様**。物語でも記事でもない。来たのは「distill-essence-engine を使って、バイブコーディングのキャラを作りたい」という依頼と、その調査材料である。
> 作るのは、バイブコーディングの**一点**を、横長16:9の挿絵一枚に絞ったもの。キャラクターは**猫**（ユーザー選択）。**文字は置かない**（挿絵カード）。**画像は生成しない**（`CLAUDE.md` §Verification。引くのは著者）。

## 仕様

| 項目 | 内容 |
|---|---|
| format | 挿絵（[illustration](../../references/ja/formats/illustration.md)）——レジストリ済み。装飾・一場面×一点・一枚・横長16:9・文字なし |
| style | やわらかい平塗りマスコット（[soft-flat-mascot](../../references/ja/styles/soft-flat-mascot.md)）——レジストリ済み（検証待ち）。丸い平塗り・最小の輪郭線・大きな目・無地の背景 |
| キャラ | 猫（三毛）——ユーザー選択。「キーボードの上の猫」 |
| 用途 | 装飾／伝達の境界。バイブコーディングについての文章・スライド・プロフィールの横に置く一枚。**キャラクターの種**にもなる |
| 言語 | ja（三カラム・説明）。合成プロンプトのみ英語 |

## ① 何が来たか（理解）

**バイブコーディングの来歴**:

- **2025年2月2日、Andrej Karpathy のX投稿で命名。**「vibeに身を任せ、指数関数的な成長を受け入れ、**コードの存在を忘れる**」。
- 本人の言葉：「いつも "Accept All"、もう差分は読まない」「エラーはそのまま貼り付ける」「**I just see stuff, say stuff, run stuff, and copy paste stuff, and it mostly works.**」「使い捨ての週末プロジェクトなら悪くない」。
- **2025年、Collins辞書の Word of the Year。** Merriam-Webster も収録した。
- **定義の核は「コードを書かないこと」ではなく「コードを読まないこと」。** Simon Willison は「LLMに書かせたコードをレビューせずにソフトウェアを作ること」、Martin Fowler は「LLMが生成したコードを一切見ないこと」と定義する。レビューし、テストし、説明できるなら、それはバイブコーディングではなく通常のAI支援開発である。
- **対象は「自分ひとりのためのソフトウェア」「使い捨ての週末プロジェクト」。** 非エンジニアが自分の道具を作る。PCMagの非プログラマーはClaude Codeで家探しサイトを作り、Irish Times は「software for one」と呼んだ。
- **反面、コードは理解の外に育つ。** Lovable は1,645アプリ中170に情報漏洩、Replitは本番DBを削除、CodeRabbitは「AI共著PRは主要問題1.7倍・脆弱性2.74倍」、METRは「経験者は19%遅いのに速いと感じる」と報告した。2026年、Karpathyは「agentic engineering」へ軸足を移し、Willisonは「レビューしないこと」が定義だと整理した。
- **日本の文脈**：藤井聡太の「今年一番ハマった」、paiza×Python VTuberサプ子の無料講座、SHIFT AIの法人コース。非エンジニアの実践として広がっている。

**この依頼の二層**:

- 表の依頼は「バイブコーディングのキャラを作りたい」。**キャラは猫**（ユーザー選択）。
- キャラは**概念の人格化**である。猫は「バイブコーディングをする人」ではない。**猫のキーボードへの関係が、人間のコードへの関係の鏡**になる。

## ② 語る一点（選定）

**猫の体重がキーボードに乗っていて、それでもアプリは動いている。人間の手は、キーボードの上にない——マグを置いたばかりで、指はまだ取っ手の形のまま、一本だけ浮いている。**

**なぜこの一点か。** バイブコーディングの核は「コードを読まないこと」である。**猫はキーボードを読まない——読めない。** それでもキーボードは暖かく、猫はそこにいる。**人間はコードを読まない——読まない。** それでもアプリは動き、人間はそこにいる。**猫の無理解と人間の無理解が、同じ姿勢で並ぶ。** これがこの一枚の「おおっ」である。猫は可愛いから主役なのではなく、**読まない者の姿勢を最も正確に持っている**から主役である。

**手は「休んでいる」のではなく「置いたばかり」であり、まだ「これから」である。** 指はもうマグを持っていないのに、まだ取っ手の形に丸まっている。そのうちの**一本だけが、テーブルから数ミリ浮いている**——置ききっていない。**猫は「もう」、手は「これから」。** 止まっているのではない、**止めたうえで、まだ動ける**のである。これが「Accept All」の姿勢の正体である。

**支える三点**（最小限）:

1. **画面には、コードではなく、もう動いている小さなアプリ。** 大きなミントの面に**一行だけ中身**（小さな丸と短い棒二本——何かが一つ、もう入っている）、淡い青のカードが一つ、丸いボタン、下に**空の入力欄と細いカーソル一本**。**文字はない。** アプリは「もう使われている」という証拠を持つ。
2. **人間の手は、マグを置いたばかり。** 手のひらを下に、**下辺と左辺で切れる**。指は取っ手の形にゆるく丸まり、**一本だけ浮く**。**キーボードにも猫にも触れない。** マグは手の奥、左端で半分切れる。
3. **猫の目は、二つに分かれている。** **画面に近い目は細い一筋**（読まない）、**手に近い目は開いて、小さな瞳が手の側の目尻に寄っている**（見ている）。眠っているのではない。**見ているようで読んでいない**——猫の「監督」は、人間の「監督」の鏡である。**首輪の鈴は黙り、入力欄は空のまま、カーソルが一本待っている。** **返事のない合図が、二つ。**

**潰す誤読**:

| 誤読 | なぜ嘘か | だから描かないもの |
|---|---|---|
| (a) 猫がタイピングする | バイブコーディングは**猫の芸**ではない。猫は**休んでいる**——体重だけがキーに乗る | 前足でキーを押す、タイピング、キーボードの上の行進 |
| (b) 猫がコードを読む | 猫は**読まない**。読む仕草（画面に顔を寄せる、目を細めて文字を追う）は、この一枚の否定 | コード、ターミナル、緑の文字、構文、読めるUI |
| (c) AIの魔法 | AIは**道具**であり、魔法ではない。ロボット・脳・回路・ホログラムは、概念を別の物語にする | ロボット、アンドロイド、光る脳、回路基板、ホログラム、デジタル雨、ネオン、魔法の光 |
| (d) ハッカーの部屋 | バイブコーディングは**台所のテーブル**で起きる。暗い部屋・パーカー・緑の文字は、別の文化 | パーカー、暗い部屋、複数モニター、マトリックスの雨 |
| (e) 猫の芸のミーム | 笑わせる一枚ではない。**静かな一枚**である。猫の「くつろぎ」が主題 | 舌を出す、驚く、コップを落とす、複数の猫、子猫 |
| (f) 文字の説明 | 挿絵は**文字を絵に埋めない**。画面のUIコピーも、ラベルも、吹き出しも置かない | 活字、ラベル、字幕、ロゴ、透かし、読めるUI、もじばけ |
| (g) 人間が主役 | 人間の顔を描けば、主役は人間に戻る。**主役は猫**である | 人間の顔、上半身、二人目、猫を撫でる手 |
| (h) 猫が眠っている | 眠りは「くつろぎ」だが、**見ていない**。この一枚には**目撃**が要る。手に近い目が開いているから、猫は「そこにいる者」になる | 両目を閉じる、顔を伏せる、丸くなって背中だけ見せる |

**削ったもの**：人間の顔・上半身——**主役は猫**／猫の名前・飼い主の設定——**文字を持てない**／部屋の全景・窓・観葉植物——**余白が呼吸**／コード——**この概念の否定**／AIの擬人化——**画面のアプリで足りる**／猫の芸——**静けさが主題**。

## ③ 翻訳（抽象 → 視覚）

| 抽象 | 具象へ |
|---|---|
| **バイブコーディング＝コードを読まない** | **猫はキーボードを読まない。** キーの文字は描かない。キーは形だけ。猫はその上で休む |
| **コードは存在するが、読まれない** | **猫の体重で、いくつかのキーが沈んでいる。** 沈んだキーは、コードの存在だけを示す。読まれない。**沈んだキーは、猫の胸の前の見える帯に置く**——体の下に隠さない |
| **「だいたい動く」** | **画面に、もう動いている小さなアプリ。** コードはない。中身が一行だけ入った面・丸いボタン・空の入力欄。**使われた形跡が「動いている」の証拠** |
| **人間は操作をやめた** | **手はマグを置いたばかり。** 指はまだ取っ手の形にゆるく丸まり、**一本だけ浮いている**。キーボードにも猫にも触れない。**行為の痕跡と、まだ残る気配が、行為の不在を示す** |
| **人間は機械を信頼している** | **猫は暖かいキーの上で休んでいる。** 猫はキーボードを信頼していない——**暖かさ**を信頼している。人間もコードを信頼していない——**動くこと**を信頼している |
| **監督の不在** | **画面に近い目は細い一筋、手に近い目は開いて手を見る。** 見ているようで読んでいない。**鈴は黙り、入力欄は空で、カーソルが一本待っている**——返事のない合図が二つ |
| **コードは理解の外に育つ** | **キーボードの文字を描かない。** 猫の体の下のキーは、形だけで、読めない |
| **vibe＝くつろぎ** | **平らな色だけ。影も光もない。** **珊瑚色の首輪と金の鈴だけが、唯一の飽和色** |
| **行為の痕跡** | **取っ手を離れた指が、まだ取っ手の形をしている。一本だけ浮いている**——**手は「これから」、猫は「もう」** |
| **リスク／借り物の緊張** | **猫の右耳の小さな切れ込み。** 外の生活の痕跡。**画面の方を向いたまま、耳は動かない**——気づいて、動じない。コードの傷も、人間は読まない——説教せず、形だけ置く |

## ④ 同一の世界（キャラクターと場）

**猫（主役）**:

- **三毛。** 生成りの体、柔らかい灰色の斑、**左目のまわりのキャラメル色の斑**、白い口もと、白い尾の先。**右耳に小さな切れ込み**。
- **丸く、ぷっくり。** 大きな頭、小さな体。かわいいプロポーションだが、誇張しない。
- **キーボードの上で、三日月のように丸くなる。** 頭は左（人間の手の方）、尾は右（トラックパッドの上）。あごはキーボードの手前の縁。**前足の一本がノートPCの縁から垂れ、もう一本はあごの下**。後ろ足は畳む。背中は丸い。**体はキーボードの大半を覆うが、胸の前には細い帯が見え、そこに沈んだキーが三、四個ある。**
- **目は二つに分かれる。** 首は画面へ三分の四、**顔は見える**。**画面に近い目は細い一筋。手に近い目は開き、小さな瞳が手の側の目尻に寄る。** 鼻と口は小さい。**表情は平ら——笑わない。**
- **右耳の切れ込みは、画面の方を向いたまま動かない。** 気づいている。動じない。
- **珊瑚色の細い首輪、丸い平らな金の鈴。** **首輪には少し大きいが、よく読める大きさ**。**金は平らな面、鈴の口の細い線だけ**——光らせない。**珊瑚と金が、この一枚で唯一の飽和色。**
- **毛の質感は描かない。** 斑は平らな色面。ひげは短い線を三本まで。

**ノートPC**:

- 開いている。角は丸い。マットな淡い灰色。**画面がこちらに三分の四で見える向き。**
- **画面は、もう動いている小さなアプリ。** 大きなミントの面に**一行だけ中身**（小さな丸と短い棒二本）、淡い青のカードが一つ、丸いボタン、下に**空の入力欄と短いカーソル一本**。**コードも文字もない。**
- **カーソルは細い縦線一本**、アプリの線より少しだけ重い。残像は描かない（二本は文字記号に見える）。
- **猫の体重で、いくつかのキーが沈む。** キーは丸い四角、文字なし。トラックパッドは少し濃い平らな面。**猫の尾がトラックパッドの手前の縁に掛かり、白い先が見える。**

**人間（手だけ）**:

- **下辺と左辺で切れる。手首から先だけ。** オートミール色のカーディガンの袖口。
- **マグを置いたばかり。** 手のひらは下、**指は取っ手の形にゆるく丸まり、握りしめない**。**一本だけ、テーブルから数ミリ浮く**——その下に細い隙間。**キーボードにも猫にも触れない。**
- **マグは手の奥、左端で半分切れる。** 無地の生成り。テーブルに**輪染み**が一つ——マグがそこにあった時間だけを示す。
- **顔は描かない。二人目も描かない。**

**場**:

- **台所のテーブル。** 窓は見せない。**日光もランプも置かない。**
- **淡い温かい灰色のテーブル、生成りに近い壁。** 背景は無地。右側と上に大きな余白。
- **光**：平らで静か。**光源を作らない。** 影も、光の面も落とさない。**色だけ。**
- **色**：温かい中性四色（生成り、クリーム、柔らかい灰色、淡い温かい灰色）＋画面のミントと淡い青＋珊瑚と金のアクセント。**猫はクリーム・柔らかい灰色・キャラメルの三色で描き、口もとと尾先は紙の生成りのまま**——四色目にしない。マグとボタンも同じ生成り。**緑は置かない。**

## ⑤ 構成（Format）

横長16:9。**左に手とマグ、中央にノートPCと猫、右に余白。** 猫は**最も丸く、最も温かい塊**。画面は猫の背の上に覗く。**手は下辺と左辺で切り、猫の顔より下・手前の面に置く**——焦点と同じ高さに並べない。**手は猫より小さい。** 焦点は**猫の顔と首輪**。

**視線の三角形**：**猫の開いた目 → 手。猫の細い目 → 画面。見る者 → 猫。** 手は、キーボードにも猫にも**届く距離に置かれたまま、届かない**。視線が閉じるのは、**猫の顔と首輪**である。**中央対称にしない。** 影は落とさず、猫はキーの上に平らに接する（細い接触線だけ）。**文字は無し。**

## ⑥ 様式（Style）

やわらかい平塗りマスコット：**マットな平塗り**、**細い均一の輪郭線**、**丸い形**、**大きな単純な目**、**小さな鼻と口**、**かわいいプロポーション（大きな頭・小さな体）**、**控えめな表情**、**無地の背景**、**影なし**。**グラデ・光沢・スペキュラ・写実的な毛並みは使わない。**

- **色数**：猫は**三つの平らな色（クリーム・柔らかい灰色・キャラメル）＋珊瑚と金のアクセント**。白い口もとと尾先は**紙の生成り**——インクを足さない。小道具は温かい中性色と、画面のミント／青に限る。
- **様式カードからの意図的な逸脱**：様式カードは「マスコット一人＋無地の背景」だが、この一枚は**場面**である（ノートPC・手・マグ・テーブル）。**マスコットの平らな言語を小道具に拡張し、背景は無地のまま**にする。猫の輪郭線を最も強く、小道具は薄く——**猫が「figure」として読める**ように。**逸脱はここだけ。**
- **なぜこの様式か**：バイブコーディングの「vibe」は、**声を張らないくつろぎ**である。劇場アニメの光や、マンガの強い影は、この一枚を「ドラマ」にする。**交通系マスコットの平らで丸い言語は、猫の体重と、人間の手の静止を、そのまま見せる。** かわいさは**猫の姿勢**に従属させ、媚びない。

## ⑦ 禁止（Negative）

- **コードを描かない**——コード・構文・ターミナル・緑の文字・マトリックスの雨・エラーメッセージ。
- **文字を描かない**——活字・ラベル・画面のUIコピー・数字・ロゴ・透かし・署名・もじばけ。**画面は形だけ。**
- **猫にタイピングさせない**——前足でキーを押す、キーボードの上を行進する、画面を叩く。**猫は休む。**
- **猫を眠らせない**——両目を閉じる、顔を伏せる、背中だけ見せる。**手に近い目は開いている。**
- **AIを擬人化しない**——ロボット・アンドロイド・光る脳・回路基板・ホログラム・デジタル雨・ネオン・魔法の光・「AI」アイコン。
- **画面を光らせない**——光条・グロー・レンズフレア・発光する鈴。**ミントは色であって、光ではない。**
- **手を触れさせない**——キーボードに手を置く、猫を撫でる、マウスを持つ、タイピング。**手は取っ手の形のまま、テーブルの上。**
- **手を握りしめない**——拳、白くなる指、何かを掴む形。**ゆるく丸めて、一本だけ浮かせる。**
- **動きの線・効果音・エマナタを描かない**——「静か」は線で描かない。
- **ハッカーの部屋にしない**——パーカー・暗い部屋・複数モニター・緑の文字。
- **オフィスにしない**——観葉植物・書類・ケーブル・ごちゃつき・二つ目の焦点。
- **窓・日光・ランプを置かない**——外の光を作らない。**平らな色だけ。**
- **人間を主役にしない**——人間の顔・上半身・二人目・猫を撫でる手。
- **猫の芸にしない**——舌・驚き・コップ落とし・複数の猫・子猫。
- **写実・3D・グラデ・光沢を避ける**——写真・3Dレンダー・グラデーション・光沢・スペキュラ・写実的な毛並み・重い陰影・落ち影・ごちゃついた背景。
- **中央対称にしない。**

## ⑧ 忠実性

- 入力の概念を超えない。**コードを読まないこと**が核。**コードを描かない**ことで守る。
- **猫をプログラマーにしない。** 猫は休む。**人間を操作者にしない。** 手はマグを置いたばかりで、キーボードの上にない。
- **猫を眠らせない。** 眠りは「くつろぎ」だが、**目撃**がない。手に近い目を開けて、手を見せる。
- **手を握りしめない。** 指はゆるく取っ手の形を保ち、一本だけ浮く——**「これから」を、拳にしない。**
- **AIを擬人化しない。** 画面のアプリだけがAIの姿。
- **リスクを説教しない。** 猫の体重・耳の切れ込み・読めないキーで、緊張を形だけ置く。
- **合図を説明しない。** 鈴とカーソルは、絵の中の物として置く。キャプションを付けない。
- **実在の人物・組織の似姿にしない。** 手は類型。ロゴなし。
- **感情を煽らない。** 過剰な笑顔・達成のポーズ・涙を置かない。**静かなくつろぎのまま。**

## 未判定

1. **猫の色**：三毛を選んだ。**黒猫＋珊瑚の首輪**なら、より図形的で、影のようになる。**白猫**なら、画面のミントと最もよく響く。差し替え可。
2. **人間の特定**：手だけ。**誰の手か**は描かない。本人の手にするなら、写真参考が必要。
3. **画面の中身**：汎用の小さなアプリに、**一行だけ中身**を入れた（使用の痕跡）。**特定の道具**（鳥の記録・レシピ・乗車時刻）にすると、より particular になる。今は汎用のまま。
4. **比率**：16:9。**正方形**なら、猫を中央に寄せ、手を右下に。プロフィール用なら正方形。
5. **文字を置くか**：挿絵カードに従い**置かない**。キャプションは絵の外に。
6. **様式の検証**：soft-flat-mascot は**検証待ち**（registry）。この一枚は検証ケースになりうる。
7. **キャラの再利用**：この一枚は挿絵であり、モデルシートではない。**同じ猫を何枚にも使うなら**、このプロンプトをキャラクター参照にして、モデルシートを作る。
