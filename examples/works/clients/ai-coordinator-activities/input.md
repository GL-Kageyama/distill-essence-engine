# 入力——AI活用推進コーディネーターの「実際の活動」を、三場面の一枚に畳む

> 種別＝**事業の説明文書**。物語でも記事でもない。読んだのは `AI業務改善基盤/資料` のうち、活動の中身を持つ文書——[バイブコーディング 01-002](../../../../AI業務改善基盤/資料/事業/バイブコーディング/01_構想・方針/002_概要_バイブコーディングによるAI業務改善支援_v0.1.md)（支援の原則・標準の進め方・ガードレール）、[外の日 03-001](../../../../AI業務改善基盤/資料/日々の活動/03_手順/001_手順_外の日の動き方_v0.1.md)（研修の日）、[内の日 03-002](../../../../AI業務改善基盤/資料/日々の活動/03_手順/002_手順_内の日の作り方_v0.1.md)（制作の3条件・手順書の3点セット）。
> 作るのは、**この人が現場で何をしているか**が一目で分かる横長の一枚。方針や現在地ではなく、**手の動き**を描く。**画像は生成しない**（`CLAUDE.md` §Verification。引くのは著者）。

**この一枚が描くのは、生業（AI活用推進コーディネーター）の現場だけ。** 表現（AIクリエイター）と生活（家庭）は入らない——別の一枚である。

## ① 何が来たか（理解）

- **支援は「教える」で終わらない。** 標準の進め方は 棚卸し → 選定 → 試作 → 現場検証 → 定着 → 評価。研修は入口（S1〜S2）で、本体はそのあとの伴走と定着（S3以降）にある。入口は単体で採算に乗せず、本体への移行を前提に設計する。
- **成果物の定義が厳しい。** 「動く」「渡せる」「直せる」の3つが揃って初めて渡せる。「渡せる」＝**置き場所・使い方・直し方の3点セット**が揃っていること。**個人のPCにしかない道具は、成果物として数えない。**
- **手順書の3点セット**は、置き場所（共有フォルダのどこ、担当は誰）・使い方（5手順以内）・直し方（変えてよい場所、変えたら確認すること、連絡先）。
- **保守担当は、作った本人以外から1名**。3か月使われなければ廃止を検討する。つまり**3か月後に、まだ使われているかを見る**。
- **研修の成果物は、参加者が作った道具1点。** こちらの教材は手段でしかない。
- **原則は「業務が先、道具は後」「小さく作って、早く捨てる」「作った人に閉じない」。** 支援の中心は、作り方を教えることではなく、**作ってよいものと、作らないほうがよいものを判断すること**。
- **活動は外の日と内の日に分かれる。** 火曜は「会って決める」日（商談・研修・契約交渉・税理士・銀行・役所）、木曜は「渡せる形にする」日（設計・制作・資料づくり）。この一枚は、外の日のうち**研修**と、その後の**伴走・定着**を描く。

## ② 語る一点（選定）

**この仕事の成果は、最後のコマにコーディネーターがいないこと。**

**なぜこの一点か。** 「AIの研修をしています」は、どの研修会社でも言える。この支援にしかないのは、**渡した道具が本人の手で動き、他の人の名札が付いて、講師がいなくても残る**という設計である。原則3「作った人に閉じない」、ガードレール5「保守担当を本人以外から1名」、そして「個人のPCにしかない道具は成果物として数えない」——三つとも同じことを言っている。**この仕事は、いらなくなるために行く。**

**支える三点**（三コマがそのまま支えになる）：

1. **研修で、作らせる。** 講師は作らない。参加者の画面に、小さな道具が一つ生まれる。講師は机の端に立っていて、どのキーボードにも触れていない。
2. **伴走で、操作させる。** 同じ参加者と、同じノートPC。**マウスを握っているのは参加者の手**で、講師の手は机の上にある。横に、手順書の下書き——置き場所・使い方・直し方の三行。
3. **定着で、いなくなる。** 3か月後、同じ机に別の同僚が座り、**あの参加者が隣から手を伸ばして一行だけ直している**（「直せる」の証拠）。机の上には清書された手順書、**その下に、取り消した一行がそのまま残った業務一覧**、そして**「保守」で始まり名前を手順書に半分隠された名札**。講師の椅子は、奥に押し込まれて空いている。

**背骨は、講師の距離。** 後ろ（研修）→ 隣（伴走）→ 不在（定着）。この三つは、そのまま「教える／任せる／渡す」である。**距離が離れるほど、仕事が進んでいる。**

**通しの小道具は、金のタブが付いた小さな道具。** 1コマ目は受講者のノートPCの画面に、2コマ目は同じ画面に、3コマ目は共有フォルダの中に——**同じものが、持ち主を変えて残る**。色はこの一点だけに使う。

**潰す誤読**：

| 誤読 | なぜ嘘か | だから描かないもの |
|---|---|---|
| (a) 講師が教えている画 | 教えるのは最初の一度だけ。主役は受講者の手と、渡ったあとの道具 | 壇上・プロジェクター・教鞭・大勢の前で話す講師 |
| (b) 明るい会社紹介 | 笑顔の集合写真にすると、**誰の仕事か**が消える | 顔の見える人物・握手・ガッツポーズ・ロゴ・社名 |
| (c) 成果の数字 | この仕事の成果は数字ではなく「いなくなれること」 | グラフ・パーセント・KPI・削減時間の表示 |
| (d) 立派なオフィス | 机は一つ、窓は一つ。同じ場所で三度 | 広いオフィス・観葉植物・コーヒー・私物の山 |
| (e) 三つの別々の場面 | 別々に見えたら、連鎖が消える | 別々の部屋・別々の人物・別々の机 |
| (f) 説明の文字 | 活動は手と物が語る。文字は名前に留める | 段落・吹き出し・長い見出し・キャッチコピー |

**削ったもの**：商談・契約交渉・税理士・銀行・役所——**外の日の他の5種類。別の一枚**／内の日の設計・資料づくり——**手元の仕事。この一枚に残るのは、制作の結果だけ**／16タイプ・6フェーズ——**分類。活動ではない**／料金・実績——**営業の紙**／試作を捨てる話——**この三コマの外**／数字——**この仕事の成果は数字ではない**。

## ③ 翻訳（抽象 → 視覚）

| 抽象 | 具象へ |
|---|---|
| **業務が先、道具は後** | **机の上の印刷物。** 1コマ目、業務一覧の一枚。**一行だけ鉛筆で取り消されている**——やらないと決めた業務。その理由は書かない |
| **研修の成果物は、参加者が作った道具1点** | **受講者のノートPC。** 表計算の画面の隣に、**金のタブが付いた小さな窓**が一つ、生まれている。講師の手は、どのキーボードにもない |
| **伴走は、任せること** | **マウスを握る参加者の手。** 講師の両手は机の上。**手順書の下書き**が間に一枚——置き場所・使い方・直し方 |
| **作った人に閉じない** | **3コマ目の机。** 別の同僚が操作し、**あの参加者が隣から手を伸ばして一行だけ直している**。**講師の椅子は奥に押し込まれ、空** |
| **保守担当は本人以外から1名** | **印刷された小さな名札。** 「保守」で始まり、**名前は手順書に半分隠れている**。参加者の名前ではない |
| **道具は共有フォルダに置く** | **フォルダの窓。** 金のタブの道具が、その中にある。個人のPCの画面ではない |
| **3か月後に、まだ使われているか** | **窓の外の街路樹**と、**手順書の状態**（鉛筆の下書き→活字の清書）。緑 → 緑 → 裸。時計もカレンダーも描かない |
| **この仕事は、いらなくなるために行く** | **3コマ目の不在。** 説明しない。椅子と名札が言う |

## ④ 同一の世界（同じ部屋・三度）

- **同じ会議室。** 長い白い机が一つ、左に窓が一つ、窓の外に街路樹。三コマとも同じ角度・同じ寄り。**動くのは人と物と季節だけ。**
- **線は細く正確。** 教科書の実験図の線。塗りは淡いパステル（オフホワイトの紙、淡いミントの壁、淡い青の窓の光）。影は最小。
- **金は一点だけ。** 金のタブが付いた小さな道具。それ以外に彩度の高い色はない。
- **顔は描かない。** 後ろ姿と、机の上の手。カメラは仕事を見ていて、人を見ていない。人物は匿名の事務職で、実在の顧客ではない。
- **文字は短い日本語ラベルだけ。** 「業務一覧」「手順書」「置き場所」「使い方」「直し方」「保守」。**時制ラベルは置かない**——時間は街路樹と手順書の状態が言う。吹き出しなし。
- **季節で時間を言う。** 1コマ目と2コマ目は緑、3コマ目は裸の枝。光は左から。

## ⑧ 変えないもの（忠実）

- **活動を変えない**：研修（参加者が道具を1つ作る）→ 伴走（本人が操作する）→ 定着（手順書・置き場所・直し方・保守担当）。これは [01-002 §4・§6・§8](../../../../AI業務改善基盤/資料/事業/バイブコーディング/01_構想・方針/002_概要_バイブコーディングによるAI業務改善支援_v0.1.md) と [03-002 §4](../../../../AI業務改善基盤/資料/日々の活動/03_手順/002_手順_内の日の作り方_v0.1.md) の記述のまま。
- **3点セットを変えない**：置き場所・使い方・直し方。**4点に増やさない。**
- **数字を作らない**：削減時間・受講者数・料金・成果のパーセントは、この一枚に置かない。**3か月**だけは資料にある（3か月後の評価、3か月使われなければ廃止）。
- **講師を主役にしない**：1コマ目は後ろ、2コマ目は隣、3コマ目は不在。**この距離を縮めない。**
- **道具を講師のものにしない**：金のタブの道具は、1コマ目から受講者の画面にある。**講師のPCを描かない。**
- **匿名を守る**：実在の顧客・同僚を描かない。名札は「保守」で止め、**名前は手順書に半分隠す**——伏字ではなく、隠れている形にする。
