# ガイディングライト — ロゴ（マークのみ）

ブランドモチーフ（[input.md](input.md)）から、**同じ内容**を4つの様式で描いたロゴ案。
差し替えたのは様式だけ——マークの骨格は4案で共通。

## 共通の内容（4案で変えないもの）

- **語る一点**＝灯の芯から上がる**炎が、そのまま一頭のシャチになっている**瞬間。
- **灯**＝浅い油皿・小さな輪の把手・低い脚の三つの塊。製品ではなく、灯りの原型。
- **炎＝シャチ**——尾びれを芯に広げ、体を少し起こし、**背びれを炎の縁から横へ突き出す棘**に、**頭を炎の先端**に、胸びれを横へ跳ねる火の舌に。
- **目**＝白熱の一点。マークの中で最も明るい場所は、ただ一つの目。
- **人は描かない**。導かれる者は見る者自身。群衆を描くと「人を照らす光」の説明になる。
- **光は一筋**。頭の上へ細く開く。四方への光条は「希望＝光」の記号なので描かない。
- 正方形・中央・余白を広く・1色でも成立。

> **なぜ誘導灯の記号（緑の走る人）を使わないか**——それは製品カテゴリの記号で、ブランドの灯りではなくなる。灯りの原型に、名の由来であるシャチを重ねることで、「21世紀の闇を抜ける光」が**このブランドだけの形**になる。

## 配色の提案

基本は依頼どおり「炎の色（黄→橙）」。そのうえで3案を提案する。

| 提案 | 地 | 炎 | 白熱 | 理由 |
|---|---|---|---|---|
| **海と灯**（推奨） | 深海 `#06232B` / `#0B3038` | `#F2B45C` → `#E8742C` | `#FFFDF6` | 名の由来の「光の差す海」を地に。冷たい海が、暖かい灯りを**唯一の導き**にする。暗闇＝海、光＝灯り、が二温度で一度に立つ |
| **夜と灯** | 夜紺 `#081828` | `#F5B14E` → `#FF8C42` | `#FFFFFF` | 既存のダークグロー系の実績パレット。デジタルで最も強い |
| **墨と灯** | 墨 `#171512` | 燠 `#D9551F` 一点 | 和紙 `#EFE7D8` | 1色・印刷・刻印・刺繍に強い。名刺や封蝋まで落とせる |

- 避ける色: シアン・紫・多色の虹。灯りは暖色の一系統に閉じる。
- どの案も、生成後に地の色だけ差し替えれば成立する（マークは1色の閉じたシルエットのため）。

## 使い方

1. `prompt.md` の**合成プロンプト**を Stable Diffusion / Midjourney などに貼る。
2. 正方形（1:1）で生成する。
3. 受け入れ判定は3つ——**16px で読めるか / 1色で成立するか / 白地と黒地の両方で立つか**。
4. 4案は同じ内容の様式違い。混ぜず、1案を選んで詰める。
