# ガイディングライト — ロゴ（マークのみ）

ブランドモチーフ（[input.md](input.md)）から、ロゴの基本形の候補を並べる。**A〜Dは未決、Eは不採用**——判断は [採決表.md](採決表.md) に置く。

## 現在の方向

- **白背景**。以後の焼きは白地で行う。
- **ランタンは有機的で、滑らかで、抽象的**。**把手は持たない**。丸い台・洋梨のガラス・短い首・小さな傘の三つでランタンと読める。直線も、段も、太い側枠も持たない。
- **炎はシルエット**。内部の描き込みはしない——目も、白斑も、描いた鰭の線も持たない。
- **シャチは輪郭で読ませる**。姿勢は候補ごとに変える（跳ねる・丸まる・斜めに昇る・**半分はみ出す**）。**輪郭は正確に描き、内側の描き込みを削ぐ**——それが「匂わせる」の中身。立ち上がりは炎にも見える。
- 人は描かない。光条も描かない。
- 正方形・中央・余白を広く・1色でも成立。

## 配色

基本形は**白地に墨と琥珀**。墨のランタン、珀の橙 `#E8742C` の炎、ガラスは白抜き。**1色版では炎も墨になり、ガラスだけが白く抜ける**。

暗い地での応用として3案を持つ。

| 応用 | 地 | 炎 | 白熱 | 理由 |
|---|---|---|---|---|
| **海と灯**（暗い地の推奨） | 深海 `#06232B` / `#0B3038` | `#F2B45C` → `#E8742C` | `#FFFDF6` | 名の由来の「光の差す海」を地に。冷たい海が、暖かい灯りを**唯一の導き**にする |
| **夜と灯** | 夜紺 `#081828` | `#F5B14E` → `#FF8C42` | `#FFFFFF` | ダークグロー系の実績パレット。デジタルで最も強い |
| **墨と灯** | 墨 `#171512` | 燠 `#D9551F` 一点 | 和紙 `#EFE7D8` | 1色・印刷・刻印・刺繍に強い |

- 避ける色: シアン・紫・多色の虹。灯りは暖色の一系統に閉じる。
- 海と灯の焼き用プロンプトは [guidinglight-logo-sea-light](guidinglight-logo-sea-light/prompt.md)（暗い地の応用）。

## 使い方

1. **候補 A〜D** を焼く。白地で、ランタンと炎のシルエットが立つかを見る。
2. [採決表.md](採決表.md) の観点で並べる——**16px で読めるか / 1色で成立するか / 白地と黒地の両方で立つか**。
3. 採用が決まったら、必要なら様式を白地で振り直す。

焼いた絵は同じフォルダに置く。
