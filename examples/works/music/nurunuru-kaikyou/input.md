# 入力：主題歌「ヌルヌル海峡」を、霧の岸の一瞬に畳む

> 種別＝**歌**（主題歌一式）。物語ではなく、**外部の概念**——落合陽一の「ヌル」（null／空／計算機自然）——を、**ド演歌**の節調に畳んだ一曲である。**万博パビリオンの歌ではない。**
> 入力ファイル＝`soul-voice-teller/examples/nurunuru-kaikyou/届ける/theme-song.md`（正典。読み違い予防版は同ディレクトリの `theme-song-mix.md`）
> 作るのは、この歌が歌う**一つの瞬間**を、横長16:9の水彩一枚に絞ったもの。**文字は入れない。**

---

## ① 何が来たか（理解）

- **種別**：歌（主題歌一式）。歌詞・曲調指定・ボーカル指定・楽曲説明・挿入位置から成る。**この一枚の入力は歌であって、小説ではない。**
- **歌の形式**：ド演歌（本格演歌）。女性ヴォーカル、こぶし、72 bpm、4/4、都節／ヨナ抜き短音階、三味線・尺八・琴・ストリングス・エレキギターのトレモロ。**ポップスとの混成ではない。** 曲調がすでに「夜」を宣言している。
- **歌が畳んだ概念**：**null は零でも無でもない**（値の不在・未定義・まだ何にもなっていない）／**空は形が立ち上がる条件**（無ではない）／98%反射の**伸縮性鏡膜**が自分の像を持たず周囲を映す／**Mirrored Body**——名・声・姿を取ったあと何が残るか／**計算機自然**（十分に発達した計算機群は自然と見分けがつかない）／**声字実相**／**即今**。
- **核心の問い**：**名前・声・姿を取ったあと、何が残るか。**
- **フック**：**「掴めば消えて　離せば還る」**。題名が場所、この一行が動き。以下のすべて（水面・鏡・蔓・根・森・熊・「まだ何にもなっていない」）は、この動きから導かれている。
- **歌が自分で宣言している場面**：**霧の海峡の岸。女がひとり、渡し船の灯を見送っている。水面は鏡。名を呼べば、霧が自分の声で返す。夜の森へ降り、熊を追い、また岸へ戻る。夜が明ける。女はまだ、何にもなっていない。**
- **感情が立ち上がる場所**：**万葉集14-3378「引かばぬるぬる吾にな絶えそね」**——引けばぬるりとついてくる蔓のように、縁は切れない。8世紀の恋歌が、概念の触感を先に歌っている。
- **歌わないと決めたもの**（この歌の境界）：万博／パビリオン／来場者数／閉幕・解体・移転／施設の名（ヌルヌルネクサス・テトラヌル）／書の名（マタギドライブ）／AI・計算機の**説明**（講義）。**語そのものは置くが、説明はしない。**

## ② 語る一点（選定）

**語る一点＝霧の岸の岩の上。指が蔓を握った。蔓は指のあいだから滑り抜けた。それでも、根は岩にある。**

- この歌で、フック「掴めば消えて　離せば還る」が**物の形を取る**のは、Verse 3 と Bridge の**蔓**である。
  - Verse 3：**「岸に絡んだ　いわい蔓／引けばぬるりと　ついてくる」「自性の欠如　縁起の根／水にしずまぬ　根がある」**
  - Bridge：**「引かばぬるぬる　吾にな絶えそね／万葉集　ぬるぬる／いわい蔓　スペリヒユ」**
- **引けばぬるりと外れるのに、切れない。** 掴めないことと、離れないことが、一本の蔓に同時にある。**これが null の触感であり、この歌の感情の出どころである。**
- 8世紀の一行が、そのまま手ざわりになっている。**歌のいちばん古い場所を、いちばん近い手前に置く。**
- 岸の場面なので、霧・鏡の水面・渡し船の灯は、蔓のまわりにそのまま残る。**一点に絞っても、歌の場所を失わない。**

**選ばなかったもの**（選定の半分は捨てること）：

- **霧が自分の声を返す瞬間**（Mirrored Body・二つの鏡）——歌の核心にいちばん近いが、**先例の null²音頭が同じ機構（同じ姿が二人、半拍ずれる）で描いている。** 二曲は同じ「ヌル」への**昼と夜の二つの扉**であり、同じ絵を二度描けば、夜が昼の説明になる。**機構を写さない。**
- **森と熊**（Verse 5・6）——別の世界である。入れると焦点が二つになる。
- **御神体・ロボットアーム・ミラーキューブ**——装置のスペック。歌が「説明しない」と決めた側に近い。
- **夜明け**——歌の終わりの**状態**であって、動きではない。この一枚は動きを描く。
- **題字**——挿絵の文法は「文字を絵に埋め込まない」。文字が無くても、この一枚は歌の顔になる。

## ③ 翻訳（抽象 → 視覚）

| 抽象（歌の語） | 具象へ |
|---|---|
| 掴めば消えて 離せば還る | **握った指のあいだを滑り抜ける蔓。** 落ちる一滴。**それでも根は岩の割れ目にある**——掴めていないのに、離れていない |
| いわい蔓（スペリヒユ説） | 小さな多肉の楕円の葉をつけた、地を這う蔓。濡れて茎に艶がある |
| 水にしずまぬ根 | 根は**水面より上の**岩の割れ目に食い込んでいる。水に浸かっていない |
| 水面は鏡　持たぬ貌 | 水は空と霧と女の**背**だけを写し、顔は写さない（女はうつむいている） |
| 98%の鏡膜 | 水はほぼ完全な鏡。波はない。**指先の一滴だけが輪を作る** |
| 渡し船の影が消える | 船は無い。**灯の映りだけが水面に一本、残っている** |
| 霧（あちらの岸は霧ばかり） | 向こう岸を消す白。**地平線が無い** |
| 世界は聴くものに変わる | **音のない絵。** 波も、鳥も、風も描かない |
| 名も声も姿を捨ててゆく | 女の顔を描かない。**名も声も姿も、画面の外に置く** |

- **particular**：この蔓。この岩。この一滴。**「蔓一般」ではなく、指のあいだから抜けた、この一本。**
- **indirect**：「掴めば消えて離せば還る」を、文字でも矢印でもなく、**手に残っていない手**で描く。見る者は、蔓がまだ岩についていることに、**二度目に気づく**。意味は、見る者の拡張のなかで立つ。
- **抑制**：劇的にしない。嵐も、大波も、月も、燃える空も無い。**静けさが、この歌の演歌である。**

## ④ 一つの世界（一貫）

- **時**：夜。夜明け前。**日は昇らない。** 光は灯だけ。
- **場所**：霧の海峡の岸。濡れた黒い岩。鏡のような浅い水。向こう岸は霧で消えている。
- **人物**：女ひとり。うつむき、背と肩だけ。**顔は描かない。** 着ているものは無地の暗い作業着——**着物の柄を描かない**（歌は衣装を歌っていない）。
- **天候**：霧。無風。**波紋は、一滴の落ちた一点だけ。**

## ⑤ 配置（構成）

- **焦点（手前・最大）**：手・蔓・一滴。**下三分の一、左寄り。**
- **支え（中景）**：女の背と肩。焦点のすぐ後ろ。
- **文脈（遠景）**：霧。**地平線を描かない。** 灯の映りは**右下**、小さく、細く。
- **余白**：霧と水面。**残した白がこの一枚の主役である。**
- 蔓は**画面の外へ切れる**。植物がフレームの外へ続いていることを、切れ際で語る。

---

## ⑥ 様式（水彩）

- **水彩は鏡と同質である。** 鏡膜は「面が世界を写す」もの、水彩は「白い紙と薄い重ねが光を写す」もの。だから鏡の面を描き込まず、**滲みと白**で描く。
- 夜の水彩は濁りやすい。**藍とプルシアン藍の薄い重ね**で夜の深さを出し、**白は紙のまま残す**。灯の温色は**一点だけ**。
- 硬いインクの輪郭を置かない。縁は**淡い色の縁**。

## ⑦ 否定（描かないもの）

- **万博と装置**：パビリオン・ロボットアーム・ミラーキューブ・鏡の箱。
- **二人目の人物**：分身・鏡像の人物。**女はひとりである。**（水に写るのは彼女の背だけ）
- **顔・目**：描かない。
- **文字**：題字・看板・ラベル・矢印。
- **劇的な天候**：嵐・雷・大波・しぶき・燃える空・日の出。
- **様式の破れ**：写真の質感・油絵の厚塗り・3D・デジタルの滑らかなグラデーション・硬い輪郭。

## ⑧ 忠実性のための禁止

- **概念を名指ししない**——「AI」「null」「計算機自然」の文字も、それを示す記号（回路・歯車・ロボット）も描かない。テーマは、**手・蔓・根・水面の位置**にだけ置く。
- **説明しない**——歌が解説を歌わないのと同じく、絵も解説しない。矢印も、分解図も、注記も無い。
- **後日談を描かない**——万博・閉幕・解体・移転。**この歌は概念の歌であって、出来事の報告ではない。**
- **結末を描かない**——夜明けの光を入れない。女はまだ、何にもなっていない。**この一枚は、その手前で止まる。**
- **様式を内容の説明に使わない**——水彩の滲みは「曖昧さ」の記号ではない。**面が光を写す媒材**として選んでいる。
