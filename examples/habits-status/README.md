**一と二は二枚で一組である。** 同じ一冊を、俯瞰と接写の二つの位置から撮ったもので、**一話一カット**の作品の側の語彙（カメラが置けるのは手・物・顔）に合わせ、位置だけを変えている。**一枚目が「全量」、二枚目が「現在地」**——役割は重ならない。

**三は、その二枚が畳んだものを開く。** 第一枚は全量を**一冊の紙面**に畳んだので、個々の要素は見えない。第三枚は**同じ全量を、物の数だけに開く**——世界観の要素とモチーフを、出典が「運搬」として読み直している順に、一列に置く。**一と三の差は、畳み方である。**

> **第三枚だけ、文字を置かない。** 一と二は進みを「書かれた字の解像度」で示した。**三はそれができない**——列に並ぶ物の上に読める印が一つも無いからである。**ゆえに解像度は、字ではなく「その物がどう作られたか」へ移る。**

## 進みを何で測るか——三つの解像度

作品の【ルック】が既に定めている物差しを、そのまま制作の物差しにする。**外から借りた比喩は使わない。**

| 解像度 | 制作の側で何を指すか | 出典の語 |
|---|---|---|
| **鉛筆** | まだ消せる——**構想** | 「消されずに残った名」（一巻の紙） |
| **ボールペン** | 消せない——**設計** | 【ルック】の三つの解像度 |
| **印刷** | 機械が刷った——**出力** | 同上 |

**朱の印は「刷られた」の印であって、「決定稿」の印ではない。** この作品のビジュアルに決定稿はまだ一つも無い（[`../habits/character/README.md`](../habits/character/README.md)）。**朱が一つも無い行が在ることは、破れではない。**

## 一枚の型

二枚とも、隣の樹と同じ書き方である——`# 見出し` / 出典の語 / 内容・フォーマット・様式 / `## 合成プロンプト（Merged）`。**Merged は英語**（distill の規則）。**この二枚は `input.md` を共有する**（作品の樹が `input.md` を共有しているのと同じ規則）。
