# メモ → 解説図（理解）

- 入力: メモ（[input.md](input.md)）
- format: 解説図（理解・全弧×畳み込み・縦長）—— 未登録（生成 → 登録候補）
- style: バウハウス系ベクター（未登録 → 登録候補）
- trace: false（通常モード＝3欄のみ）

## 内容（Content）
語る一点＝**「全部」と「1つ」の対比**。既存＝やること全部のリストの山（見るだけで疲れる）。新＝起きたら「1つだけ」提示し、完了で次の1つへ。やる気は「1つできた」で積み上がる。差別化を、リストの山 vs 1枚のカードとして示す。

## フォーマット（Format）
縦長の解説図、2 段。上段＝既存（タスクの山が崩れる）。下段（焦点）＝ループ（起きる → 1つの行動 → 完了 → 次の1つ）が 1 枚ずつ進む。階層で「1つ」を立て、余白で軽さを出す。

## 様式（Style）
バウハウス系フラットベクター：機能的なグリッド、平坦な色面、アクセント 1 色、細いサンセリフ、装飾なし。

## 合成プロンプト（Merged）
Tall vertical Bauhaus-style flat vector diagram, two stacked sections. Top: a pile of task cards collapsing under its own weight. Bottom, the focal section: a single loop — wake → one action → done → next one — each step a single clean card. One accent color, functional grid, thin sans-serif, wide negative space. Not photorealistic, no 3D render, no decorative illustration.
