# 入力：世界モデル三構想（①④⑤）

> 出典: `資料/発想/概念深掘りエンジン_構想` / `資料/発想/世界モデル生成器_構想` / `資料/発想/世界モデル評価レイヤー_構想`

## ① 概念深掘りエンジン

AI生成は「見える部分」ばかり作って薄っぺらい。氷山の一角の「下部」を作り込む。

- 表面（表層）を支える見えない下部（前提・成立条件・因果・制約・含意・意味）を、問いで掘り出す
- 再帰的。表面→下部→…→不変項（人は死ぬ、時間は戻らない）まで掘る
- 二つの出口：**作り込む**（下部を埋めて表層を支えさせる）／**ピックアップ**（下部から新しいアイデアを釣り上げる）
- 物語に閉じない——主張・設計・プロダクトなどあらゆる概念に適用できる

## ④ 世界モデル生成器

一つの物語ではなく、**物語を生む「母体（世界）」**を作り、蓄積・再利用する。

- 5構成要素：世界・人物・ルール・因果・感情
- 6性質：核・整合性・歴史・対立・余白・問い
- 核＝一点のズレ×広い波及（フォース、ミノフスキー粒子）
- 世界モデルから物語を取り出す。蓄積はYAML・gitで資産化

## ⑤ 世界モデル評価レイヤー

世界モデルを「肥沃さ（物語を安定して生める力）」で検品する。

- 静的検品：6性質（核・整合性・歴史・対立・余白・問い）を直接点検
- 動的検品：住める判定＝世界から2本以上の物語を切り出して評価
- 弱い箇所を①④へ戻す＝ループのブレーキ

## 三つの関係（ループ）

```
①深掘り → ④世界モデル生成器 → ⑤評価レイヤー → ①深掘り（弱い箇所を修正）→ …
```

- ①＝掘る（原理・深掘り。分野を問わない）
- ④＝構造化する（物語・世界に特化。蓄積・再利用）
- ⑤＝検品する（世界の肥沃さを測り、弱い箇所を①④へ戻す）
- **深めるエンジン（①＋④）と検品するエンジン（⑤）が揃って初めて「自動で深く、かつ破綻しない」世界を作れる**
