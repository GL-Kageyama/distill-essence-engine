# 午前二時の幽霊 → キャラクター設定画（真白）

- format: キャラクター設定画（character-sheet・0.1.28 新カード・伝達＝制作仕様）
- style: セルシェード（cel-shade・検証済み）

## 内容（Content）

②選択＝**「実体」であることを仕様として書く**。真白＝「目立たない」高校二年生（design 2-1: 画面を撫でるように速く動く指・長時間のスマホで丸まった背・スクリーンの光が顔に張り付いている・人より画面を見るときの目の方が速い・声は小さい）。草稿が与える具体の外見＝**肩まで伸びた髪・細い首**（第3話）。ここがニジと共有する輪郭であり、この設定画が固定するのは「ニジが写される側」の実物——**輪郭は定義され、影を落とす、実体の少女**。

③翻訳＝**孤独も中毒も書かない**。身体の印だけを注記として引き出す——丸まった背、画面の光を帯びた顔、撫でる親指。名前「真白＝白＝空白・未完成」は、髪の白ではなく**色彩を足さない無地の静けさ**として滲ませる（白い制服の襟・淡い髪色ではなく、装飾のなさとして）。ニジとの「自然な差」はこちら側では**実体の質感**——影の有無を注記で明示し、シートの白地はフォーマットどおり影を落とさない。

## フォーマット（Format）

白地・多面図4面（正面／斜め／側面／背面）を**同一の身長線と目線**に載せる。ニュートラルな A ポーズ、腕はシルエットから離す。下段に表情5面——合わせる笑顔（顔の筋肉が勝手にそうなる）／画面を見る目／「どうせ」で引っ込む静けさ／小さな声で言う／初めて送る瞬間（第12話）。右に拡大図——肩までの髪と細い首（**「ニジと同じ」**と注記）、丸まった背、画面を撫でる親指、そして「実体——影を落とす。ニジと違い影が無い」の注記。引き出し線で注記し、雰囲気でなく情報として読ませる。

## 様式（Style）

セルシェード＝平坦な彩色面・閉じた線・2段の硬い影。設定画の白地と衝突する部分は format が勝つ（接地影・背景は描かない）。真白の「無地さ」は cel-shade の「情報が雰囲気に勝つ」と重なる——感情を線や塗りで足さず、注記だけで示す。

## 合成プロンプト（Merged）
