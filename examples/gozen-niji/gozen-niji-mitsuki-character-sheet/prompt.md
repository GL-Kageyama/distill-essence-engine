# 午前二時の幽霊 → キャラクター設定画（美月）

- style: セルシェード（cel-shade・検証済み）

## 内容（Content）

②選択＝**「真白が合わせている、明るい側」を仕様として書く**。美月＝親友（series-bible「真白が言えなかった言葉の宛先」）。真白が「無地・抑える・静けさ」なら、美月は「明るい・直接的・身体的に軽い」（series-constants）。草稿が与える具体＝**笑うと目が細くなり、口元がほんの少し曲がる**（第2話）、**首をかしげる**（真白の違和感を察する）。この設定画が固定するのは「表情が動く側」——真白の静けさとの対。

③翻訳＝**「明るさ」を「華やかさ・派手さ」にしない**。低彩度の世界観のなかで、美月の明るさは色彩ではなく**表情と身体の軽さ**——目が細くなる笑顔、首のかしげ、開いた姿勢。真白との「自然な差」＝こちらは**動く側**（真白は「合わせて」静かに笑う）。ただしニジと違い、美月は真白の写しではない——**別人**（顔は似せない）。

## フォーマット（Format）

白地・多面図4面（正面／斜め／側面／背面）を**同一の身長線と目線**に載せる。**真白と同じ制服・同じ学年（二年）**だが、姿勢は開いていて背筋が軽い（真白の丸まった背との対）。ニュートラルな A ポーズ、腕はシルエットから離す。下段に表情5面——明るい笑顔（目が細くなる）／「なんか、雰囲気変わった？」と問う顔／本気で嬉しそうな顔（第2話）／首をかしげる（違和感）／踏み込まない顔（見抜きかけて問わない）。右に拡大図——目が細くなる笑顔と口元（**「真白と違って表情が動く」**と注記）、首のかしげ、肩より少し短めの動く髪、そして「実体——影を落とす。現実の人間で、真白の写しではない」の注記。引き出し線で注記し、雰囲気でなく情報として読ませる。

## 様式（Style）

セルシェード＝平坦な彩色面・閉じた線・2段の硬い影。設定画の白地と衝突する部分は format が勝つ（接地影・背景は描かない）。美月の「明るさ」は cel-shade の「情報が雰囲気に勝つ」と重なる——感情を線や塗りで足しすぎず、表情の動きを注記で示す。
