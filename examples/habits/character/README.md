## §5b① の「作らない」は、どこへ移ったか

方針 §5b① は、もともとこう定めていた。

> **① 二十四名の設定画を、一組にしない。**
> **一個ずつは動き、並べれば図鑑。担保は、どの癖も持ち主を持たないことだけである。**

**移った先の条件は、こうである。**

- **「一組にしない」は、解かれていない。** 二十四枚は組の宣言を持たず、互いを名指ししない。一枚ずつが独立に読める。
- **この README の一覧は、図鑑の入口である。** 一覧は必ず生まれる——**担保は、この表には無い。** 担保は二十四枚の本文の側にあり、**それは「どの一枚も、他の二十三枚を名指ししない」という一条だけである。**
- **そして、移った先の条件は、移る前より弱い。** 移る前は「どの癖も持ち主を持たない」——**癖そのものの水準で守られていた。** 移った先は「互いを名指ししない」——**書き方の水準でしか守られない。** 一枚を読めば、その一人の顔と癖が結びつく。**そこは、もう切れている。**

**この一段を、ここに書いておく。** 空にすれば、二十四枚は理由の無い図鑑になる。
