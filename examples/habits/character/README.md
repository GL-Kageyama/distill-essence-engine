## 一枚の型（十の部分）

二十八枚すべてが同じ順に並ぶ。初稿（`../_backup_20260916/habits-usui-chinatsu-character-sheet-luminous-anime/prompt.md`）から逐語で採った型である。

1. `# 『ハビッツ！！！』 {名} → キャラクター設定画（character-sheet × luminous-anime）`
2. `> ## 初稿`——初稿であること・変更の可能性・**「発明（要承認）」の表がこの一枚の足したものの全部である**こと・**朱の枠に「初稿」を画像の上にも置く**こと
3. 四行——`- 入力:` / `- format:` / `- style:` / `- lang: ja`（生成プロンプトは英語）
4. `## 出典の語（この一人について・一語も変えない）`——その一人の台帳からの逐語。**版を付ける**
5. `## 発明（要承認）——この一枚が足したもの`——三列 `| 項目 | 置くもの | 導き方 |`
6. `## 内容（Content）`——②選択／③翻訳／④中心…を、その一人の記名と動きから組む
7. `## フォーマット（Format）`——白地・多面図4面＋表情4面＋拡大図。**描かれる文字は三種**（ヘッダの名＝日本語／注記＝英語／「初稿」＝日本語）。**作中の名は判読不能**
8. `## 様式（Style）`——luminous-anime の生き残る部分だけ。**様式メモを必ず添える**
9. `## 合成プロンプト（Merged）`——英語。段落ごとに一行・空行のみ
10. 末尾の否定行——`Not photorealistic, no 3D render, …`

**二つの決まりを、二十八枚すべてに掛ける。**

- **様式は luminous-anime のまま。** format カードが様式軸の例に挙げるのは cel-shade／line-art／manga-ink で、**luminous-anime は名指しされていない。** 忠実性アンカー四点（層を成す空・体積光・フレアとブルーム・夕景の配色）は、**設定画ではすべて落ちる。** 落ちることを、各枚の「様式メモ」が自分で書く。
- **数値を置かない。** 身長は相対だけ。**数を置けば、それは主張ではなく測定値として読まれる。** 衣装・髪型で識別しない。

## §5b① の「作らない」は、どこへ移ったか

方針 §5b① は、もともとこう定めていた。

> **① 二十四名の設定画を、一組にしない。**
> **一個ずつは動き、並べれば図鑑。担保は、どの癖も持ち主を持たないことだけである。**

**2026-09-16、著者がこれを解いた。** 二十四名は**人のかたちの設定画**を持ち、`ledger.yaml` の二十四の `identity` もこの樹を指す。**二十四名に顔を与えることは、二十四の癖に持ち主を与えることである。** ゆえに——

**移った先の条件は、こうである。**

- **「一組にしない」は、解かれていない。** 二十四枚は組の宣言を持たず、互いを名指ししない。一枚ずつが独立に読める。
- **この README の一覧は、図鑑の入口である。** 一覧は必ず生まれる——**担保は、この表には無い。** 担保は二十四枚の本文の側にあり、**それは「どの一枚も、他の二十三枚を名指ししない」という一条だけである。**
- **そして、移った先の条件は、移る前より弱い。** 移る前は「どの癖も持ち主を持たない」——**癖そのものの水準で守られていた。** 移った先は「互いを名指ししない」——**書き方の水準でしか守られない。** 一枚を読めば、その一人の顔と癖が結びつく。**そこは、もう切れている。**

**この一段を、ここに書いておく。** 空にすれば、二十四枚は理由の無い図鑑になる。
