## 内容（Content）

**②選択＝`呼ばれる名を持つ者が、呼び返さない`。** この作品の中心語は名である——`名は呼ばれた回数でできている`。**碓氷千夏は、その中心において「呼ばれる」側の人間である。** 彼女の名は正しく呼ばれ、彼女はそれに正しく答える。**しかし、返さない。** 地の文に二人称が一行も無く、会話では誰かを名で呼ばずに用件から入り、欠けている人称は`あなた`である。**ゆえにシートが固定すべきは、表情の豊かさでも名の書かれた位置でもなく、呼ばれてから答えが来るまでの、その一拍である。**

**③翻訳＝記名の現場を描き、彼女の字を一つも置かない。** 彼女は`一日じゅう記名を扱う`——出席簿、欠席連絡、転入出、アレルギー表、落とし物、名札の予備、給食エプロン。**その人が扱う記名のうち、この一枚に彼女の字が一つも無い。** 名札の差し込みは`前任者が書いた字`であり、転出欄の一行は`千夏の字でも前任の事務の字でもない`。**一枚の表面が、彼女の一日の仕事の形をしている——名はそこに在るが、書いた手は彼女ではない。** そして第一巻の頂点で彼女が発する唯一の問いは、**`その字、誰の字。`**——**このシートの表面は、その問いを最初から立てている。**

**④この一枚の中心＝`返事が一拍遅れる`。** 名を呼ばれ、返事が一拍遅れる。**その一拍に、この人物の全部がある。** 遅れているのは言葉ではなく、**返すことそのもの**である。この一拍は、静止画では**動作の完了直前**としてしか描けない——**四つの表情は、すべて「返す直前」である。**

**⑤年は、二箇所に残る。** **左胸の針穴が二つ**——布が覚えている年（去年まで、少し高い位置に留めていた）。**右手中指の第一関節の小さな膨らみ**——手が覚えている年（ペンの当たる場所）。**この二つは対である**——名札を留め続けた年が布に残り、名を書き続けた年が手に残る。**この人物は、自分の名前を自分で書かない。それでも、書く側の年は手に残っている。**

**⑥朝は二拍ある。** **留める前に、布の上から姓の三文字を指でなぞる**（層＝run-10）——**なぞっている最中で止める。三文字は布の下にあるので、指の下には何も見えない。** そして**留めたあと、一度だけ読み返す**（骨＝run-09）——**読むのは自分の名である。読んでも、それは自分の字ではない。** **なぞるのは手で、読むのは目である。二拍で、彼女の朝が終わる。**

**⑦半歩下がる、という姿勢の扱い。** 出典は`立つとき常に半歩下がる`と言う。**これは format の規律（中立のAポーズ）と衝突する。** format の掟は`シートは仕様として読まれるので、情報と雰囲気が衝突する場所ではすべて情報が勝つ`——**Aポーズも情報であり、半歩も情報である。** ゆえに**多面図は Aポーズのまま**（制作仕様としての姿勢は譲れない）、**半歩は、下段の四つ目の表情と、側面図の足もとの荷重として置き、引き出し線の注記で名指す。** 立ち位置を図の外へずらすのではなく、**図の内側に、下がる向きを置く。**

**⑧表情4面。** 職員室で名を呼ばれ、**返事が一拍遅れる**（第9話「呼ばない名前」）／名札を、**留める前になぞり、留めたあとに一度読み返す**（第3話「三文字をなぞる」＋層）／誰かを名で呼ばずに、**用件から話し始める**（run-06 の癖）／名の書かれた位置にもう一度立つ（第14話「空いたまま」）——**半歩下がったまま立つ**。**四つとも出典から採り、四つとも「返す直前」で止める。**

**⑨ガード。** 名札の姓は**判読できない**（印刷であることだけが情報）。**読みを振らない**——`正しく呼ばれる`という値は読みが固定された上で成立しているのであり、シートがそれを先に決めてはならない。転出欄の一行も**判読不能**である。**この一枚に、彼女の手で書かれた文字は一つも無い**——Negative に`handwriting`を、`no signature`を置く。**また run-04 / run-05 のカーディガンを Negative に置く**（`no cardigan`）——それが現れれば、棄却された版がこの一枚で復活する。恐怖もかわいいも出さない。

**記録として残す一つの緊張。** 出典のカメラ規則は`顔は、呼ばれた後にだけ置かれる`。**碓氷千夏は呼ばれる側の人間である**——ゆえに、四枚のうち**この一枚だけは、顔を四度置くことが規則に反しない。** 他の三枚が「設定画は作品ではない」ことの印として顔を置くのに対し、**この一枚は、作品の規則の内側で顔を置いている。** そしてその顔に置かれるのは、**返事の一拍である。**

## フォーマット（Format）

白地・多面図4面（正面／斜め／側面／背面）を**同一の身長線と目線**に載せる。中立のAポーズ、腕はシルエットから離し、**手は空**。下段に表情4面（上の四つ）。右に拡大図四点——**左胸の針穴（二つ）**、**右手中指の第一関節の小さな膨らみ**、**名札の差し込みと、その上で止まる指**、**出席簿の転出欄の、空いたまま一年残る一行**。隅に朱の枠で**「初稿」**。**描かれる文字は三種**——ヘッダの名（**日本語**）、引き出し線の注記（英語）、そして「初稿」（日本語）。**作中の日本語（名札の姓、転出欄の一行）は判読不能のまま**置く。

**四つの拡大図は、すべて「年」か「名」のどちらかを運んでいる**——針穴＝年（布）、中指＝年（手）、名札と指＝名、転出欄＝名。**この規則に乗らないものは拡大図にしない**——たとえば`筆箱に貼られたままのはがれかけたシール`は、出典のルックではあるが、年も名も運ばないので、この一枚では拡大図にしない（出典の語には残す）。

## 様式（Style）

光の写実アニメの**生き残る部分だけ**を使う。**清潔なアニメ線画**と**配色の規律**——蛍光灯の白、深いシアンに寄る影、そして**一箇所だけ最も強いハイライトを受ける点。**

> **様式メモ（この様式が設定画で失うもの）。** format カードが「様式軸を埋められる」と例に挙げるのは cel-shade／line-art／manga-ink で、**luminous-anime は名指しされていない。** 理由は明らかである——**この様式の主役は光であり、設定画の主役は人物である。** ゆえに四つの忠実性アンカー（層を成す空・体積光・フレアとブルーム・夕景の配色）は、**この一枚ではすべて落ちる。** 落とさなければならない——白地に空を置けば、それは format の avoid「人物の背後の情景」であり、**雰囲気が情報に勝つ。** 残るのは線と配色の規律だけで、それで足りる。**朱の「初稿」枠だけが、この作品の朱であり、同時にこの様式の「最も強いハイライトを受ける一点」である。**
> **この一枚には、様式が与えるはずの「最も明るい一点」が人物の上に一つも無い。** 出典は彼女を`会計年度任用職員`と書き、`年収は三百万に届かない`と書く——**最も平凡な光で、最も長く書かれた人物。それが彼女の仕様である。**
