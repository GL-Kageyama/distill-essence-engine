## 内容（Content）

**②選択＝書いた回数が、ゼロの位置。** この作品の中心語は名である——問いは`呼ばれた名は、誰のものか。`。**山田健太は、その中心で「一度も書かれていない」側に立つ。** 記名は`名のない鍵の札`——**鍵を部屋に結びつける紙**であり、**`札に書かれるのは、部屋の名である。鍵の持ち主の名は、どこにも書かれない。`** そして彼自身の名も、`彼の名は、記名の欄に無い`。癖は`内見の鍵の束に、誰のものか分からない鍵が一本ある。`——**名が書かれないまま、五年間、束の中にある。** ゆえにシートが固定すべきは、鍵の数でも鍵束の重さでもなく、**抜かれない一本の、擦れていない穴**である。

**③翻訳＝鍵を部屋に結びつける紙を描き、そこに名を一つも書かない。** 札には**名が書かれていない**——`誰のものか分からない鍵`の持ち主の名も、**彼自身の名も**。部屋の名は**判読不能**である。作中の日本語は判読不能のまま置き、**「札に名が無い」ことは、引き出し線の注記で名指す。**

**④この一枚の中心＝`持ち主不明の一本で止まる`。** 鍵束を持った手が、一本を残したまま止まる。**止まっているのは歩みではなく、外すことである。** この一拍は、静止画では**動作の完了直前**としてしか描けない——**四つの表情は、すべて「束ね終える直前」である。**

**⑤年は、二箇所に残る。** **鍵が現れた年**——`五年前からある`。**妻がその音を出した最後の年**——`最後に呼んだのは、五年前の引っ越しの日である`。**`出典は、この二つが同じ日だとは書かない。この台帳も書かない。`** ゆえに**この一枚も書かない**——**同じ数が二つ、別の場所に置かれ、その二つを結ぶ線は、どこにも引かれない。**

**⑥拡大図四点は、「名」か「年」のどちらかを運んでいる**——鍵の札＝名（名が書かれない紙）、持ち主不明の一本＝名（名が書かれないまま、束の中にある）、机の上で抜かれては戻される鍵＝年、抜かれない一本の擦れていない穴＝年（その一本にだけ、年が残らない）。**この規則に乗らないものは拡大図にしない。**

**⑦この一枚は、`誰も見ていない。`動作に、四度、顔を置く。** format の掟は表情4面を要求する——**しかし出典は`その動作を目に入れている者——誰もいない。`と書く。** ゆえに**四つの顔は、誰にも向けられていない**——**視線を図の外へ出さない。** 見られている図ではなく、**見ていない図として置く。**

**⑧表情4面。** `鍵束を机に置き、`——まだ開いていない／`一本ずつ抜いては戻し、`——戻したところで止まる／`鍵束を机から内見の扉へ、`彼の手で運ぶ——**`持ち主不明の一本で止まる`**／`内見の客。` `鍵の数。`——**数の合わないところで止まる。** **四つとも出典から採り、四つとも「束ね終える直前」で止める。**

**⑨ガード。** 札には**名が書かれていない**——Negative に`no name written on the key tag`を置く。部屋の名は**判読不能**。**ヘッダの名に読みを振らない**（出典に読みが無い）。**`内見の客`は、この一枚では描かない**——白地に人物を増やせば、`誰も見ていない。`という規律が崩れる。**`誰のものか分からない鍵を、五年前から残す。`——この一本を、この一枚でも説明しない**（`この一本を、本文で説明しない。`）。恐怖もかわいいも出さない。

## フォーマット（Format）

白地・多面図4面（正面／斜め／側面／背面）を**同一の身長線と目線**に載せる。中立のAポーズ、腕はシルエットから離し、**手は空**。下段に表情4面（上の四つ）。右に拡大図四点——**名のない鍵の札**、**持ち主不明の一本**、**机の上で抜かれては戻される鍵**、**抜かれない一本の、擦れていない穴**。隅に朱の枠で**「改訂稿3」**。**描かれる文字は三種、すべて日本語である**——ヘッダの名、引き出し線の注記（**活字で、判読できる**）、そして「改訂稿3」の枠。**作中の日本語（札に書かれた部屋の名）は判読不能のまま**置く。

**身長は相対のみ。数値は置かない。** 出典に身長が無く、**この一枚は順位を持たない**——比較の相手を置かない。

**四つの拡大図は、すべて「名」か「年」のどちらかを運んでいる**——鍵の札＝名（名が書かれない紙）、持ち主不明の一本＝名（名の書かれない鍵）、抜かれては戻される鍵＝年（同じ位置で、五年前から）、擦れていない穴＝年（その一本にだけ、年が残らない）。**この規則に乗らないものは拡大図にしない**——たとえば`管理物件210戸`という数は、この一枚では引き出し線の注記に置き、拡大図にはしない。

## 様式（Style）

光の写実アニメの**生き残る部分だけ**を使う。**清潔なアニメ線画**と**配色の規律**——蛍光灯の白、深いシアンに寄る影、そして**一箇所だけ最も強いハイライトを受ける点。**

> **様式メモ（この様式が設定画で失うもの）。** format カードが「様式軸を埋められる」と例に挙げるのは cel-shade／line-art／manga-ink で、**luminous-anime は名指しされていない。** 理由は明らかである——**この様式の主役は光であり、設定画の主役は人物である。** ゆえに四つの忠実性アンカー（層を成す空・体積光・フレアとブルーム・夕景の配色）は、**この一枚ではすべて落ちる。** 落とさなければならない——白地に空を置けば、それは format の avoid「人物の背後の情景」であり、**雰囲気が情報に勝つ。** 残るのは線と配色の規律だけで、それで足りる。**朱の「改訂稿3」枠だけが、この作品の朱であり、同時にこの様式の「最も強いハイライトを受ける一点」である。**
> **この一枚には、様式が与えるはずの「最も明るい一点」が人物の上に一つも無い。** 出典は彼を`不動産仲介`と書き、`その動作を目に入れている者——誰もいない。`と書く——**誰も見ていない動作をする男の一枚に、いちばん強い光は、朱の箱の上にしかない。**
