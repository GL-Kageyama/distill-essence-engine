## 内容（Content）

**②選択＝書く者と呼ぶ者が、同じ家にいる位置。** この作品の中心語は名である——問いは`呼ばれた名は、誰のものか。`。**木村智美は、その中心で「書かれる」側と「呼ばれない」側のあいだに立つ。** 職場では`「木村先生」。`、児童には`「先生」。`、そして**`職員室で下の名前を呼ぶ者はいない`。** 家では**`夫が「智美」と書く。口では「おい」しか言わない`**——`書くことと、呼ぶことは、違う。` 記名は`宿題の名前欄`——**書く者の名を書く欄**であり、**`空欄は、埋められない。`** ゆえにシートが固定すべきは、呼ばれない名の側ではなく、**書かれて、呼ばれないまま残っている名**と、**空欄をいちばん上に置く手**である。

**③翻訳＝書く者の名を書く欄を描き、そこに彼女の字を一つも置かない。** 名前欄の空いた一枚が、束のいちばん上にある。**空欄は、埋められない**——**この一枚でも、彼女の字で埋められることは無い。** 他の児童の名前欄には名が書かれており、**それも判読不能である。** 作中の日本語は判読不能のまま置き、**「空欄のまま」であることは、引き出し線の注記で名指す。**

**④この一枚の中心＝`名のない一枚の上で止まる`。** 束を教壇の端から中央へ置き直す手が、名のない一枚の上にある。**止まっているのは手ではなく、埋めることである。** この一拍は、静止画では**動作の完了直前**としてしか描けない——**四つの表情は、すべて「載せ終える直前」である。**

**⑤年は、一箇所に残る。** **夫の字で書かれた名**——`結婚してから、夫がその音を出したことは一度もない`。**書かれて、呼ばれずに残った年が、そこにだけ残っている。** 名は三箇所にある——空欄（名が無い）、他の児童の名前欄（書かれた名）、職場の名札（姓と職名）。**この一枚では、年が一つ、名が三つ。その数を、そのまま置く。**

**⑥一拍は、一度で終わる。** `名のない一枚について、一度だけ言い合う。`——**`そして一度で終わる。`** ゆえに表情4面の四つ目は、**言い合いの途中ではなく、終わったところ**で止める——**続く二度目を、この一枚は置かない。**

**⑦拡大図四点は、「名」か「年」のどちらかを運んでいる**——空欄の一枚＝名（名が無いことが名を運ぶ）、書かれた名前欄＝名、束のいちばん上＝名、夫の字で書かれた名＝年（書かれて、呼ばれずに残った）。**この規則に乗らないものは拡大図にしない。**

**⑧空欄は、説明できない。** format の掟は白地・多面図である——**空欄を意味づける説明を地の文でしない**という規律は、**この一枚でも守る。** ゆえに空欄には、**何も書き足さない**——注記は「この欄は空である」と名指すだけであり、**なぜ空かは、この一枚も書かない。**

**⑨表情4面。** `教壇で束を揃え、`——最後の一枚の前で止まる／`名のない一枚を抜いて、`——抜き終える直前で止まる／`束のいちばん上に載せ替える`——**`名のない一枚の上で止まる`**／`日直の児童`と`名のない一枚について、一度だけ言い合う`——**一度で終わるところで止まる。** **四つとも出典から採り、四つとも「載せ終える直前」で止める。**

**⑩ガード。** 空欄は**空のまま**である——Negative に`no writing in the empty name column`を、`no filling in of the blank`を、`no red marking on the nameless sheet`を、`no correction fluid`を置く。他の児童の名前欄は**判読不能**。**ヘッダの名に読みを振らない**（出典に読みが無い）。**日直の児童は、この一枚では描かない**——白地に人物を増やせば、`児童は、何も言わない。`という規律が崩れる。恐怖もかわいいも出さない。

## フォーマット（Format）

白地・多面図4面（正面／斜め／側面／背面）を**同一の身長線と目線**に載せる。中立のAポーズ、腕はシルエットから離し、**手は空**。下段に表情4面（上の四つ）。右に拡大図四点——**名前欄の空いた一枚**、**名の書かれた名前欄（判読不能）**、**束のいちばん上に載せ替えられた、名のない一枚**、**夫の字で書かれた名（一枚の紙の上に）**。隅に朱の枠で**「初稿」**。**描かれる文字は三種**——ヘッダの名（**日本語**）、引き出し線の注記（英語）、そして「初稿」（日本語）。**作中の日本語（名前欄の名）は判読不能のまま**置く。

**身長は相対のみ。数値は置かない。** 出典に身長が無く、**この一枚は順位を持たない**——比較の相手を置かない。

**四つの拡大図は、すべて「名」か「年」のどちらかを運んでいる**——空欄＝名（名が無い）、書かれた欄＝名、束のいちばん上＝名（空欄が置かれる位置）、夫の字＝年（書かれて、呼ばれずに残った）。**この規則に乗らないものは拡大図にしない**——たとえば`児童410名`という数は、この一枚では引き出し線の注記に置き、拡大図にはしない。

## 様式（Style）

光の写実アニメの**生き残る部分だけ**を使う。**清潔なアニメ線画**と**配色の規律**——蛍光灯の白、深いシアンに寄る影、そして**一箇所だけ最も強いハイライトを受ける点。**

> **様式メモ（この様式が設定画で失うもの）。** format カードが「様式軸を埋められる」と例に挙げるのは cel-shade／line-art／manga-ink で、**luminous-anime は名指しされていない。** 理由は明らかである——**この様式の主役は光であり、設定画の主役は人物である。** ゆえに四つの忠実性アンカー（層を成す空・体積光・フレアとブルーム・夕景の配色）は、**この一枚ではすべて落ちる。** 落とさなければならない——白地に空を置けば、それは format の avoid「人物の背後の情景」であり、**雰囲気が情報に勝つ。** 残るのは線と配色の規律だけで、それで足りる。**朱の「初稿」枠だけが、この作品の朱であり、同時にこの様式の「最も強いハイライトを受ける一点」である。**
> **この一枚には、様式が与えるはずの「最も明るい一点」が人物の上に一つも無い。** 出典は彼女を`小学校教諭`と書き、`彼女の名は、書かれて残り、呼ばれずに残る。`と書く——**書かれる側にいて、いちばん多く名を書かれる立場の人が、自分では一度も書かない。それが彼女の仕様である。**
