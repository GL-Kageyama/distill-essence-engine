# 入力：3つの創作パターンの比較（人間だけ / 人間＋AI / 人間＋AI＋5つの道具）

> 対象: 同じ書き手の創作ワークフローを、支援の有無で3段階に比較する。5つの道具は「AI評価者たちによる『知恵の評議会』」配下の5リポジトリ。

## 比較する3パターン

1. **人間だけ** —— AIなし。書く・直す・見分ける・別の形に変える、すべてをひとりの人間が担う。蝋燭ひとつ。
2. **人間＋AI** —— 生成AIが加わる。生成は速いが、どの原稿も「平均的」。見分ける仕組みが無い＝書き手がひとりで判断するしかない。
3. **人間＋AI＋5つの道具** —— 生成AIに加えて、5つの道具が評価・昇華・声・蒸留を担う。人間は作者として全体を差配する。

## 5つの道具（本質）

- **soul-voice-teller**（書く側）—— 人間が作者・AIは起草装置・personaは作者の魂の鏡。「書くことは魂を運ぶこと」。
- **elevate-draft-engine**（磨く側）—— 8視点が独立に分岐し、衝突・止揚（否定・保存・高次化）して一段高い答えへ。
- **wisdom-council-layer**（見抜く側・価値）—— 多声評価で価値を見抜く。相違は平均せずそのまま保存。
- **novel-council-layer**（見抜く側・小説）—— 物語の濁流から読む価値のある物語を見抜く。「物語は時間の中で読まれる」。
- **distill-essence-engine**（蒸留する側）—— あらゆる入力を一枚の画像プロンプトへ蒸留する。

## 前例（同一世界の設定）

`council-workshop-illustration/` で定めた等角ジオラマの世界（30度グリッド・パステル面・琥珀のアクセント・夜のたそがれ）を踏襲する。鏡台＝soul-voice、炉＝elevate、円卓＝wisdom×novel、蒸留器＝distill の配置をパネル3で再利用する。
