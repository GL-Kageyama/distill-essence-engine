# 入力——バイブコーディングで「何を作れるか」を、棚一枚に畳む

> 種別＝**続編**。前の一枚（[../prompt.md](../prompt.md)）の**同じ世界・同じ二人**。前の一枚は「教えている瞬間」、この一枚は「作ったもの／作れるもの」。
> 作るのは、**バイブコーディングで何が作れるか**を、横長16:9の概念図一枚に絞ったもの。**文字は置かない**。**画像は生成しない**（`CLAUDE.md` §Verification。引くのは著者）。

## 仕様

| 項目 | 内容 |
|---|---|
| format | 概念図（conceptual-illustration）——レジストリ済み。全概念×畳み込み・一枚・横長16:9・文字なし |
| style | クリーンラインラボ（clean-line-lab）——前の一枚と同じ |
| 用途 | 伝達。前の一枚の「講義」に対して、こちらは「成果の範囲」。**何を作れるかを、カタログでなく、棚の上の具体的な物で示す** |
| 言語 | ja（三カラム・説明）。合成プロンプトのみ英語 |

## ① 何が来たか（理解）

- **問いは「何を作っているか」「何を作ることが可能か」。** これは**範囲**の問いである——一つの作品ではなく、**どこまで行けるか**。
- **だが「何でも作れる」は、何も言っていない。** 汎用の「アプリ」アイコンを並べれば、この一枚は**カタログ**になり、誰のものでもなくなる。**バイブコーディングの本当の射程は、小さく、具体的で、自分の生活・仕事の困りごとに効くもの**である。
- **ゆえに、この一枚は「棚」にする。** 棚の上に、**その人が実際に作った小さな道具**が並ぶ。**仕事（シフト交代）／家（植物の水やり）／台所（レシピの原価）／修理（自転車の整備記録）**——四つの領域、四つの具体的な物。**五つ目は、まだ空のスロット**。**空きが「可能」である。**
- **コーディネーターは、作らない。** 講師は棚の下に立ち、**手を空けて**、受講者を見ている。**棚に手を伸ばすのは受講者**である。前の一枚の「講師の手はキーボードにない」が、この一枚では「講師の手は棚にない」になる。

## ② 語る一点（選定）

**受講者の手が、五つ目の空のスロットに、まだ何も映っていない小さな画面を置こうとしている。**

**なぜこの一点か。** 「何が作れるか」は、**並んだ完成品**だけでは閉じてしまう——それは「作ったものの一覧」であり、**可能**ではない。**空のスロット**が、この一枚の問いに答える。**棚の左から右へ、作ったものが並び、右端で、まだ何もない一枚が置かれる**——**範囲は、塗り終えた部分ではなく、空いている部分で示す。**

**支える四点**（棚の左から右へ、作った順）：

1. **シフト交代**——小さなクリップボードの格子と、その横の電話。同じ格子が、一つだけ動いている。
2. **植物の水やり**——テラコッタの鉢と、棒に留めた電話。画面には点のカレンダー。
3. **レシピの原価**——使い込んだレシピカードと、小さなタブレット。三本の棒と、合計の棒。
4. **自転車の整備記録**——自転車のベルと、ぶら下がった札、小さな表示器。三つのチェック欄。

**五つ目**——**まだ何も映っていない小さな画面**。**金のカーソルが一本だけ**。**受講者の手が、それを棚の空きに置こうとしている。**

**潰す誤読**：

| 誤読 | なぜ嘘か | だから描かないもの |
|---|---|---|
| (a) アプリのカタログ | アイコンを並べれば、この一枚はストアの画になる。**棚の上の物は、アプリではなく、アプリが仕える生活の道具**である | アプリアイコン・スマホの格子・ストア画面・均等に並んだ製品 |
| (b) 何でも作れる | 銀河・爆発・浮遊する画面・無限記号は、**「何でも」という何も言っていない約束**である | 銀河・宇宙・爆発・浮遊UI・無限記号・魔法の光 |
| (c) 完成品の自慢 | 棚が**整った展示**になれば、それは製品ショーケースであり、**使い込まれた仕事場**ではない | 均等な間隔・値札・ラベル・ガラスケース・観賞用の照明 |
| (d) コーディネーターの手柄 | 棚に手を伸ばすのが講師なら、**作ったのは講師**になる。**伸ばすのは受講者**である | 講師の手が棚に触れる・講師が画面を操作する |
| (e) コードの画 | バイブコーディングはコードを見せない。**画面は、動く小さな道具**である | コード・ターミナル・構文・黒板 |
| (f) 文字の説明 | 概念図は**文字を担い手にしない**。**物と配置が概念を担う** | 活字・ラベル・値札・矢印・吹き出し・読めるUI |

**削ったもの**：六つ目以上——**四つ＋空きで足りる**／「何でも作れる」の記号——**空きがそれを言う**／講師の説明——**手と視線で足りる**／アプリの名前・機能名——**文字を持てない**／コード——**この商品の否定**／観賞用の棚——**使い込まれた棚**。

## ③ 翻訳（抽象 → 視覚）

| 抽象 | 具象へ |
|---|---|
| **何を作れるか** | **棚の左から右へ、四つの具体的な道具。** 仕事・家・台所・修理。**五つ目は空き** |
| **可能** | **まだ何も映っていない画面と、金のカーソル一本。** 受講者の手が、それを空きに置く |
| **小さく、具体的** | **使い込まれた物**——縁の欠けた鉢、コーヒーの輪染みの残るレシピカード、曲がった札、角の擦り切れたクリップボード |
| **生活・仕事に効く** | 四つの領域は**同じ人物の生活の四つの面**。**一つは仕事、一つは家、一つは台所、一つは修理** |
| **コーディネーターは作らない** | **講師の手は棚にない。** マグを持ち、受講者を見る。**棚に伸びる手は受講者の片手だけ** |
| **教えたのは講師、作ったのは受講者** | 講師は**左端**、受講者は**右端**。棚は**二人のあいだ**を左から右へ走る。**講師は始まりに立ち、受講者は続きに立つ** |

## ④ 同一の世界（人物と場）

**前の一枚の続き。同じ部屋、同じ光、同じ二人。**

- **講師（左、立つ）**：30代半ば。短い黒髪、細い丸眼鏡、淡い青のシャツ、くすんだセージのカーディガン、裏返した白いバッジ。**片手にマグ、もう片方の手は体側。** **棚に触れない。**
- **受講者（右、低い丸スツールの上に立つ）**：20代前半。短い黒髪のボブ、淡い黄のニット、灰色のズボン。**片手を棚の縁に添え、もう片方の手で、空の画面を空きに置こうとしている。** 背伸びをして、集中している。
- **場**：白に近い壁、淡い木の棚（二つの簡単な金具）、下に淡い木の長机と丸いスツール。机の上に**閉じたノートPC**とマグ。**他は置かない。**
- **光**：左上の窓から、平坦で柔らかい。**上の壁に淡い斜光の帯を一本。** 影は最小限。
- **色**：生成り紙、ミント、淡い青、淡い黄、くすんだセージ、淡いくすみのテラコッタ。**飽和色は、空の画面の金のカーソル一本だけ。**

## ⑤ 構成（Format）

横長16:9。**棚は画面の上三分の一から中段を、左端から右端へ走る。** 左から、シフト→植物→レシピ→修理→**空き**。**空きは右端、受講者の手の届く位置**。**講師は左下、受講者は右下**、二人とも小さく。**棚が主役、二人は従**。**視線の三角形**：講師→受講者の顔→空の画面の金→講師。**焦点は空の画面と受講者の手**。**左から右へ読む**——作った順、そして、まだ作っていないものへ。**余白は棚の上の壁**。文字なし。

## ⑥ 様式（Style）

クリーンラインラボ（前の一枚と同じ）：細いインク線、淡いパステル、影最小、奥行きは線の重みと重なり、落ち影なし、金の一点。**概念図としての文法**：**一つの中心の象徴（棚）**、**対比（完成 vs 空き）**、**左から右へのナラティブ**、**領域ごとの淡い色**（仕事＝淡い青、家＝淡い緑、台所＝淡い黄、修理＝淡いくすみ青）。**文字は担い手にしない。** **様式カードのラベル／キャプション節は落とす。** これは意図的な逸脱である。

## ⑦ 禁止（Negative）

- **文字を描かない**——活字・ラベル・値札・字幕・吹き出し・矢印・画面のUIコピー・数字・ロゴ・透かし・署名・もじばけ。**画面は形だけ**、バッジは空白。
- **アプリのカタログにしない**——アプリアイコン・スマホの格子・ストア画面・均等に並んだ製品・ガラスケース・観賞用の照明。
- **「何でも作れる」の記号を置かない**——銀河・宇宙・爆発・浮遊UI・無限記号・魔法の光。
- **コードを描かない**——コード・構文・ターミナル・黒板・エラーメッセージ・緑の文字。
- **AIを擬人化しない**——ロボット・アンドロイド・光る脳・回路基板・ホログラム・デジタル雨・ネオン。
- **講師に作らせない**——講師の手が棚・画面・受講者に触れる。**棚に伸びる手は受講者の片手だけ。**
- **完成品を自慢しない**——均等な間隔・値札・新品同様の道具・スポットライト。
- **教室・商談・オフィスのスチルにしない**——黒板・教壇・制服・机の列／プレゼン画面・名刺・握手・スーツ／観葉植物・余分なカップ・本・額縁・ケーブル・ごちゃつき。
- **写実・3D・グラデ・光沢を避ける**——写真・3Dレンダー・デジタルグラデーション・油絵の質感・重い陰影・ウェブトゥーンの艶・エアブラシ・絵画的な筆致・粒子・紙の質感。
- **実在の人物・組織の似姿にしない**——実在の顔・ロゴ・組織名・肩書き。

## ⑧ 忠実性

- 入力の問いを超えない。**四つの領域は提案**であり、実際の受講者の作品に差し替えられる。
- **「何でも作れる」と言わない。** **空きは一つ。** 範囲は、**具体的な四つ＋一つの空き**で示す。
- **講師に作らせない。** **受講者にコードを読ませない。**
- **AIを擬人化しない。** ロボット・脳・回路・魔法を置かない。
- **完成品を自慢しない。** 使い込まれた物、静かな棚。**感情を煽らない。**
- **実在の人物・組織の似姿にしない。** バッジは空白、ロゴなし。

## 出典の届く範囲

- 「何を作っているか、何を作ることが可能なのか」＝ユーザーの一文。**範囲の問い**として読んだ。
- **バイブコーディングの一般的な用法**（自然言語でAIに指示し、動くソフトウェアを作る）から、**小さな生活・仕事の道具**を四つ選んだ。**四つの領域は、この一枚が決めたもの**（入力に無い）。→ 未判定。

## 未判定

1. **四つの領域は提案**。実際の生徒の作品（例：予約、家計、在庫、学習、イベント受付）に差し替え可能。**差し替えるほど、この一枚は「その人」の話になる。**
2. **棚の形式**：壁の棚／ペグボード／作業台。今は**壁の棚**（前の一枚の白い壁をそのまま使う）。
3. **人数**：二人／受講者だけ／講師だけ。今は**二人**（前の一枚との連続性のため）。受講者だけなら、棚と空きがより強く出る。
4. **文字を置くか**：**置かない**。各道具の名を出したいなら、別フォーマット（インフォグラフィック）でラベルにする。
5. **比率**：16:9。**縦長なら、棚を縦に**——上から下へ、作った順。
6. **画像は未生成**。テキスト検証のみ（`CLAUDE.md` §Verification）。引くのは著者。
