# 入力：重度の引きこもりが、深い自己救済により立ち直っていくアニメ物語（構想）

> 種別＝物語の構想（アニメ）。完成した本文ではなく、主題と弧の指定。

## 主題

重度の引きこもりが、深い自己救済によって立ち直っていく。他者に救われるのでも、奇跡が起きるのでもない——葛藤と苦しみの果てに、**自分自身にとっての真理**に辿り着き、そこから立ち直る。

## 弧

閉塞 → 深い葛藤・苦しみ → 自分にとっての真理への到達 → 立ち直り

## 二つの要求（この一枚が同時に満たすべきもの）

1. **深い葛藤から、自分自身にとっての真理に辿り着くこと**を、イラストで表現する
2. **引きこもりという、生々しい現実**を、イラストで表現する

## 語られていないが、この作品のもの

- 救済は外から来ない。**内側で起きる**——だから外から見える事件がない
- 「真理」は発見ではなく**読み替え**でありうる：この部屋は自分を殺す場所だったのか、それとも生かし続けた場所だったのか
- 時間は事件ではなく**堆積**として部屋にある
- 回復の最初の徴は、感情ではなく**身体**に現れる（立つ、座る、手を置く）

## ⑧ 忠実性のための禁止

- 夜明けの光・開いた窓・涙・外へ踏み出す足——これらは**この物語のものではない**（借り物の記号）
- 治癒を他者・偶然・光の到来に帰さない
- 部屋の汚れを美装しない。同時に、汚れを「悲惨」の記号として消費しない
