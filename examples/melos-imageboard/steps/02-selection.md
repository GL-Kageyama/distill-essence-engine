# ②選定（Select）— 語る一点

**選んだ一点**：泉の水を飲む場面。路傍、斜陽、岩の裂け目から湧く清水、疲労困憊で崩れたメロス。

**なぜこの一点か**：
- 絶望 → 希望の**転換点**（転換点 3）。全文の「走る」が可能になる起点。
- 主題「信実」を「小さく澄んだ水」という**間接の形**で凝縮できる（水＝信頼の源泉、直接「信じる」と言わない）。

**回避した凡庸**：
| 凡庸（避けた） | 理由 |
|---|---|
| クライマックス（友との抱擁・王の赦し） | 「この話を絵に」が真っ先に返す場面 |
| 題名そのもの（走る男） | 字義通りすぎる |
| 説明の場面（王との対話） | リテラルに説明するだけ |
| 全要素の要約 | 一点で全体を暗示できなくなる |
