# 入力：主題歌「ヌルヌル音頭」を、夕暮れの一瞬に畳む

> 種別＝**歌**（主題歌一式）。散文の物語ではなく、**外部の概念**——落合陽一プロデュース『null²（ヌルヌル）』（2025年大阪・関西万博 シグネチャーパビリオン、テーマ「いのちを磨く」）——を、**音頭の節調に畳んだ一曲**である。
> 入力ファイル＝`soul-voice-teller/examples/nullnull-ondo/届ける/theme-song.md`
> 作るのは、この歌が歌う**一つの瞬間**を、横長16:9の水彩一枚に絞ったもの。

## ① 何が来たか（理解）

- **種別**：歌（主題歌一式）。歌詞・曲調指定・ボーカル指定・楽曲説明・挿入位置から成る。**この一枚の入力は歌であって、小説ではない。**
- **歌の形式**：音頭（盆踊り音頭）。七五調・囃子詞の掛け合い・太鼓と笛・輪踊り。**大阪万博'70の三波春夫**の系譜を名乗る。
- **歌が畳んだ概念**：落合陽一『null²』——公式テーマ「いのちを磨く」／般若心経の「空即是色・色即是空」を**「ヌル即是色 色即是ヌル」**と置き換える／伸縮する**鏡膜**の外観（建物が呼吸するように変形する）／天井と床が鏡面LEDの**無限反射空間**（「ヌルの森」）／**MirroredBody®**（3Dスキャン＋声の複製で作る分身。問いかけると即座に答える）／**荘子の胡蝶の夢**／1トン超のロボットアームが鏡の立方体を振り回す**御神体**。
- **核心の問い**：**鏡に映った自分の分身と話すとき、話しているのは誰か。**
- **感情の頂点**：ヌルの森で、自分の分身が「なにか聞いて」と言い、**自分の声で自分が答える一瞬**。
- **歌が自分で宣言している場面**（theme-song.md §情景）：**夕暮れの夢洲、ヌルの館の前。太鼓が鳴り、輪になって踊っている。輪の真ん中で、四方の鏡がどこまでも続き、もう一人の自分が手を振っている。**
- **歌わないと決めたもの**（開示度の読み替え）：概念（空・ヌル・鏡・分身）は歌ってよい。**パビリオンの末路という「出来事」は歌わない**——閉幕日の葬送セレモニー・解体・クラウドファンディングによる引っ越し・横浜への転生。**これらは概念ではなく後日談である。この一枚も描かない。**

## ② 語る一点（選定）

**輪の掛け合いと、分身の応答は、同じ一つの身振りである。**

語る一点＝**夕暮れの輪。囃子に返して、一人が片手を上げた。そのすぐ隣に、同じ姿がもう一人——まだ手を上げていない。**

- 音頭の形式は**掛け合い**である。音頭取りが呼び、一同が返す。
- この歌の概念の核は**分身の応答**である。呼びかけると、自分の声で自分が返す。
- **この二つは、一つの身振りに畳める。** 呼びかけと応答が、同じ姿の二つに分かれて立っている。
- 反射のようにも見え、他人のようにも見える。**どちらが先に動いたかを、絵は決めない。** 決めないことが、核心の問い（誰が話しているのか）を名指しせずに置く。
- クライマックス（御神体が鏡を振り回す場面）でも、説明の場面（「なにか聞いて」と尋ねる場面）でもない。**踊りの最中の、日常の裂け目**である。

**削ったもの**（選定の半分は捨てること）：

- **御神体さん**（ロボットアームと鏡の立方体）——この作品で最も固有の要素だが、入れると焦点が二つになる。**外した。**
- **環**（万博の大屋根リング）——遠景の細い弧としてだけ残す。第一の焦点にはしない。
- **提灯・櫓・花火・桜・屋台**——**入力に無い。** これは汎用の「日本の祭り」への漂流を止めるための禁止である（⑧）。
- **題字**——挿絵の文法は「文字を絵に埋め込まない」。文字が無くても、この一枚は歌の顔になる。

## ③ 翻訳（抽象 → 視覚）

| 抽象（歌の語） | 具象へ |
|---|---|
| 掛け合い（音頭） | 上げた手と、上げていない手。輪になった背中（顔は描かない） |
| 分身（もう一人のわたし） | 同じ姿が二つ。ただし半拍ずれて、手が違う |
| 誰が話しているのか | **どちらが先かが決まらないこと**。表情では描かない |
| ヌル（鏡の世界／ヌルの森） | 館の鏡膜——空と輪を映して、呼吸のようにうねる面。輪がその面のなかへ続く |
| 天井も床も 光になって | 足もとの磨かれた地に伸びる、輪の写り。日が落ちるほど、光が面へ移る |
| 夢洲の浜に 環がかかって | 遠景の水面と、地平の細い弧 |
| 陽が落ちる（Outro） | 低い日。**「燃える空」ではなく、沈んでいく光**として描く——mood の自動スイッチにしない |
| いのちが すこし 磨かれて | 踊りつづけること。**結末は描かない。** 輪はほどけない |

- **鏡膜と水彩は同質である。** 鏡膜は「面が世界を写す」もの、水彩は「白い紙と薄い重ねが光を写す」もの——**様式そのものが内容を語る位置にある。** だから鏡の面は描き込まず、**wet-on-wet の滲みと、残した白**で描く。
- 波・空・浜は**余白**。人物は小さく、顔は描かない（挿絵の文法＝印象を視覚へ）。

## ⑧ 忠実性のための禁止

- **後日談を描かない**——閉幕セレモニー・解体・引っ越し・転生。**日は落ちるが、祭りは終わらない**（歌の Outro「陽が落ちる。輪はほどけず、踊りは続いている」）。この一枚に終わりを描かないことが、歌の抑制と同じ規律である。
- **主題を名指ししない**——「AI」「人間と機械」「境界」の文字も、それを示す記号（ロボット、回路、歯車）も描かない。テーマは、二人の位置と手にだけ置く。
- **入力に無い祭りの記号を持ち込まない**——提灯・櫓・花火・桜・屋台。
- **文字を描かない**——題字も、看板も、のぼりも。
- **パビリオンを SF のメカとして描かない**——館は膜であり、面である。機械の箱ではない。
