# 使い方

## クイックウォークスルー

1. **インストール** — `./install.sh`（グローバル）または `./install.sh --local`（このプロジェクト）。
2. **選択** — VSCode で入力テキストを選択（選択が内容スロットになる）。
3. **指定** — 自然言語で欲しいものを言う（「イメージボード化して、木版で」）。

エンジンは英語のプロンプトを 3 欄（Content／Format／Style）＋合成プロンプトで返す。そのまま Stable Diffusion / Midjourney など に貼れる——フォーマットが時間軸を持つ場合は、Wan などに貼れる埋められた仕様書を返す。

同じ内容を別の出力にしたいときは、軸を 1 本だけ差し替える：「同じ内容で、サムネイルに」（フォーマット）／「同じ内容で、ピクセルアートで」（様式）。

入力→出力の実例は [`../../examples/`](../../examples/)。

## 入力

| 引数 | 意味 |
|---|---|
| `content` | 変換する内容（省略時は VSCode 選択） |
| `url` | URL（YouTube→文字起こし、GitHub→README、ホームページ→本文）。`scripts/fetch.py` で取得 |
| `format` | 何を作るか（フォーマット名 または 自然言語） |
| `style` | どんな様式で（様式名 または 自然言語） |
| `reference` | 参考画像パス または 参考にする例（イメージ参照） |
| `characters` | 登場人物の固定（名前＝外見・服装・体格。キャラ参照） |
| `trace` | true で各工程のトレースも出力（検証用） |
| `lang` | en / ja / zh — 説明・トレースの言語（生成されるプロンプト自体は常に英語） |

## 名前付きカードの再利用

`format: 漫画`／`style: 木版` と**名前で指定**すれば、登録済みのカード定義を展開して再利用。一覧は `references/registry.md`。名前がカードに一致しなければ、その場で生成し、検証で「使える」なら登録を提案する。

## 出力

英語のプロンプトを 3 欄（内容／フォーマット／様式）＋末尾の合成プロンプトで出力。SD/MJ などにそのまま渡せる（フォーマットが時間軸を持つ場合は、合成プロンプトの代わりに埋められた仕様書）。

## 検証

画像生成を挟まないテキスト検証。生成プロンプトを既存評価者（admiration／hook／anti-generic-filter／emotional-power／aesthetic-critic）で判定する。
