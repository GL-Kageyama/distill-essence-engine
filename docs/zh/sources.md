# 网络调研的来源

> 为蒸馏样式卡·格式卡的语汇而参照的外部来源。卡不是「原始提示词的复制」，而是把这些语汇蒸馏成引擎独有的形式（媒材×谱系×时代／语汇／负向对）。

## OSS（下载后吸收其结构与模板）

- [VigoZhao/AI-Visual-Prompt-Cookbook](https://github.com/VigoZhao/AI-Visual-Prompt-Cookbook)（MIT）— style.json v2.1 架构（环境变量·保真锚·视觉分解·do/avoid·prompt_template·negative·示例）。`references/card-schema.md` 的基础。
- [freestylefly/awesome-gpt-image-2](https://github.com/freestylefly/awesome-gpt-image-2)（MIT）— 生成工作流（类别匹配·6 区块·多方案呈现）与 Prompt as Code 的思路。反映在 SKILL.md 的步骤 2。
