# Neubrutalism（neubrutalism）

- **Medium**: Digital ／ **Lineage**: Web brutalism revival ／ **Era**: 2020s
- **Summary**: Thick black outlines, hard offset shadows with no blur, clashing saturated color, raw typography — a web style that refuses to be polite.

## Environment variables
`SUBJECT`＝the content, `ACCENT`＝the clash of saturated colors, `TYPE`＝the raw type line

## Fidelity anchors
- **Thick black outlines** on every shape
- **Hard offset shadows** — no blur, no softness (a solid shadow block offset down-right)
- **Clashing saturated colors** (bold primaries, cream/off-white ground)
- **Raw typography** — bold, slightly irregular, one loud headline
- Flat, ungraded color; no gradients, no gloss, no gradients of any kind

## Visual breakdown
- **Composition**: shapes that sit and cast hard shadows, asymmetric, playful
- **Typography**: one bold raw typeface, a loud headline, no subtlety
- **Color**: cream ground, black outlines, clashing saturated accents
- **Texture / lighting**: flat, hard shadow blocks, no gradient, no gloss

## do
- Outline every shape thickly in black
- Cast a hard offset shadow (no blur) under each shape
- Let saturated colors clash against a cream ground

## avoid
- Soft or blurred shadows, gradients, gloss, thin outlines, muted pastel palettes, polite restraint

## Negative
`not soft shadows, no gradient, no gloss, no thin outlines, no muted or pastel palette`

## Prompt template
```text
A neubrutalist design of {SUBJECT}. Thick black outlines on every shape, hard offset
shadows with no blur (solid shadow blocks down-right), saturated colors clashing
against a cream ground, bold raw typography {TYPE} with one loud headline. Flat,
unpolished, playful — a web style that refuses to be polite.
```
