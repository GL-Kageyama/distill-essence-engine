# Picture book（picture-book）

- **Purpose**: Narration (re-experience) ／ **Granularity×time**: whole arc × unfolding ／ **Size & aspect**: spread (horizontal), multiple pages
- **Summary**: One spread = one scene; text and image separated, using the gap between pages (the absence).

## Environment variables
`SUBJECT`＝the story, `N`＝number of spreads, `TEXT`＝the text

## Composition grammar
One spread = one scene; text and image separated; a soft frame and a repeating motif; using the gap of the page turn (the absence)

## do
- One spread, one scene
- Separate text and image
- Place a repeating motif

## avoid
- Multiple scenes in one spread, overlaying text on the picture

## Prompt template
```text
A picture-book spread (one scene) from {SUBJECT}. Text and image separated, a soft frame,
a repeating motif, the page-turn gap left open.
```
