# Landing page（landing-page）

- **Purpose**: Layout (design) ／ **Granularity×time**: one page above the fold × a single point ／ **Size & aspect**: desktop 16:9 (optionally a tall scroll)
- **Summary**: The product's promise read at a glance above the fold — a headline, a sub-line, one conversion point, and a visual that supports them.

## Environment variables
`PRODUCT`＝the product, `HEADLINE`＝the headline, `SUBHEADLINE`＝the sub-line, `CTA`＝the conversion point, `VISUAL`＝the supporting hero visual

## Composition grammar
The first view has one job: make the promise readable in a glance. A headline, a sub-line, a single conversion point (button), and one supporting visual. A hierarchy that steers the eye to that one CTA; web whitespace and grid; the product's own voice. One page, one promise — not a catalogue.

## do
- Make the headline say the one promise, spelled correctly once
- Lead the eye to a single conversion point
- Keep whitespace and a clear grid

## avoid
- A catalogue of features, several competing CTAs, a cluttered hero, misspelled headline

## Prompt template
```text
A landing page of {PRODUCT}, desktop 16:9 above the fold. A large headline
"{HEADLINE}" with a sub-line "{SUBHEADLINE}", a single conversion point "{CTA}"
made prominent, and a supporting visual of {VISUAL}. A clean web grid, generous
whitespace, a hierarchy that leads the eye to the one CTA, {PRODUCT}'s own visual
voice kept consistent.
```
