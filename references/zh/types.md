# 类型（假定目的 × 格式 × 样式 × 压缩的 2 层）

> 决定转换「方法」（粒度×时间×作用）的词典。distill-essence-engine 的参考文档。SKILL.md 承担本质（固有×间接），这边承担依赖格式的方法。

## 假定目的的类型（用户为什么转换）

在格式的「作用」更上游。**用户究竟为什么而转换**，按对象（自己／他人）整理：

| 对象 | 假定目的 | 含义 | 典型格式 |
|---|---|---|---|
| 自己 | **理解** | 把握内容 | 图解 / 信息图 |
| 双方 | **再体验** | 以另一种形态品味作品 | 影像板 / 漫画 |
| 自己 | **记录** | 留下事件・思考 | 漫画（对话记录→漫画） |
| 他人 | **传达** | 传达内容 | 信息图 / 概念图 |
| 他人 | **吸引** | 吸引注意 | 缩略图 / 封面 |
| 双方 | **装饰** | 点缀文章 | 插画 |

**假定目的 → 格式的作用 → 粒度×时间**三段。假定目的决定作用的方向（理解/传达→说明系、吸引→注目系、再体验→象征/叙述系、记录→叙述系、装饰→装饰系）。这就是「目的是压缩的上游」的精确形态。

## 格式的类型

格式空间的 4 轴（粒度／时间／目的／大小・比例）中，**目的为核心**（「目的是压缩的上游」＝由上游的假定目的决定）。按作用梳理：

| 作用 | 格式 | 粒度 × 时间 |
|---|---|---|
| **叙述** | 漫画 / 分镜脚本 / 绘本 / 四格漫画 / 网页漫画 / 横长条漫 / 跨页大图 / 随笔漫画 / 纪实漫画 / 视频规格 | 全弧 × 展开（四格漫画・横长条漫：片段 × 一点，跨页大图：单一场景 × 一点，视频规格：全弧 × **保持时间**展开） |
| **象征** | 影像板 | 全弧 × 折叠（多格） |
| **象征** | 封面 / 海报 | 单一象征 × 折叠 |
| **象征** | 图标 | 单一象征 × 一点 |
| **概念** | 概念图 | 全概念 × 折叠 |
| **注目** | 缩略图 / 单格漫画（讽刺） | 单一象征・单一场景 × 一点 |
| **说明** | 信息图 / 图解 / 时间轴 / 流程图 / 对比矩阵 / 数据图 / 学习漫画 | 全弧 × 折叠 |
| **装饰** | 插画 | 单一场景 × 一点 |
| **制作规格** | 角色设定画 / 角色印象板 / 印象板（concept-board） / 美术板 | 设定画：一人物 × 多面（无时间轴） ／ 角色板：一人物 × 折叠（探索） ／ concept-board：全弧 × 折叠（不分割的一幅） ／ 美术板：一地点 × 一点 |

目的 6 种 × 粒度／时间的组合，再加上制作规格家族（供后道工序照着复制的文档，而不是供欣赏的画）。空间本身无限，这 10 型不过是**结晶化的命名格式**（＝代表点）。

**大小・比例也由格式决定**（由在哪里被看见决定）：缩略图＝小型・横 16:9，图标＝正方形，封面＝竖（书籍比），海报＝大型・竖，分镜脚本＝电影比 16:9，漫画＝页面比，信息图＝纵向长滚，时间轴＝横向条带（或纵向滚动），流程图＝纵向，对比矩阵＝横向网格，数据图＝横向・单一面板，概念图＝单张图・比例灵活（正方形到横长）。漫画系则另有：四格漫画＝固定四格竖列，网页漫画＝纵向长滚单画布（移动端），横长条漫＝横向单行条（报纸），跨页大图＝通栏单一分格（跨页），单格漫画＝紧凑单格，随笔漫画・纪实漫画・学习漫画＝页面比例。制作规格家族由后道工序读什么决定：角色设定画＝横长表・素地上的一行多面图，角色印象板＝一块板上的多个面板，印象板（concept-board）＝单幅・电影比〜灵活，美术板＝一张背景板・16:9。

**专业化技能的价值**由「固有构成文法的积累度」决定：

- 漫画（分格・气泡・跨页・视线诱导）是最典型的例子。
- 插画（单一场面）最薄——时间不展开・并非极端・也无特殊目的的「默认」。
- 概念图（以视觉隐喻／分屏构图／颜色编码把全概念折叠进一张图）是薄默认的反面：专业化技能的价值，在于针对特定概念选择并组合这些装置的纪律。

## 样式的类型

样式＝词汇＋文法＋规范。**词汇由媒介决定**，所以以媒介为主轴：

| 媒介 | 例 |
|---|---|
| 手绘 | 水彩 / 油画 / 铅笔 / 墨线 / 粉彩 / 速写 |
| 版画・印刷 | 木刻 / 丝网 / 孔版印刷 |
| 数字 | 像素 / 3D / 矢量 / 毛刺 |
| 摄影・记录 | 街头摄影 / 胶片 / 扫描 / 账册 |

另有**交叉的 2 轴**：

- **系谱**（文化・历史的传统）：浮世绘 / 水墨画 / 印象派 / 包豪斯 / 漫画 / 美漫
- **时代・技术**：复古 / PS1 / 8bit / 赛博朋克 / 复古未来
- **功能文档家族**（横贯手绘媒介的系谱）：[clean-line-lab](styles/clean-line-lab.md) 及其兄弟——blueprint-plan / recipe-howto / circuit-schematic / mechanism-work / geometric-construction / lab-notebook——共享同一种 DNA（功能文档的文法・概念成为可见的机制・克制＋一点意义强调），只有文档的方言不同。0.1.24 新增・已验证（power-* 样式替换用例。判定见 [examples/EVALUATION.md](../../examples/EVALUATION.md)）。

样式＝**媒介 × 系谱 × 时代**的交点，各自拥有词汇＋文法＋规范。

**样式词汇的陷阱**：罗列 `flat layered planes`・`wood grain` 这类通用标签是 Midjourney 的存货，成不了特定的声音。把每个样式固有的词汇（木刻则「刀痕・印的深浅・版木纹・晕染」等）精炼进词典（Phase 4）。

## 压缩的 2 层

| 层 | 变不变 | 内容 |
|---|---|---|
| **本质** | 不变（1 种） | 把固有 × 间接（真实 × 托付）应用于选定／翻译／配置 |
| **方法** | 依赖格式 | 粒度（全弧↔单一象征）・时间（展开↔折叠↔一点）・作用 |

- **本质（固有 × 间接）在全部格式中相同** — 以单一引擎即可正确。
- **方法（粒度・时间・构成）随格式而变化** — 需要格式专用技能。

→ 架构的分岔点：**本质 → 单一 SKILL.md（Phase 1）、方法 → 格式专用技能（Phase 4）**。
