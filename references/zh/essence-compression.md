# 本质的压缩

> 菜谱式转换引擎的「贯穿概念」。全部格式・全部转换原理的脊梁。distill-essence-engine 的参考文档。

## 概念

**「把内容的本质压缩进静态视觉」** —— 这就是这个引擎所做的全部。压缩成几张，由格式决定。

把输入（时间×意义×要素的无限信息）以 2D 静止图像（一张，或多张）为约束，在保持本质的同时折叠进去。折成几张由格式的粒度决定（一张＝缩略图・封面・插画・图标，多张＝漫画・分镜脚本・绘本）。格式不过是在这种压缩的「粒度」与「配置」上的策略差异。

### 为什么是「本质的压缩」而不是「概念的压缩」

「概念压缩装置」这个比喻，「压缩」的轴是对的。但在两点上偏窄。

- **被压缩的对象是本质而非概念。** 概念＝智性抽象。引擎折叠进去的是包含情感・氛围・故事・意义在内的本质。③翻译替换的是「心的动」而不是概念。若是「概念」，情感层会掉落，看起来像一台冰冷的装置。
- **压缩的质量伴随翻译。** 压缩是在同一媒介内变短（文章→摘要）。这里跨越媒介（文章→视觉）。没有翻译就止于「摘要」，成不了图像。

## 压缩的三道工序

| 工序 | 问 | 对应的转换原理 |
|---|---|---|
| **选定** | 留下什么（削减信息） | ② 选定 |
| **翻译** | 如何替换为视觉 | ③ 翻译 |
| **配置** | 如何排进构图 | ⑤ 构成（＝格式） |

三道工序是一个动作（**固有 × 间接**）的三个面：

- **选定** ＝ 选择固有的「瞬间」（时间的面）。以一点暗示整体。
- **翻译** ＝ 替换成固有的「象征」（意义的面）。以痕迹托付意义。
- **配置** ＝ 以固有的「关系」排布（空间的面）。以留白留下发现。

→ 详见 [选定](selection.md)・[翻译](translation.md)・[配置](arrangement.md)。

周围的原理承担这种压缩的基础与约束：

- **① 理解** ＝ 压缩的前提（把握来的是什么）
- **④ 一致性・⑦ 负向・⑧ 忠实性** ＝ 压缩的约束（守护什么・排除什么）
- **⑥ 样式** ＝ 样式（用哪种视觉语言诉说）

## 2 轴的正交（格式＝压缩、样式＝样式）

引擎由正交的 2 轴构成。三分结构（内容槽／转换逻辑／样式）与之直接对应。

| 轴 | 问 | 本质 |
|---|---|---|
| **压缩**（内容 → 结构） | 如何折叠本质 | 压缩＝「展示什么」 |
| **样式**（结构 → 外观） | 用什么样的视觉语言画 | 样式＝「以怎样的声音诉说」 |

- **格式＝压缩的策略。** 即使内容相同，全弧→单一场景→单一象征，压缩率也会变化。
- **样式＝样式。** 质感（表面的触感）只是样式的一部分。样式是「词汇（水彩的晕染・像素的点）＋文法（模糊・叠加方式）＋规范（柔和为好・约束为美）」的整体＝那幅画说话的声音。即使压缩相同，水彩／像素／油画的观感完全不同。本质不变（⑧忠实性）。可以替换，正因为它是最外层、后盖上去的一层。
- 样式也并非完全自由。⑦负向与样式成对（水彩则排除照片写实，等等），也可能影响翻译的选择方式。

样式，是看穿一侧的 `prose-style`（评价文章的「声音・文体」）的视觉版。

> 用语的整理：style＝**样式**（怎么画）。质感太窄，画风窄于画，表现太宽——中间才是「样式」。画风是样式的下位（就绘画而言）。

## 3 轴的供给源（内容・目的・样式）与压缩的位置

决定输出的是 3 个问。各自供给源不同。

| 轴 | 问 | 供给源 |
|---|---|---|
| **内容** | 有什么可画的材料 | 输入（确定） |
| **目的** | 为什么做 | 指定优先。未指定则从输入推测候选 |
| **样式** | 怎么画 | 指定优先。未指定则从输入推测候选 |

- **压缩（选定＋翻译＋配置）不是轴，而是操作。** 由内容＋目的在引擎内部导出。
- **目的是压缩的上游。** 目的驱动压缩的粒度・时间（缩略图＝注目→单一象征＋一点，分镜脚本＝叙述→全弧＋展开）。格式＝目的＋粒度＋时间的束，目的是其核心。
- **「从输入导出 3 轴」只说对了一半。** 输入能确定的是内容。目的・样式以指定为优先，从输入只能得到候选。

```
输入＝内容 ──┐
            ├→ [引擎] ──→ 图像提示词
指定＝目的 ──┤     │
指定＝样式 ──┘     压缩＝选定＋翻译＋配置（由内容＋目的）
```

与三分结构的对应：**内容槽＝输入、转换逻辑（格式）＝由目的驱动、样式＝样式**。人指定的是目的（格式名）与样式两项，压缩由引擎承担。输出也按这 3 栏（内容／格式／样式）分开给出——为让各轴能独立替换。

## 格式空间（4 轴）

格式由 4 轴的组合构成，能把握整个空间。详见 [类型](types.md)。

### 轴①：粒度（把输入的多少折进一张）

```
全弧（分镜脚本） → 单一场景（插画） → 单一象征（缩略图）
    信息多                   少                   最少
```

### 轴②：时间的处理

- **展开**：把时间排列在多个分格里（漫画・绘本）
- **折叠**：把时间压进一张（影像板・封面）
- **一点**：只有某个瞬间（插画）

### 轴③：目的（为什么做这张图）

- **叙述**＝传达故事（分镜脚本・漫画）
- **象征**＝表现本质（封面・海报・图标）
- **注目**＝吸引目光（缩略图）
- **说明**＝传达概念（信息图・图解）
- **装饰**＝美美地添上（插画・诗×插画）

### 轴④：大小・比例（在哪里被看见）

- 缩略图＝小型・横 16:9，图标＝正方形，封面＝竖（书籍比），海报＝大型・竖，分镜脚本＝电影比 16:9，漫画＝页面比，信息图＝纵向长滚。

由 4 轴的组合，可以无限生成「可能存在的格式」（例：粒度高 × 折叠 × 象征 ＝ 影像板）。

## 与既有体系的连接

「如何抓住本质」这个问，与既有的成果物同根。

- **elevate-draft-engine 的止扬（Aufheben）**：向本质升华（写的一侧）
- **admiration**：本质性的「哇」（超出预测而必然）
- **hook**：本质的「未知」（想知道）
- **emotional-power**：本质性的心的动

这个引擎，是**把那种「本质」压缩并视觉化**的一侧的担当者。对写的一侧（止扬）与看穿的一侧（评价），补上**画的一侧**的缺失。
